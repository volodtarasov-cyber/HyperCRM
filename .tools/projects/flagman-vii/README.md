# Обработка «Флагман VII»

Технический обработчик курса Антона Маркина (2025). Исходники читаются из `D:\Курсы`, не меняются. Материалы, инвентаризация, журналы и транскрибации — в игнорируемой `.tools/local/flagman-vii/`. Готовые материалы и границы обработки — [указатель](../../../knowledge/frameworks/flagman-vii-2025/_index.md).

Из корня волта:

```powershell
& .tools/venv-whisper/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/course.py inventory
& .tools/venv/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/course.py extract
& .tools/venv-whisper/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/course.py run --limit 1
& .tools/venv-whisper/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/course.py run
& .tools/venv-whisper/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/course.py status
powershell -NoProfile -ExecutionPolicy Bypass -File .tools/projects/flagman-vii/start.ps1
```

`inventory` читает метаданные всех MP4 и SHA-256, выбирает основной курс владельцем точного дубля. `extract` извлекает DOCX с гиперссылками, текстовые PDF по страницам, XLSX с формулами и ссылками, TXT, CSV, XMind; не открывает внешние ссылки и не выполняет макросы. `.url` пропускает как рекламные ярлыки раздачи. Старый DOC, ZIP, RAR и изображения требуют отдельного разбора; пустые страницы PDF отмечаются для OCR.

`run` использует уже установленную large-v3, только локальный кэш. Звук — через PyAV без несовместимого аргумента `metadata_errors` и без FFmpeg. JSON хранит сегменты и показатели распознавания, SRT — субтитры, Markdown — читаемую версию. Метка завершения записывается последней; ошибка отдельного файла не останавливает очередь. Дубли ссылаются на канонический ID в `inventory.json`. Повторный запуск пропускает только законченные комплекты с совпавшим хешем. Один worker защищён блокировкой ОС.

`start.ps1` запускает полную очередь скрытым процессом с журналами `worker.stdout.log`, `worker.stderr.log` и PID в рабочем каталоге. `status` также строит `README.md` с картой всех исходных видео и ссылками только на готовые транскрибации. Карту можно обновить отдельной командой во время работы.

Для повреждённых стилей XLSX применяется извлечение OOXML без стилей; нестандартные символы PDF нормализуются. Формулы сохраняются как формулы, не рассчитываются. Автоматическая транскрибация и извлечённые документы требуют редакторской проверки.

Пилот `--limit 1` берёт самое короткое уникальное видео. Полный прогон: подготовка → основной курс → бонус, естественный порядок номеров. Проверить ошибочные файлы можно в `errors/` и по неполному покрытию `status`; старый файл ошибки не доказывает текущий сбой, комплект результатов имеет приоритет.

Для мягкой остановки создать `.tools/local/flagman-vii/STOP`; worker остановится после текущего видео. Для возобновления удалить только этот файл и запустить `run` снова. Выключение ПК останавливает обработку; автозапуска и запрета сна нет. `worker.json` — диагностический снимок, наличие живого процесса проверяется отдельно.

Этот обработчик автоматизирует извлечение и транскрибацию. Конспекты, каталог сервисов, плейбуки и книга требуют отдельного смыслового разбора и проверки источников; скрипт их не объявляет готовыми.

## Сборка книги из подготовленных материалов

```powershell
& .tools/venv/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/catalog.py
& .tools/venv/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/build-book.py
& .tools/venv/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/build-book.py --pdf
& .tools/venv/Scripts/python.exe -X utf8 .tools/projects/flagman-vii/check-delivery.py
```

`services.json` и `manual-service-evidence.json` задают имена/роли/контексты. `finalize-catalog.py` переносит уточнения законченного чтения в конфигурацию; запускать при необходимости обновить её, до каталога. `catalog.py` затем собирает указатель по локальному корпусу. Ни одна из этих команд не открывает внешние ссылки и не устанавливает актуальность тарифов.

`build-book.py` проверяет соответствие видео/конспектов/транскриптов и собирает Markdown, автономный HTML и EPUB. `--pdf` печатает уже собранный HTML локальным Chromium в offline-контексте; браузер берётся из `D:\.cache\ms-playwright`, ничего не скачивается. Результаты — `.tools/local/flagman-vii/exports/`. Исходники книги — Markdown в папке курса, а не отредактированный вручную экспорт.

`check-delivery.py` проверяет локальные цели ссылок, якоря HTML, XML EPUB и наличие оснований для каталога. Это проверка сборки, без внешнего SEO/юридического фактчекинга. JSON-результаты лежат в `.tools/local/flagman-vii/analysis/`.

`attachment-review.py` готовит порционное чтение раздатки и отделяет таблицы от текста. Состояние чтения различает содержательный проход и структурный обзор данных/образцов. `extract-legacy-docs.ps1` извлекает старые DOC через Word только для чтения с отключёнными макросами; `register-legacy-docs.py` регистрирует результат рядом с другими извлечениями. Исходные DOC/PHP/RAR не выполняются как программы.

`course-only-edit.py` — разовая очистка старых редакторских адаптаций после решения работать по курсу; резервные версии в игнорируемой `analysis/before-course-only-edit/`. Повторять очистку без причины не нужно.
