## Источники дохода (по v2)

- **Левша (нога 2):** база 120к подтверждена (08.06), результатная часть → потенциал 200-250к.
- **Трафик-портфель (нога 1):** простой процент 40% ТМ (решение 29.05) → чистыми **150-187к**. Не 250к — то была старая фикс-модель.
- **Инфобиз (нога 3):** клуб 5к/мес × N + 2 группы 10-15к/мес + разовый консалтинг (консультация 20к, спринт 90к). Фракц-CMO убран 23.06. На 29.06 продаж 0.

## Цели

- **Floor ~270-300к/мес** — с оговоркой: по %-модели трафика floor проседает к 270.
- **Base ~400-500к** — реалистичный осенний коридор.
- **600к к декабрю — растяжка, не базовый сценарий.** Честный декабрьский выход ≈ 450-550к.

## Зависимости

1. Платёжные рельсы для ноги 3 (приём не-РФ денег) — до запуска клуба на мир.
2. Разгрузка Левши до 12-16 ч/нед — иначе нога 3 физически не стартует.
3. Факт Левши за июнь (120 vs 200-250).
4. Трафик post-Женя: валовая не просела, Лия не перегружена (≤10 клиентов).
