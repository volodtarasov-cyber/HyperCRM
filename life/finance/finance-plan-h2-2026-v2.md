## Floor / Base / Target — честный разбор

- **Floor ~270-300к** — Левша 120 + трафик 150. ⚠️ **Floor 300 берётся НЕ так уверенно, как в старом плане:** там трафик считали 250 (фикс-модель). По %-модели floor проседает к ~270 в низком сценарии. Чтобы держать 300 — нужен либо трафик ближе к 187, либо результатная часть Левши.
- **Base ~400-500к** — реалистичный осенний коридор (Левша 150-200 + трафик 187 + нога 3 раскачивается).
- **Target 600к — стало СТРОЖЕ обеспечено, чем рисовал старый план.** Даже верхняя граница декабря = ~590. Чтобы пробить 600, нужно ОДНОВРЕМЕННО: Левша на топе (250) + трафик 187 + нога 3 = 150. Старые 600 опирались на иллюзии (трафик 250 + сопровождение 166) — обе убраны.

**Bottom line:** floor ~300 — ок (с оговоркой по трафику). **600 теперь — растяжка, не базовый сценарий.** Честный декабрьский выход ≈ **450-550к**, 600 — если нога 3 реально выстрелит и Левшу насчитают по результату.

## Зависимости (без них верхний сценарий не случится)

1. **Платёжные рельсы** (нога 3 глобал) — приём денег от не-РФ (foreign entity / Stripe / крипта). Решить до запуска клуба на мир.
2. **Левша → 12-16 ч/нед** — пока детейлинг 5/2 забирает все 40 ч, на ногу 3 времени нет. Без разгрузки Левши нога 3 не стартует физически.
3. **Факт Левши за июнь** — зафиксировать результатную часть (120 vs 200-250).
4. **Трафик post-Женя** — подтвердить валовую и %-маржу.
