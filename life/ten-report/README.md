# Отчёт в десятку

> Еженедельный отчёт в мастермайнд-группу «десятка». Куратор — Илюшин Александр.
> Дедлайн: **воскресенье 23:59**.

## Формат

Одно сообщение с тегом `#Тарасов_Владимир` (личный тег участника) и диапазоном недели в заголовке.

## Как я помогаю

Каждое воскресенье:
1. Собираю daily-файлы за неделю (пн–вс)
2. Подтягиваю в черновик:
   - Что сделано по проектам (из блока «Итоги» каждого дня)
   - Вне плана / инсайты (оттуда же)
   - Энергию на финише по дням → средняя / паттерны
3. Оставляю пустыми: цифры ЧП, прогноз, цели на след. неделю, запрос к десятке
4. Ты дожимаешь руками — копируешь в TG

## Файлы
- `_template.md` — форма
- `YYYY-WXX.md` — архив по неделям (например `2026-W16.md` для 13–19.04)
