# Наблюдения и их происхождение

Указатель помогает связать существующие основания с анализом. Он не копирует истории клиентов и не добавляет новых респондентов. Исходные формулировки принадлежат документам по ссылкам. Метод добавления → [структура](../../structure.md), новая запись → [форма](../../templates/observation.md).

## Когда появляются новые материалы

Для самостоятельного нового наблюдения создаётся файл со следующим свободным ID по [форме](../../templates/observation.md), затем добавляется строка указателя. Если это ещё одно поле уже известного эпизода, сохраняется тот же ID эпизода/компании. Один источник может поддерживать разные выводы; один вывод может иметь несколько независимых оснований.

Синтетические реплики не попадают в этот указатель как наблюдения о покупателях. Публичный зарубежный эпизод сохраняет свой рынок, тип бизнеса и ограничения переноса.
