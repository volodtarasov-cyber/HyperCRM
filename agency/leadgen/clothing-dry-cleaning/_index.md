# Химчистки одежды: лидген агентства

По решению Володи работа по нише ведётся в этой папке. Структура: **ниша → JTBD → сегмент → база аудитории и отдельные воронки → этапы AARRR, материалы и проверки**. Общее исследование, источник факта и результат замера не смешиваются.

| Дополнить боли, желаемые результаты, страхи, возражения и выбор | [Аудитория рабочего сегмента](jtbd/delegate-marketing-for-growth/segments/replace-marketer/audience/_index.md) |
| Найти или добавить конкретную связку | [Воронки сегмента](jtbd/delegate-marketing-for-growth/segments/replace-marketer/funnels/_index.md) |
| Посмотреть определения показателей и реальные результаты | [Измерения](measurement/_index.md) |
| Добавить новый материал по общей форме | [Наблюдение](templates/observation.md), [сегмент](templates/segment.md), [воронка](templates/funnel.md), [результат проверки](templates/experiment-result.md) |

**Объект этой воронки — привлечение собственников химчисток в агентство.** Источники самого агентства описываются в Acquisition. Разбор маркетинга химчистки и карта каналов для неё — результат Activation; выбор клиентских каналов не подменяет выбор источников агентства.
