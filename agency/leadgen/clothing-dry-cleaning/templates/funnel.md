# Форма новой воронки

Место: `jtbd/<работа>/segments/<сегмент>/funnels/<связка>/_index.md`.

| Поле | Содержание |
|---|---|
| funnel_id | Следующий свободный код |
| Версия связки | Изменять при существенном изменении пути; версия сценария учитывается отдельно |
| Работа и сегмент | Ссылки на паспорта |
| Вход и исходное состояние | Какой человек, с какой задачей и откуда приходит |
| Наблюдения и выводы аудитории | Конкретные ID, а не общий портрет |
| Первая польза | Что получает и какое действие наблюдаем; проверенность критерия отдельно |
| Платное предложение | Ссылка на продукт; не обязательная ступень по умолчанию |
| Путь | Ссылки на этапы AARRR и материалы |
| Показатели | Определения событий, числителей, знаменателей и окна |
| Ограничения исполнения | Ссылка на роли/экономику и известные лимиты |
| Применение | Фактические публикации/проверки, если есть |
| Следующий вопрос знания | Что пока мешает обоснованно выбрать механику |

Материалы создаются по необходимости, а не сразу все. Реальный запуск фиксируется в [реестре проверок](../measurement/experiments.md). Сырые события, задачи и контакты здесь не ведутся.
