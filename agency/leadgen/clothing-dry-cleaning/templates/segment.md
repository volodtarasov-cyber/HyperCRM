# Форма нового сегмента внутри работы

Место: `jtbd/<работа>/segments/<сегмент>/_index.md`. Новый сегмент выделяется по отличию ситуации выбора, прежнего способа, критериев или барьеров, а не ради заполнения дерева.

| Поле | Содержание |
|---|---|
| segment_id | Следующий свободный код |
| Родительская работа | Ссылка на паспорт JTBD |
| Ситуация выбора | Когда рассматривает решение |
| Предыдущий способ | Из реального эпизода либо «не установлен» |
| Граница включения и исключения | Какие ситуации сюда относятся |
| Основания | ID наблюдений, независимые эпизоды, рынок |
| Тип знания | Рабочая интерпретация / гипотеза; не объявлять проверенным по наличию файла |
| Четыре силы | Ссылки на сведения; неизвестные поля оставить неизвестными |
| Отличие от соседних сегментов | Что реально меняет предложение и путь |
| Аудитория | Ссылки на проблемы/результаты, страхи/возражения, выбор/язык |
| Воронки | Ссылка на собственный реестр связок |

Для сегмента без покупательского эпизода достаточно паспорта и пробелов. Пустую библиотеку воронок и вымышленные боли создавать не нужно. Правила → [структура](../structure.md).
