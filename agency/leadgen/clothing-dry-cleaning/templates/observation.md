# Форма нового наблюдения

Создавать в `research/observations/CDC-OBS<number>.md`; использовать следующий свободный ID [указателя](../research/observations/_index.md). Эта форма не является новым наблюдением.

| Поле | Что записать |
|---|---|
| ID наблюдения | Постоянный код |
| ID источника | Код [реестра](../research/sources.md) |
| Компания / автор и episode_id | Реальный объект; если не установлен, так и указать |
| Рынок, ниша, роль | Только известные признаки |
| Дата события / публикации / получения | Раздельно; неизвестное не восстанавливать |
| Тип основания | Прямое высказывание / пересказ / наблюдаемое действие / измерение |
| Точное место в источнике | Ссылка, раздел, страница или таймкод; клиентская запись остаётся локально |
| Наблюдение | Одно конкретное утверждение, без добавления мотива за человека |
| Дословность | Цитата с точным местом либо явно помеченный пересказ |
| Контекст | Ситуация, предложение, этап пути |
| Ограничения | Что этим основанием нельзя доказать |
| Связанные выводы и возражения | ID из audience/ |
| Применение | Работа, сегмент, воронка и этап |
| Противоречит | ID другого наблюдения/вывода, если есть |

Если факт уже имеет владельца в карточке клиента, вместо копии сохраняется точная ссылка на его поле. После создания добавить строку в указатель. Синтетический сценарий не оформляется как наблюдение о реальном покупателе.
