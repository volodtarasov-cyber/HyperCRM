# Как связывать данные без двойного счёта

Это проект полей для существующего рабочего учёта, не внедрённая CRM. Постоянные ID справочников → [структура базы](../structure.md#постоянные-id). Показатели и определения событий принадлежат конкретной воронке, сейчас [CDC-F01](../jtbd/delegate-marketing-for-growth/segments/replace-marketer/funnels/content-city-review/measurement-and-test.md).

## Единица анализа

Одна компания учитывается по устойчивому ID центра решения о покупке. Несколько её точек, чатов или повторных сообщений не становятся несколькими лидами. Если одинаковый бренд объединяет независимых покупателей-франчайзи, граница определяется фактической организацией.

Контакт, компания, эпизод выбора, разбор и материал имеют разные ID. Один человек может увидеть ролик, читать канал и написать: это касания одной компании, когда связь установлена. Неустановленная связь не достраивается догадкой.

Повторные сообщения одной компании в одном эпизоде не дают дополнительные переходы в компании-уровневых конверсиях. Для анализа отдельных разборов допускается другой объект, но числитель и знаменатель тогда оба относятся к разборам. Выбранный объект указывается рядом с показателем.

## Поля связи

| Поле | Назначение |
|---|---|
| company_id | Компания / независимый центр покупки; не название бренда само по себе |
| contact_id | Конкретный контакт в защищённом рабочем учёте |
| episode_id | Отдельная ситуация выбора; связывает несколько наблюдений одного покупательского эпизода |
| source_id, observation_id | Происхождение исследовательского утверждения |
| job_id, segment_id | Работа и подтверждённая либо предварительная принадлежность к сегменту |
| funnel_id | Связка, к которой относится событие |
| material_id, version | Конкретный материал и версия; если не установлен, остаётся неизвестным |
| experiment_id | Фактически начатая проверка; не назначается подготовке вместо запуска |
| review_id | Конкретный городской разбор |
| event_code, occurred_at | Определённое событие и фактическое время с часовым поясом |
| evidence_ref | Ссылка или точное место основания события в доступном рабочем контуре |
| attribution_basis | Рассказ человека, техническая метка или другое явное основание; неизвестный источник не угадывается |
| measured_at, period, cohort | Дата среза, период и правило включения в знаменатель |

Имена полей — схема связи. Они не означают, что такой набор уже настроен в сервисе.

## Контекст конкретного обращения

| Группа | Поля |
|---|---|
| Компания | Ниша, город, число относящихся к задаче пунктов, ссылка на компанию |
| Ситуация | Запрос человека, прежний способ маркетинга, что не устраивает, основание отнесения к сегменту |
| Источник | Первый названный источник, другие известные касания, конкретный материал, способ установления |
| Разбор | Согласованная дата, фактическая дата, причина переноса или отказа |
| Выход | Ссылки на запись и документы, факт выдачи карты, ответ о первом шаге |
| Нагрузка | Минуты подготовки, данных, созвона, оформления, коммуникации и фактический исполнитель |
| Расходы | Учтённые денежные расходы, полнота учёта и основание стоимости труда |
| Продолжение | Следующий фактический выбор, предложение, оплата или причина остановки при наличии основания |

## Сопоставимость

Исследование считает независимые компании/эпизоды по вопросу, воронка — фактические события, экономика — деньги и нагрузку. Тот же эпизод в интервью, отзыве и пересказе остаётся одним эпизодом. Зарубежный аналог и собственная российская химчистка не объединяются в однородную выборку без оговорки.

Неизвестный признак не равен «нет», отсутствующая проверка не равна провалу, будущая встреча не равна неявке. Нулевой знаменатель даёт «не определено». Проценты показываются вместе с N/M, периодом, правилом включения и незавершёнными путями.

Сводки разных версий допускают сравнение только с описанием различий аудитории, источников, периода и предложения. До/после без сопоставимой группы не доказывает причинного эффекта нового текста.
