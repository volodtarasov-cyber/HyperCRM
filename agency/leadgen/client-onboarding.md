# Онбординг клиента после оплаты — own leadgen

> Дата: 2026-05-05
> Назначение: быстро перевести оплатившего клиента в запуск без хаоса и потери импульса.

---

## Цель онбординга

За 1-2 рабочих дня после оплаты собрать всё, что нужно для запуска первой VK-связки:

- доступы;
- материалы;
- услуга для первого теста;
- сценарий обработки заявок;
- таблица учёта;
- дата первого weekly review.

---

## Сообщение после оплаты

```text
Оплату получил, старт фиксируем.

Чтобы быстро собрать запуск, пришлите, пожалуйста:

1. Доступ к VK-группе и рекламному кабинету.
2. Фото/видео работ.
3. Прайс или диапазоны расчёта.
4. 3-5 отзывов / кейсов, если есть.
5. Список услуг, которые хотите продвигать.
6. Кто отвечает на заявки и в какое время.
7. Как сейчас фиксируете заявки и заказы.

Первый шаг с нашей стороны: выбираем одну услугу для теста, собираем оффер и 5-7 креативных гипотез.
```

## Материалы

| Материал | Минимум |
|----------|---------|
| Фото работ | 10-20 фото |
| Видео процесса | 3-5 коротких видео, если есть |
| Отзывы | 3-5 |
| Прайс | полный или диапазоны |
| Гео | районы / город / зона выезда |
| Ограничения | загрузка, график, сложные услуги |
| УТП | сроки, забор/доставка, гарантия, опыт |

## Выбор первой услуги

Не запускать всё сразу.

Критерии выбора:
- услуга маржинальная;
- есть спрос;
- можно быстро рассчитать;
- есть фото/видео;
- клиент готов её обрабатывать;
- есть понятный сценарий боли.

Приоритеты:

Для стирки ковров:
- сезонная стирка ковров с забором;
- стирка ковров + химчистка мебели;
- повторная кампания по базе.

Для клининга:
- уборка после ремонта;
- генеральная уборка;
- уборка перед въездом / после арендаторов;
- коммерческий регулярный клининг, если есть отдельный B2B-процесс.

## Настройка обработки заявок

До запуска нужно согласовать:

- куда приходит заявка;
- кто отвечает;
- норматив скорости ответа;
- какие вопросы задаём;
- когда отправляем follow-up;
- где фиксируем статус.

Минимальный норматив:

```text
Новая заявка -> ответ до 15 минут в рабочее время.
Если спросил цену и пропал -> follow-up через 24 часа.
Если не дозвонились -> повтор через 2-4 часа и на следующий день.
```

## Таблица заявок

Минимальные колонки:

| Поле | Что фиксируем |
|------|---------------|
| Дата | когда пришла заявка |
| Источник | кампания / креатив / ключ |
| Услуга | что интересует |
| Контакт | имя / телефон / VK |
| Статус | новая / ответили / расчёт / заказ / отказ |
| Сумма | если заказ |
| Причина отказа | дорого / неактуально / выбрал других / не ответил |
| Комментарий | качество лида |

## Weekly Review

Первый weekly review — через 7 дней после запуска рекламы.

Шаблон:

```text
Итоги недели:

1. Потратили:
2. Получили лидов:
3. CPL:
4. Квалифицированных лидов:
5. Заказов / предварительных заказов:
6. Лучшие связки:
7. Слабые связки:
8. Главные причины отказа:
9. Что отключаем:
10. Что усиливаем:
11. Что нужно от клиента:
```

## Решение после 30 дней

В конце теста подготовить короткий отчёт:

- какие связки тестировали;
- что сработало;
- что не сработало;
- сколько стоил лид;
- какое качество;
- что происходило в обработке;
- есть ли смысл продолжать;
- план следующего месяца.

Решение:
- продолжаем и масштабируем;
- меняем услугу/оффер;
- останавливаем работу.
