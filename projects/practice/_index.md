# Агентство @agency — дашборд направления

**Статус:** active — главное направление развития

**Владелец:** Володя
**Проверено:** 2026-09-01

> Цель: делегируемое маркетинговое агентство с **1 млн ₽+ чистой прибыли в месяц**. Путь `projects/practice/` сохранён исторически; каноническое решение → [life/decisions.md](../../life/decisions.md).

## Северная звезда

Агентство доводит собственный участок работы до денег:

```text
спрос → посадочная → квалифицированный лид → продажа → валовая прибыль
```

Фиксированная оплата обязательна. Бонус за результат появляется только там, где клиент даёт надёжную квалификацию, продажи и атрибуцию.

## Основные разрывы

| Разрыв | Почему важен | Условие закрытия |
|---|---|---|
| Нет единой карты «клиент → продукты → исполнитель → себестоимость» | нельзя считать маржу и мощность | все активные клиенты разложены в одном P&L |
| Не везде есть квалификация и продажи по источнику | нельзя обещать результат после заявки | у клиента есть владелец данных и регулярная передача |
| Карты не упакованы в отдельный продукт | Лия получает новую площадку без границ работы | состав, KPI, цена и пилот минимум на двух клиентах |
| Быстрый лендинг не стандартизирован | большой сайт Ольги не подходит каждому трафиковому тесту | фиксированы состав, срок, итерации и себестоимость |
| Юля может превратиться в оператора всех платформ | теряется глубина и контроль | Юля управляет paid-контуром, Сергей и Света исполняют специализации |
| Цель 1 млн чистыми не разложена по мощности | цель остаётся лозунгом | финмодель по цене, марже, единицам и числу исполнителей |
