# OPF — прогон по шагам

> **Задача метода — собрать воронку одного продукта (первое касание → заявка → покупка) и проверить тестом.** Диагностика (S1-S2) — вход в сборку, не самоцель: «где рвётся поток» показывает, что строить и тестировать первым, а не бизнес-болячку «под ключ».

> Процесс разбит на шаги **S1…S11** (4 фазы). Идём **шаг за шагом**: каждый шаг даёт артефакт в файл [сборки](_assembly-template.md). Ассистент переходит к следующему шагу **только после подтверждения** артефакта текущего.

## Как ведём прогон

1. Копируем [шаблон сборки](_assembly-template.md) под конкретный продукт (напр. `detailing-samara/.../opf-ppf-assembly.md`).
2. Открываем `s1` → делаем → заполняем артефакт S1 в сборке.
3. **Подтверждение** (по критерию готовности) → только тогда `s2`. И так до `s11`.
4. Каждый шаг **самодостаточен** — вся глубина (вопросы, таблицы, фреймворки) внутри самого файла шага, открывать другие файлы не нужно.

## Шаги

| Шаг | Фаза | Что | Результат |
|---|---|---|---|
| [S1](s1-situation.md) | Диагностика | Компания/эксперт и текущая ситуация | контекст + ГЛАВНОЕ ОГРАНИЧЕНИЕ и денежная проблема |
| [S2](s2-jtbd-segments.md) | Диагностика | JTBD-карта сегментов | 5-7 работ, кто нанимает, приоритет |
| [S3](s3-beachhead-forces.md) | Фокус | Beachhead + 4 силы | один сегмент + что им движет |
| [S4](s4-schwartz.md) | Фокус | Уровень осознанности (Шварц) | один уровень входа |
| [S5](s5-product.md) | Сборка | Продукт / юнит | продукт под сегмент и уровень |
| [S6](s6-offer.md) | Сборка | Оффер, упаковка, позиционирование | оффер + незанятое место + пакеты |
| [S7](s7-source.md) | Сборка | Источник | один проверяемый канал |
| [S8](s8-cjm.md) | Сборка | CJM — путь касаний | путь, точка перелома, лид-магниты |
| [S9](s9-sales.md) | Сборка | Заявка, квалификация, дожим | довести интерес до оплаты и вернуть тёплых |
| [S10](s10-scorecard.md) | Тест | Скоркард зрелости (7 осей) | балл зрелости + узкие места |
| [S11](s11-test.md) | Тест | 30-дневный тест | одна проверяемая гипотеза на 30 дней |

## Правило

Не забегаем вперёд. Один шаг = один разговор = один подтверждённый артефакт. Расходимся в фазе 1 (диагностика), сходимся к одному в фазах 2-4.

> **Почему нет отдельного шага «конкуренты».** Поверхностно (кто + негатив) собираем в S1; глубокое позиционирование и незанятое место — в S6 (оффер), когда уже понятно, за какой сегмент и с кем деремся.
