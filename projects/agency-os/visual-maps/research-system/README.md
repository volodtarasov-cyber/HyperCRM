## Как Открывать

### Markmap

1. Открыть нужный `.md`.
2. Нажать `Cmd+Shift+P`.
3. Выполнить `Open as markmap`.

Markdown является источником данных. Карта строится из его иерархии.

### Excalidraw

Открыть `.excalidraw` в VS Code. Расширение Excalidraw покажет визуальный
редактор с возможностью двигать блоки, добавлять стрелки и комментарии.

## Статусы Узлов

- `[ФАКТ]` — подтверждено CRM, документом, наблюдением или несколькими источниками.
- `[ОЦЕНКА]` — расчет или интерпретация на подтвержденной базе, но не прямой факт.
- `[ЦИТАТА]` — дословная формулировка клиента с указанием источника.
- `[ГИПОТЕЗА]` — правдоподобное объяснение, которое еще нужно проверить.
- `[ПРОБЕЛ]` — данных недостаточно.
- `[КОНФЛИКТ]` — источники, обещания или версии продукта противоречат друг другу.
- `[РЕШЕНИЕ]` — принятое продуктовое или маркетинговое решение.
- `[ЗАДАЧА]` — конкретное следующее действие.

## Правило Масштабирования

Не создавать одну гигантскую карту клиента. Использовать три уровня:

1. обзор системы;
2. карта направления и продукта;
3. отдельная карта каждого JTBD × сегмента.
