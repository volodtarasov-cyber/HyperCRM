# Course notes — библиотека конспектов

Слой подробных структурированных конспектов курсов, на которых стоит Agency OS.
Источник для рабочих модулей (`../modules/`) и методов (`../methods/`).

Каждый курс — отдельная подпапка: `README.md` (навигация) + `*-notes.md` (конспекты) +
`transcripts/` (полные расшифровки .txt и .srt с таймкодами).

## Как читать слой

- **Ребдеу** — методологический костяк системы: скрининг → конкуренты → продукт/JTBD → маркетинговая система. Лёг в модули #0–#4.
- **ПсихоМаркетинг** — прямой маркетинг малого бизнеса целиком: оффер, экономика, продажи, удержание, лестница клиента. Усиливает исследовательские модули и вскрывает пробелы (оффер, диагностические продажи, удержание/рекомендации).
- **Копирайтинг** — ремесло сообщения: структуры текста, заголовки, буллеты, отработка возражений. Не growth-модуль, а метод сообщения + топливо для `/copywriter`.
- **Нейрошаманский** — соционика как язык наблюдения за коммуникацией; прикладной слой, не клиническая диагностика.

> Транскрипты получены автоматическим распознаванием (Whisper) — возможны ошибки в именах и терминах. Конспекты очищены, спорные/устаревшие тезисы вынесены в критические замечания, а не как факты.
