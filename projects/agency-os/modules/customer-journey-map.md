# Карта пути клиента (CJM) по JTBD-сегменту — генеративная методология

**Статус:** working
**Тип:** анализ / упаковка / продажи
**Где применяем:** после JTBD, перед сборкой касаний/контента/скриптов — **на один продукт**
**Владелец:** Володя
**Дата создания:** 2026-06-17 · обновлён генеративно по разбору Ребдеу

> Это не шаблон с полями, а **как думает аналитик CJM**. Реверс-инжиниринг полного вывода Ребдеу. Скилл — `/cjm`.
> ⚠️ Скоуп: один продукт за прогон; одна карта = один JTBD-сегмент; затем сводка по всем сегментам продукта.

---

## Вход и кросс-ссылки (откуда берём, не из головы)
- **JTBD-сегмент** (Core/Big Jobs, точка слома) — из `/jtbd-segments`.
- **Барьеры и страхи** — из **негатива конкурентов** (отзывы) + **отзывов/звонков своих** (VoC), не выдумывать.
- **Точки контакта** — из профайла (карты, Авито, сайт, звонок, стойка, мессенджеры).
- **Эмоции** — из реальных формулировок клиента.

> Связка обязательна: барьер в CJM = тот же, что точка слома в JTBD = тот же, что негатив конкурентов. Если расходятся — ошибка.

## Что порождаем

### 1. Главный вывод (синтез по всем сегментам)
Один абзац: общий путь, который проходят ВСЕ сегменты (проблема → выбор исполнителя → пик доверия → ожидание → выдача → лояльность), **где он рвётся** (общий провал — обычно стык «первый контакт → ожидание работ»), и **3 узла, которые чинятся единым решением для всех**.

### 2. Карта на каждый сегмент
**Шапка сегмента:** JTBD-сегмент + сегмент ЦА · ключевой барьер · **точка перелома** (шаг + эмоция: балл 1–10 + лейбл) · что внедрить · быстрая победа.

**Путь ~8 шагов. На КАЖДЫЙ шаг — полный набор (это и есть глубина):**
- **Эмоция:** балл 1–10 **+ словесный лейбл** («радость с тенью тревоги», «любопытство и растерянность», «настороженное ожидание», «доверие и облегчение», «восторг и гордость», «спокойная уверенность»);
- **Длительность** шага;
- **Что делает** (нарратив);
- **Точки контакта** (конкретный список 3–4);
- **Барьеры** (3);
- **Внутренний диалог** — **3 дословные цитаты** клиента от первого лица («Кому в Самаре доверить машину за 7 миллионов?»);
- **Поисковые запросы** — **15+ на шаг, эволюционируют по воронке**: осознание («как защитить кузов нового авто») → сравнение («полиуретан или винил») → локальные/брендовые («оклейка авто самара») → цена («сколько стоит обклеить») → процесс («сколько дней клеят») → уход («уход за плёнкой»);
- **Места поиска клиентов** — где обитает / как дотянуться до аудитории ЭТОГО шага. Не «точки контакта» (это куда он сам пришёл), а **где его искать активно**. Пройтись по таксономии, выбрать релевантные типы + назвать **конкретные инстансы**:
  - **Группы ВКонтакте** · **Страницы / паблики ВК** · **Instagram-аккаунты** · **TikTok-аккаунты** · **YouTube-каналы** · **Telegram-каналы и чаты** · **Блоги / форумы / сайты** (нишевые форумы, профильные площадки, отзовики) · **Лидеры мнений** (блогеры/эксперты ниши) · **Offline-ареалы** (физические места скопления сегмента) · **Входящие партнёры** (смежный бизнес, кто отдаёт рекомендацию).
  - Под тёплость шага: холодные шаги (осознание) — паблики/блогеры/offline/партнёры; активный поиск — форумы/отзовики/тематические чаты; пост-покупка/реферал — лидеры мнений + входящие партнёры.
- **Возможности** (3);
- **Лид-магниты на шаг** («чем протащить дальше») — **несколько на шаг**, каждый: **тип** (PDF-гайд / видео-разбор / статья / квиз / калькулятор / кейс-подборка / протокол приёма / пробный фрагмент / фотоотчёт / памятка / гарантийный пакет) · описание · **Снимает:** (какой барьер закрывает) · **Как донести:** (канал **+ обоснование по тёплости аудитории на этом шаге**) · **Альтернатива:** (второй канал);
- **Переход к следующему этапу**.

> Лид-магниты и запросы — НЕ на сегмент, а **на шаг**. Канал подбирается под тёплость шага.

### 3. Пересечения и конфликты
- 🟢 **Зелёные** — что чинится **единым решением** для всех сегментов (письменная фиксация цены/срока, экскурсия-диагностика, проактивные фотоотчёты).
- 🔴 **Красные** — где **мотивы сегментов конфликтуют** (по цене: премиум 1,2,5 vs чувствительные 3,4; по скорости: срочным нельзя занимать приоритетные окна неспешными работами).

### 4. Общие приоритеты (сквозные)
5 улучшений, общих для всех сегментов, от главного провала к удержанию.

## Движок рассуждения (думай так)
1. **Эмоция — балл + лейбл.** Найди шаги, где падает ≤4 (провал) и где пик ≥7 (использовать).
2. **Точка перелома — ОДНА на сегмент** (где решается да/нет), не «везде важно». Обычно совпадает с пиком доверия (экскурсия-диагностика) или с провалом (ожидание вслепую).
3. **Барьеры — из реальности** (негатив конкурентов + VoC + точка слома JTBD).
4. **Лид-магниты и запросы — на КАЖДЫЙ шаг, не на сегмент.** На шаг — несколько лид-магнитов, каждый закрывает конкретный барьер этого шага.
5. **Канал лид-магнита — по тёплости аудитории НА ЭТОМ шаге:**
   - холодный/осознание → реклама в Директ/таргет на вводный лендинг/видео;
   - сравнение/активный поиск → SEO-посадочная, квиз, калькулятор;
   - тёплый/оставил заявку → мессенджер (WhatsApp/Telegram), персональный расчёт;
   - в работе / на выдаче → лично в боксе / мессенджер по клиенту.
   Всегда + «Альтернатива» (второй канал).
6. **Поисковые запросы эволюционируют по воронке:** на каждом шаге свой кластер (осознание → сравнение → локальные/брендовые → цена → процесс → уход). 15+ на шаг.
6б. **Места поиска ≠ точки контакта.** Точка контакта — куда клиент пришёл сам; место поиска — где его дотянуть активно. На каждом шаге пройти таксономию (VK группы/паблики · Instagram · TikTok · YouTube · Telegram каналы/чаты · форумы/блоги/сайты · лидеры мнений · offline-ареалы · входящие партнёры) и назвать **конкретные инстансы**, не «соцсети».
7. **Внутренний диалог — дословными цитатами** от первого лица (из VoC), не пересказ.
8. **Сведи green/red:** что единым решением для всех, где конфликт мотивов (нельзя один прайс-месседж/одну скорость на всех).
6. **Главный вывод — синтез:** общий путь + где рвётся + 3 узла на весь центр.
7. **Возможности конверсии шага** → ТЗ на касания/контент/скрипты (барьер → тема кейса/блок лендинга/ответ скрипта; пик → просьба об отзыве/реферале).

## Планка качества (сильная CJM vs слабая)
- ✅ эмоция с лейблом по каждому шагу; ❌ просто «нейтрально».
- ✅ одна чёткая точка перелома; ❌ «важно на всех шагах».
- ✅ лид-магнит + канал + альтернатива на сегмент; ❌ «продвигать в соцсетях».
- ✅ места поиска — конкретные инстансы по таксономии (паблик «X», чат «Y», блогер «Z», салон «W»); ❌ «искать в интернете».
- ✅ green/red конфликты явно; ❌ один план на всех.
- ✅ 5 сквозных приоритетов; ❌ список без приоритета.
- ✅ барьеры со ссылкой на источник (конкурент/VoC); ❌ из головы.

## Как использовать результат
- барьеры шага → темы кейсов/контента, блоки лендинга, ответы скрипта ([diagnostic-sale](diagnostic-sale.md));
- точка перелома → туда доказательства + диагностическая продажа;
- лид-магниты/каналы → ТЗ на контент и распределение по каналам;
- 🔴 конфликты → раздельные пакеты и месседжи ([offer-packaging-design](offer-packaging-design.md));
- после-этап → удержание ([reactivation-old-base](reactivation-old-base.md)).
