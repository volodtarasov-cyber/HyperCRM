# Детейлинг: лидген на антигравийную пленку

**Статус:** pilot  
**Тип:** лидген + упаковка + обработка заявки  
**Где применяем:** Левша  
**Владелец:** Володя  
**Дата создания:** 2026-05-03  
**Последнее обновление:** 2026-05-03  

---

## Суть

Модуль для запуска управляемого потока заявок на антигравийную пленку:

```text
Яндекс Директ + Авито
→ оффер по пленке
→ расчет по фото в WhatsApp
→ консультация
→ запись
→ допродажа / повторный контакт
```

Это первый детейлинг-модуль, который должен стать шаблоном для других услуг: мойка, PDR, шумоизоляция, химчистка.

---

## Для кого

Идеальный клиент:

- детейлинг-центр с сильным исполнением;
- есть фото/видео работ;
- есть мастера и свободные слоты;
- средний чек услуги достаточно высокий;
- есть администратор / КД, который быстро отвечает;
- можно считать заявки и записи.

Не подходит:

- нет нормальных кейсов;
- нет возможности быстро рассчитать стоимость;
- заявки теряются в мессенджерах;
- нет ответственного за обработку.

---

## Какая боль

- пленка приносит большую выручку, но поток заявок не управляемый;
- нет понятного оффера;
- клиенту сложно сразу понять цену;
- заявки требуют консультации и follow-up;
- рекламные каналы раньше могли оцениваться по заявкам, а не по выручке.

---

## Оффер

Рабочая формулировка:

```text
Антигравийная защита кузова с расчетом по фото:
пришлите автомобиль и зоны оклейки — подготовим понятный расчет и варианты защиты.
```

---

## Связка

```text
1. Источник / канал: Яндекс Директ + Авито.
2. Точка входа: объявление / посадочная / карточка услуги.
3. Обработка заявки: WhatsApp, расчет по фото, уточнение зон оклейки.
4. CRM / учет: источник, авто, услуга, сумма расчета, следующий шаг.
5. Follow-up: если клиент получил расчет и не записался.
6. Отчетность: заявки, расчеты, записи, выручка, причина отказа.
7. Повторная продажа: мойка, керамика, бронь лобового, сезонные напоминания.
```

---

## Артефакты

Нужно собрать:

- кейсы по пленке;
- фото/видео до-после;
- FAQ;
- возражения;
- шаблон расчета по фото в WhatsApp;
- список зон оклейки;
- прайс-рамки;
- карта рекламных кампаний;
- карта Авито-объявлений;
- отчет по заявкам.

---

## Метрики

Минимальные:

- заявки;
- стоимость заявки;
- доля заявок с фото;
- количество расчетов;
- конверсия расчет → запись;
- выручка по записанным клиентам;
- причина отказа;
- срок ответа на заявку.

---

## Условия запуска

До запуска нужно:

- забрать доступы к рекламным кабинетам;
- выгрузить старые кампании и заявки;
- договориться о работе с подрядчиками;
- зафиксировать майский бюджет;
- собрать упаковку по пленке;
- назначить ответственного за обработку заявок.

---

## Риски

- не хватает фото/кейсов;
- подрядчики запускают канал без единой логики;
- заявки приходят, но обработка медленная;
- нет учета расчетов и записей;
- цена отпугивает без объяснения вариантов;
- свободные слоты не синхронизированы с рекламой.

---

## Первый запуск

Где запускаем:

```text
Левша, неделя 04.05-10.05.2026.
```

Что считаем успехом за 7-14 дней:

- каналы запущены;
- заявки видны по источникам;
- есть первые расчеты;
- понятно, где теряется клиент.

Что считаем успехом за 30 дней:

- есть стабильная стоимость заявки;
- видна конверсия заявка → расчет → запись;
- можно принять решение: масштабировать, править оффер или менять канал.
