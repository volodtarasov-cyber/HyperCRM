## Сегодня

> [!important] Главный фокус
> Замкнуть одну измеримую PPF-связку:
>
> `продукт → оффер → заявка → диагностика → расчёт → запись → оплата → возврат`

### Счёт Дня

- [ ] **1/3 — утверждён продукт:** Light / Optimal / Max имеют состав, цену, срок и маржу.
- [ ] **2/3 — собрана продажа:** понятны ответственный, SLA, диагностика, расчёт и follow-up.
- [ ] **3/3 — замкнуто измерение:** заявка попадает в Б24 с источником и событиями.

**Итог дня:** `0 / 3`

### 1. Продукт PPF

- [ ] Утвердить зоны в пакетах **Light / Optimal / Max**.
- [ ] Зафиксировать **Quantum Pro / Rocket** по каждому пакету.
- [ ] Получить вилки цен и сроки выполнения.
- [ ] Зафиксировать гарантию и исключения.
- [ ] Посчитать прямые затраты и валовую маржу.
- [ ] Оставить только те бонусы, которые команда реально исполнит.

> [!success] Готово, когда
> Есть одна утверждённая продуктовая матрица без открытых коммерческих вопросов.

### 2. Путь Продажи

- [ ] Назначить ответственного за квиз и расчёт по фото.
- [ ] Утвердить SLA первого ответа.
- [ ] Собрать шаблон расчёта по фото.
- [ ] Зафиксировать стандарт диагностики: **3 варианта защиты на руки**.
- [ ] Проверить статусы и обязательные поля в Б24.
- [ ] Зафиксировать причины отказа и следующий шаг по каждой заявке.
- [ ] Определить маршрут клиента после оклейки: **30 / 60 / 180 дней**.

> [!success] Готово, когда
> Любой сотрудник может провести клиента от обращения до оплаты по одному сценарию.

### 3. Лендинг И Измерение

- [ ] Подставить утверждённые цены.
- [ ] Убрать неподтверждённые обещания.
- [ ] Подключить формы к Б24.
- [ ] Поставить Метрику и события квиза.
- [ ] Зафиксировать схему номеров колл-трекинга.
- [ ] Заменить hero и минимум 3 кейса реальными материалами.

> [!success] Готово, когда
> Тестовая заявка проходит весь путь, имеет источник и видна ответственному.

## Главные Ограничения

1. **Продажи:** приёмщики слабо конвертируют обращения независимо от канала.
2. **Продукт:** нет окончательных цен, состава и экономики пакетов PPF.
3. **Атрибуция:** без колл-трекинга и дисциплины Б24 нельзя считать CAC по каналам.
4. **Доказательства:** недостаточно реальных PPF-кейсов и фото для дорогого чека.
5. **Удержание:** 51 из 64 выпавших A-клиентов были плёночными, потеря — около 10,9 млн ₽.
