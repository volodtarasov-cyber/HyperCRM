# 🗂 Маркетинг Левши — карта папки

**Статус:** active — рабочая карта маркетингового слоя
**Владелец:** Володя

> Архитектура от 2026-06-25. Две оси: **сверху исследование → вниз продуктовые воронки**; **общее (research/content/channels/reputation) отдельно от продуктового (funnels/<продукт>)**.

## Слои

| Папка | Что внутри | Когда сюда |
|---|---|---|
| **research/** | рынок и бизнес ЦЕЛИКОМ: JTBD-сегменты, позиционирование, VoC, конкуренты, discovery, SOSTAC | понять, КАКИЕ воронки вообще делать |
| **funnels/** | по ПРОДУКТУ — своя воронка (film, shumka, polishing, …) | собрать путь под конкретный продукт/сегмент |
| **content/** | кросс-продуктовое производство: кейс-банк (фабрика), контент-план, видео-сценарии | материалы, общие для всех воронок |
| **channels/** | площадки как инфраструктура: карты (Я/2ГИС), Я.Бизнес, VK, SEO-сайт, колл-трекинг | настройка канала, не привязанная к одному продукту |
| **reputation/** | NPS, отзывы, логи репутации | работа с репутацией и отзывами |
| `ad-budget.md` | рекламный бюджет | — |

## Поток

```
research/  (сегменты, CJM, позиционирование — поняли рынок и кому продаём)
   → выбрали продукт/сегмент
   → funnels/<продукт>/  (собрали воронку: исследование продукта → оффер → крео → лендинг → скрипты → задачи)
   ↑ кормится из content/ (кейсы), channels/ (площадки), reputation/ (доверие)
```

## Стандарт продуктовой воронки (одинаковый у всех)

Каждая папка в `funnels/` стремится к этой структуре — открыл любую, всё на тех же местах:

```
funnels/<продукт>/
├── _dashboard.md          ← стадия воронки на один экран
├── _index.md              ← карта папки
├── research/              ← CJM + сегмент + диагностика ЭТОГО продукта
├── offer/                 ← офферы, пакеты, цены
├── creatives/             ← крео, инфографика, видео
├── landing/               ← лендинг: копи + код
├── scripts/               ← продуктовые скрипты (кросс-продуктовые — в ../../sales/)
└── yougile-task-export.md ← задачи на сборку
```

**Эталон — `funnels/film/`** (PPF, сегмент «новая машина»). По нему причёсываем shumka, polishing и новые.

## Связь с уровнем проекта

Корень `detailing-samara/` = **организация** (скрининг, дашборд, гипотезы, competitors, client-intelligence). `marketing/` = работа над привлечением и продажей. Кросс-продуктовые продажные скрипты и регламенты — в `../sales/`.
