# Промпт для заполнения Google Sheet — конкурентный анализ Левши

> Назначение: отдать AI-агенту или ресерчеру для заполнения таблицы `Левша Рабочий документ`.
> Zoon не считается достоверным источником: только слабый вторичный сигнал, без зелёной маркировки.

## Цветовая кодировка

- **Зелёный `#D9EAD3`** — факт подтверждён сильным источником: сайт компании, Яндекс.Карты, 2ГИС, Google Maps, VK, официальный прайс.
- **Жёлтый `#FFF2CC`** — данные неполные, косвенные, экспертная оценка, вывод из нескольких признаков, вторичный каталог или Zoon.
- **Красный `#F4CCCC`** — данные не найдены, противоречат друг другу, устарели, требуют ручной проверки.

К важной фактической ячейке по возможности добавлять примечание:

```text
Источник: [URL]. Проверено: 2026-05-14.
```

## Готовый промпт

```text
Ты — ресерчер по digital-конкурентам для премиум-детейлинга в Самаре.

Нужно заполнить Google Sheet:
https://docs.google.com/spreadsheets/d/1SXKL13eQ7aGTFr8wDqCveeT_1Pir3uURp2Fvm3pftI0/edit

Контекст проекта:
- Клиент: детейлинг-центр «Левша», Самара.
- Сегмент: премиум / сильный акцент на антигравийную плёнку, мойку, полировку, химчистку, PDR, шумоизоляцию.
- Цель таблицы: понять, как конкуренты упакованы в digital, где Левша сильнее/слабее, что можно забрать в сайт, карты, Авито, Я.Директ и контент.

Работай с листами:
1. `Анализ конкурентов`
2. `Ключи запросы`

Главный лист — `Анализ конкурентов`.

Конкуренты в строке 5:
- goodzone
- youco
- автолюкс
- Манго
- Арт Гараж
- Синдикат
- Панамера Детейлинг
- Автокачество163
- Ай график
- Автопротект
- Конкурент 1-4 — использовать под сильные референсы/конкурентов по плёнке, если найдёшь более релевантных.

Заполни по каждому конкуренту строки:
- сайт;
- VK;
- Instagram, если доступен/актуален;
- Яндекс.Карты;
- Google Maps;
- 2ГИС;
- качество заполнения страниц 1-10;
- что понравилось и можно забрать;
- услуги: мойка, детейлинг-мойка, химчистка, антигравийная плёнка, полировка, PDR, шумоизоляция;
- УТП;
- качество упаковки;
- смыслы в дизайне;
- ценовая политика;
- цены / ссылка на прайс;
- акции;
- оффер;
- CTA;
- отзывы и средняя оценка по Яндекс / Google / 2ГИС / Яндекс Услуги;
- Zoon заполняй только если уже есть в таблице как отдельная строка, но не используй как достоверный источник;
- что отмечают положительного;
- что отмечают отрицательного;
- сильные и слабые стороны;
- какое конкурентное преимущество беспокоит Левшу;
- чем Левша лучше;
- наличие калькулятора;
- наличие блога;
- кнопки соцсетей;
- мессенджеры;
- варианты оплаты;
- программа лояльности;
- юрлицо, если публично видно;
- телефон;
- данные обзвона заполняй только если реально был звонок. Если звонка не было — ставь “не проверено”.

Правила достоверности:
1. Не придумывай данные.
2. Если факт найден на официальном сайте, карточке Яндекс.Карт, 2ГИС, Google Maps, VK или официальном прайсе — заполняй и крась ячейку зелёным `#D9EAD3`.
3. Zoon не является достоверным источником. Если используешь его как вспомогательный сигнал, ячейку красить не зелёным, а жёлтым `#FFF2CC`, и писать в примечании: `Источник слабый: Zoon`.
4. Если данные косвенные, неполные, взяты из вторичного каталога или являются твоей экспертной оценкой — крась жёлтым `#FFF2CC`.
5. Если данные не найдены, противоречат друг другу или требуют ручной проверки — пиши `не найдено` / `требует проверки` и крась красным `#F4CCCC`.
6. Для экспертных строк вроде “качество упаковки”, “смыслы в дизайне”, “сильные/слабые стороны” используй жёлтый, даже если вывод хороший.
7. Важные фактические ячейки снабжай примечанием: `Источник: [URL]. Проверено: 2026-05-14`.

Приоритет источников:
1. официальный сайт конкурента;
2. Яндекс.Карты;
3. 2ГИС;
4. Google Maps;
5. VK / соцсети;
6. Яндекс Услуги;
7. каталоги и агрегаторы — только если нет сильнее источника;
8. Zoon — только как слабый вторичный сигнал, не для зелёных ячеек.

Особое внимание:
- GoodZone — реальный лидер по соцдоказательству, изучить глубже.
- Youco — важен из-за филиала рядом с Левшой.
- i-Graphics / Ай график и Автопротект — важны именно по плёнке, даже если не всплывают как общий детейлинг.
- Не смешивай автомойки низкого сегмента и детейлинг-премиум без пометки.
- Для “Конкурент 1-4” можно добавить сильные плёночные референсы из Самары или global-рынка, но обязательно подписать, почему они добавлены.

Лист `Ключи запросы`:
- Не удаляй текущую структуру.
- Расширь семантику по направлениям:
  - детейлинг;
  - оклейка плёнкой / PPF / антигравийная плёнка;
  - мойка / детейлинг-мойка;
  - полировка;
  - PDR / удаление вмятин;
  - ремонт стекла / сколы;
  - шумоизоляция;
  - тонировка.
- Добавляй только запросы, которые реально похожи на поисковые формулировки клиента.
- Если источник семантики — Яндекс Wordstat/подсказки/выдача, пометь это в примечании.

Финальный результат:
- Таблица заполнена по всем конкурентам, где данные публично доступны.
- Неполные и сомнительные ячейки визуально выделены.
- По каждой ключевой оценке понятно, это факт, экспертный вывод или требует проверки.
- Zoon нигде не используется как основание для зелёной ячейки.
- В конце работы дай краткий текстовый вывод:
  1. кто 3 главных конкурента;
  2. где Левша проигрывает;
  3. что можно быстро забрать себе;
  4. какие данные требуют ручной проверки/обзвона.
```

## Проверка результата

- Ни одна ячейка со ссылкой на Zoon не должна быть зелёной.
- Зелёные ячейки должны подтверждаться сайтом, картами, VK или официальным прайсом.
- Экспертные выводы не должны выглядеть как факты.
- Строки обзвона не должны быть заполнены без реального звонка.
