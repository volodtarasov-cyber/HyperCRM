# Первая воронка PPF — тёплая база → тёплое ядро (пилот)

> **Логика старта:** 90% плёнки идёт из тёплой базы, не с холодного трафика. Значит первая воронка — **реклама на всю базу (ретаргет) + lookalike**, а не холодная вершина и не ручной обзвон.
> **Почему вся база, а не узкие когорты:** узкие поведенческие когорты (спящие мойковщики, тонировщики) **слишком малы, чтобы накрыть таргетом** — рекламные кабинеты их не вытянут. **Почему реклама, а не ручные касания:** ручной обзвон/рассылка по базе сейчас и долго, и **юридически рискованно** (152-ФЗ / рекламный закон — нужно актуальное согласие). Реклама на custom audience через площадку — комплаентный и быстрый путь.

## Аудитория = вся база + lookalike (реклама)
- **Custom audience:** вся база контактов (телефоны/почты) → загрузить в **VK Ads** + **Яндекс Аудитории** для ретаргета. База в несколько тысяч контактов — рабочий размер.
- **Lookalike:** сид — **прошлые плёночные клиенты (690)**, не вся база (качество выше) → расширение на похожих в Самаре.
- **Path-to-film — это интеллект для ОФФЕРА/КРЕО, не для таргетинга** (узко не настроить, но знание используем):
  - комбо-стандарт «плёнка + полировка-подготовка + уход» — в крео;
  - тонировка → «полная защита» (стёкла+кузов) — отдельный креатив-угол;
  - сезонность дозревания (~4,5 мес, лето/реагенты) — тайминг кампаний;
  - ❌ не делать креативы под полировку/шумку/ПДР как вход в плёнку (3-9%).

> **Открытый вопрос (не блокер):** твоё «90% постоянники» vs данные «66,8% берут плёнку в первый визит (прямой запрос)». Свериться на пилоте — метка источника в трекере (ретаргет-базы / lookalike / прямой Директ).

## Воронка целиком (пилот)

```
АУДИТОРИЯ                ОХВАТ (реклама)        ТЁПЛОЕ ЯДРО (inbound)        КОМПАУНД
вся база (custom aud) →  VK Ads ретаргет   →   квиз/лендинг «3 варианта»  →  post-care 30/60/180
lookalike на плёнку-690   + Яндекс + lookalike   → фото-расчёт → диагностика →  реферал (клуб/сарафан)
                          крео: зоны/комбо/      40 мин 🎯 → решение
                          анти-якорь
```

Реклама греет коробкой (зоны/кейсы/«как работаем») → клиент сам приходит на квиз/расчёт → тёплое ядро добивает.

## 1. Аудитория — как собрать
1. Выгрузить из CRM/1С **все контакты базы** (телефоны/почты, без узкой фильтрации).
2. Загрузить как **custom audience** в VK Ads + Яндекс Аудитории.
3. Отдельно собрать **сид lookalike — клиенты с плёнкой (690)** → построить похожих.
4. Сегментация — на уровне **креатива/оффера** (комбо, тонировка-угол, сезон), не таргетинга.
5. Источник лида помечать в [трекере](first-funnel-tracker-template.csv): ретаргет-базы / lookalike / прямой Директ.

## 2. Охват — реклама/таргет (ручные касания сняты)
**Каналы:** VK Ads (ретаргет базы + lookalike), Яндекс Директ (прямой запрос плёнка/оклейка + ретаргет). Бюджет 80% на плёнку через прямой запрос — подтверждено path-to-film.

**Крео = крючки коробки** (не «у нас акция»):
- «Карта зон риска для вашей [тип авто] — где летят сколы» → квиз;
- «Плёнка vs подкрас за 4 года» (анти-якорь, [creo-paint-vs-film](creo-paint-vs-film.md));
- «Как мы принимаем машину» (доверие, процесс);
- комбо «плёнка + полировка-подготовка» как стандарт.

**Посадка:** квиз/лендинг «получите 3 варианта по фото» (низкострессовый вход, [offer-master](offer-master.md)) → лид падает в тёплое ядро.

> Ручной обзвон базы — **не используем** (долго + юр-риск). Если точечно (живой контакт на приёмке/партнёр) — по [скрипту](../../../sales/film-photo-calc-script-base-2026-06-26.md), но это не основной механизм.

## 3. Коробка шока → прогрев
Отправляем по реакции, не одним пакетом. Состав и порядок → [shock-awe-box-newcar-2026-06-26](shock-awe-box-newcar-2026-06-26.md). Ядро: карта зон риска по модели + 2-3 кейса похожей машины + паспорт защиты + FAQ + Pro/Rocket + смета «3 варианта».

## 4. Тёплое ядро — конверсия (шаги 5→7 CJM)
Лиды приходят **inbound** с рекламы (квиз/заявка/звонок) — не холодные, уже видели коробку в крео.
- **Обработка входящего** → [inbound-скрипт диагностической продажи](../../../sales/film-diagnostic-sale-script.md) (основной) + коробка на дожим.
- **Фото-расчёт** «3 варианта по фото» + **диагностика 40 мин** «3 варианта на руки» → [скрипт](../../../sales/film-photo-calc-script-base-2026-06-26.md).
- **Комбо-стандарт** (из path-to-film): плёнка + полировка-подготовка + уход; тонировка → «полная защита» (стёкла+кузов).
- Приёмщик доводит по лесенке касаний (анти-слив), статусы — в трекер.

## 5. Post-care + реферал — компаунд
- Постплёночный маршрут 30/60/180 → [post-film-care-pilot-plan](../../../sales/post-film-care-pilot-plan.md) (HYP-009), вести в трекере.
- Отзыв/кейс на выдаче (пик эмоции) → топливо кейс-банка + посев в сетях клиента.
- **Реферальный оффер** → referral-offer-2026-06-26.

## 6. Метрики пилота (в трекере)
- воронка рекламы: показ → клик → квиз/заявка → расчёт → диагностика → продажа → чек;
- **CPL и конверсия по источнику** (ретаргет-базы / lookalike / прямой Директ) — закрыть открытый вопрос про «90%» и понять, что дешевле;
- средний чек комбо vs изолированная плёнка;
- post-care: 30/60/180 визиты, отзыв, реферал.
