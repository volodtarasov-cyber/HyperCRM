# Авито-воронка на антигравийную плёнку

## Коротко

На Авито не нужна буквальная копия трёхстраничной агентской воронки. Её функции распределяются так:

| Модель из видео | Реализация в Авито Левши |
|---|---|
| Реклама | Продвижение объявления + обложка |
| Первая страница | Карточка объявления: заголовок, галерея, описание, отзывы |
| Страница записи | Авито-чат: квалификация, фото, расчёт, выбор времени |
| Страница подтверждения | Сообщение с датой, адресом, подготовкой и напоминанием |
| Backend | Битрикс24, SLA, дожим, no-show recovery, post-care |

Полный маршрут:

```text
Показ объявления
→ открытие карточки
→ обращение в Авито-чат / звонок
→ марка, модель, сценарий
→ 2-3 фото
→ расчёт Light / Optimal / Max
→ бесплатная диагностика
→ подтверждение визита
→ приезд
→ продажа
→ контроль 30 / 60 / 180 дней
→ отзыв и повтор
```

Главное изменение относительно обычного объявления:

> Не продавать «оклейку плёнкой» с первой фразы. Продавать понятный выбор защиты под конкретную машину.

## 1. Позиционирование

### Who

Не все владельцы автомобилей одновременно. Для каждого объявления нужен один основной сценарий:

1. Новая машина, которую хотят защитить до первых сколов.
2. Частые поездки по трассе.
3. Клиент выбирает между фарами, front body и full body.
4. Владелец дорогой или любимой машины, которому важны заводское ЛКП и ответственность студии.
5. Клиент уже сравнивает цены и боится переплатить.

### What

Клиент покупает не плёнку как материал, а:

- сохранение заводского ЛКП;
- защиту зон удара;
- спокойствие за машину;
- понятный выбор без лишней оклейки;
- предсказуемый процесс с фиксацией и гарантией.

### How

Отличающий механизм Левши:

1. Клиент присылает модель и фото.
2. Левша рассчитывает три уровня защиты.
3. Объясняет, какие зоны нужны именно в его сценарии.
4. На диагностике фиксирует состояние машины и точную смету.
5. После работы выдаёт документы и запускает контрольный маршрут.

Рабочая формулировка:

> Подберём три варианта защиты кузова по фото: минимальный, оптимальный и полный. Покажем, какие зоны стоит закрыть на вашей машине и где можно не переплачивать.

## 2. Straight Sell внутри карточки Авито

Формула из исходного видео:

```text
Hook → Problem → Solution → Proof → Offer
```

На Авито она раскладывается по карточке.

### Hook: обложка и заголовок

Базовый вариант:

> Антигравийная плёнка авто — 3 варианта защиты

Подзаголовок на обложке:

> От зон риска до всего кузова

Три тестовых угла:

| Вариант | Заголовок / обложка | Для кого |
|---|---|---|
| A. Прямой продукт | Антигравийная плёнка Quantum — защита кузова | Уже ищет PPF |
| B. Выбор | Full body или только передняя часть? Посчитаем 3 варианта | Не понимает объём |
| C. Доверие | Плёнка с гарантией 5-7 лет · 751 оценка 5,0 | Сравнивает студии |

Не смешивать все три сообщения на одной обложке.

### Problem: кадры 2-3

Показывать не абстрактный страх, а реальную ситуацию:

- сколы на капоте и фарах;
- пескоструй после трассы;
- новая машина до первой поездки;
- сравнение защищённой и незащищённой зоны;
- конкретный кейс похожей машины.

Не использовать без подтверждённого источника:

- «5-7 сколов за первый год»;
- «минус 30-80 тысяч при продаже»;
- любые универсальные обещания роста стоимости машины.

### Solution: кадры 3-5

Показать:

- Light — зоны максимального удара;
- Optimal — передняя часть;
- Max — весь кузов;
- Quantum Pro — гарантия 7 лет;
- Quantum Rocket — гарантия 5 лет;
- диагностика и точная смета до работы.

Не выводить клиенту сразу матрицу из шести комбинаций `3 пакета × 2 материала`. Сначала подобрать зоны и рекомендовать один материал. Rocket предлагать как честную альтернативу, если клиенту важна экономия.

### Proof: кадры 5-8

Минимальный набор:

1. Один кейс похожего автомобиля.
2. Реальный процесс подготовки и подворотов.
3. Фотофиксация исходного состояния, если процесс уже реально внедрён.
4. Гарантия 5-7 лет по выбранному материалу.
5. Паспорт защиты, если он уже выдаётся клиенту.
6. 751 оценка и рейтинг 5,0 по зафиксированному замеру Яндекс Карт.
7. Фото студии, освещения и охраняемой территории.

Правило:

> Обещать в объявлении только то, что клиент гарантированно получит в текущем процессе.

### Offer: последний кадр и начало описания

Главный CTA:

> Напишите в Авито-чат марку, модель и год машины. Пришлите 2-3 фото — подготовим варианты защиты и поясним, где можно не переплачивать.

Не уводить первый контакт из Авито в Telegram. Это создаёт дополнительное трение и ломает атрибуцию.

## 3. Структура описания объявления

### Первые 4-6 строк

```text
Не знаете, закрывать только фары и капот, всю переднюю часть
или весь кузов?

Напишите марку, модель и год автомобиля в Авито-чат.
По 2-3 фото подготовим варианты защиты и дадим ориентир
по цене и срокам.
```

### Далее

```text
Что получите:

— Light: зоны максимального удара
— Optimal: защита передней части
— Max: полный кузов
— Quantum Pro с гарантией 7 лет
— Quantum Rocket с гарантией 5 лет
— точная смета после бесплатной диагностики

Почему Левша:

— работаем в Самаре больше 10 лет
— 751 оценка 5,0 на Яндекс Картах по замеру 25.05.2026
— фиксируем состояние машины до работы
— показываем материал и состав работ
— условия гарантии закрепляем в документах

Чтобы получить расчёт:

1. Напишите марку, модель и год.
2. Пришлите общий вид машины и переднюю часть крупно.
3. Укажите, где чаще ездите: город или трасса.

Ответим в рабочее время до 30 минут.
```

Перед публикацией проверить фактическое внедрение фотофиксации, паспорта защиты и документов. Если процесс ещё не закреплён, не выносить его как гарантированное обещание.

## 4. Первый контакт в Авито-чате

### Цель

Не продать услугу в первом сообщении, а получить данные для полезного ответа.

### Операционная норма

- внутренний ориентир первого ответа: 5-10 минут;
- обязательный SLA: до 30 минут;
- после получения фото: дать реакцию сразу и назвать точное время расчёта;
- если нужен мастер: не исчезать, а написать срок возврата.

### Первое сообщение

```text
Здравствуйте! [Имя], Левша.

Подскажите, пожалуйста:
1. Какая машина — марка, модель и год?
2. Что хотите защитить или где уже появились сколы?

Если удобно, пришлите 2-3 фото: общий вид и переднюю часть крупно.
По ним подготовим варианты защиты и ориентир по цене.
```

Не задавать сразу пять вопросов. Сценарий езды и срок покупки уточнить следующим сообщением после ответа клиента.

### Второй шаг

```text
Спасибо, вижу задачу.

Подскажите ещё два момента:
— машина чаще ездит по городу или по трассе?
— защиту хотите сделать в ближайшее время или пока сравниваете?
```

### После получения фото

```text
Фото получил. Подключу мастера и вернусь с вариантами
до [точное время].

Покажем минимум, оптимальный вариант и полную защиту,
чтобы было видно разницу по зонам, цене и срокам.
```

Телефон запрашивать:

- когда клиент готов записаться;
- когда по фото нужен быстрый разговор с мастером;
- когда клиент сам выбирает звонок;
- если нужно подтвердить визит.

Не делать телефон обязательной платой за предварительную полезность.

## 5. Расчёт как продукт

Расчёт должен быть единым шаблоном, а не свободным текстом каждого приёмщика.

### Формат ответа

| Вариант | Что закрываем | Кому подходит | Материал | Ориентир | Срок |
|---|---|---|---|---:|---|
| Light | Конкретные зоны | Город / ограниченный бюджет | Рекомендованный | от-до | X |
| Optimal | Передняя часть | Трасса / активная эксплуатация | Рекомендованный | от-до | X |
| Max | Весь кузов | Новая дорогая машина / 3-4+ года владения | Рекомендованный | от-до | X |

После таблицы дать один экспертный вывод:

```text
Для вашей машины и режима езды я бы начал с Optimal:
он закрывает основные зоны удара без стоимости полной оклейки.

Точную смету дадим после осмотра кузова. Диагностика бесплатная,
занимает около 40 минут. Есть окно [дата/время] или [дата/время].
Что удобнее?
```

Ключевое правило:

> Три варианта не означают отсутствие рекомендации. Менеджер должен назвать лучший вариант под вводные клиента.

## 6. Proof-пакет в чате

Не отправлять человеку десять файлов подряд. Дать 2-3 релевантных материала:

1. Один похожий кейс по марке или сценарию.
2. Карта зон риска или сравнение пакетов.
3. Гарантия / процесс / фото студии по главному страху клиента.

Пример:

```text
Чтобы было проще сравнить, отправлю:
— похожий кейс [модель автомобиля];
— схему зон, которые входят в Optimal;
— короткое объяснение гарантии.

После этого можно выбрать предварительный вариант или приехать
на бесплатную диагностику за точной сметой.
```

## 7. Запись на диагностику

Не спрашивать открыто: «Когда вам удобно?»

Предлагать два конкретных окна:

```text
Диагностика занимает около 40 минут. Осмотрим кузов,
зафиксируем состояние и дадим точную смету на руки.

Есть окно завтра в 11:00 или в четверг в 18:30.
Какое закрепить?
```

### Подтверждение

```text
Записал вас на [дата] в [время].

Адрес: Самара, Ново-Садовая, 162В.
[ссылка на навигатор]

На месте:
— осмотрим кузов;
— покажем зоны риска;
— сравним варианты;
— дадим точную смету.

Решение о работе можно принять после осмотра.
За день и за 2 часа напомним о записи.
```

Это аналог третьей страницы исходной воронки.

## 8. Follow-up

### Не прислал фото

Через 2 часа:

```text
Если сейчас неудобно фотографировать, можно приехать
на быстрый осмотр. Сегодня мастер на месте до [время].
```

На следующий день:

```text
Здравствуйте! Вопрос по защите машины ещё актуален?
Можно прислать фото сюда или записаться на бесплатную диагностику.
```

Через 3 дня:

```text
Если вопрос пока отложили или уже выбрали другой вариант —
нормально, дайте знать. Если остались сомнения по зонам или цене,
могу коротко сравнить варианты.
```

### Получил расчёт, но не записался

```text
По вариантам остались вопросы?

По вашим вводным я бы рекомендовал [пакет], потому что [причина].
Чтобы зафиксировать точную цену, можно посмотреть машину
[два конкретных окна].
```

### Не приехал

```text
Здравствуйте! Сегодня не получилось приехать — всё в порядке?
Если вопрос актуален, перенесу диагностику.
Есть [два новых окна].
```

Не более трёх ручных дожимов за неделю. Далее закрыть с причиной и поставить в подходящий nurture / реактивацию.

## 9. Битрикс24 и атрибуция

### Источник

- чат Авито передаётся через нативный коннектор;
- звонок идёт на отдельный статический номер Авито;
- объявление / направление сохраняется в карточке;
- источник не перезаписывается как «прямой».

### Стадии

```text
Новый Авито
→ Ответили
→ Запрошены фото
→ Фото получены
→ Расчёт отправлен
→ Диагностика предложена
→ Диагностика назначена
→ Диагностика проведена
→ Смета выдана
→ Запись на услугу
→ Оплачено
```

Финалы потерь:

- не отвечает;
- не прислал фото;
- отказ по цене;
- выбрал конкурента;
- отложил;
- не доехал;
- нецелевой;
- дубль.

### Обязательные поля

- объявление / угол;
- марка, модель, год;
- зона интереса;
- город / трасса;
- срочность;
- фото получены;
- рекомендованный пакет;
- ориентир;
- следующий шаг;
- дата следующего касания;
- причина потери;
- сумма оплаты;
- пакет и материал.

## 10. Метрики

### Верх карточки

- показы;
- открытия;
- CTR обложки;
- обращения;
- конверсия открытия в обращение;
- стоимость обращения.

### Качество

- квалифицированные обращения;
- доля клиентов с маркой / моделью;
- доля приславших фото;
- стоимость квалифицированного обращения.

### Продажи

- расчёты отправлены;
- диагностики назначены;
- show-up;
- продажи;
- выручка;
- средний чек;
- валовая прибыль, когда появится P&L;
- CAC;
- доля Light / Optimal / Max;
- доля Pro / Rocket.

### Скорость и дисциплина

- ответ в SLA;
- расчёт в обещанное время;
- лиды без следующего шага;
- follow-up выполнен;
- пропущенные звонки;
- перезвон по пропущенным.

Временные операционные ориентиры:

| Метрика | Ориентир |
|---|---:|
| Ответ в SLA | 95%+ |
| Следующий шаг после обращения | 60%+ |
| Расчёт отправлен в обещанный срок | 90%+ |
| Диагностика → продажа | 50%+ |

Это стартовые цели из текущего регламента, а не доказанные нормативы Авито. После 30 дней заменить их фактической базовой линией.

## 11. Тест на 14 дней

### Что тестируем

Три карточки или три допустимых варианта упаковки с одинаковым процессом обработки:

| Вариант | Основной смысл |
|---|---|
| A | Прямой продукт: антигравийная плёнка Quantum |
| B | Выбор: три варианта без лишней оклейки |
| C | Доверие: гарантия + рейтинг + ответственность |

Если правила Авито или структура аккаунта не позволяют параллельные карточки, менять только обложку и первые строки последовательными периодами при сопоставимом бюджете.

### Что не менять внутри теста

- скорость ответа;
- скрипт;
- шаблон расчёта;
- доступные окна;
- бюджет на один вариант;
- географию;
- правила квалификации.

Иначе нельзя понять, сработало объявление или изменение обработки.

### Решение после теста

Не выбирать победителя только по CTR или дешёвым обращениям.

Главная таблица:

| Вариант | Расход | Обращения | Квал. | Фото | Диагностики | Продажи | Выручка | CAC |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| A | | | | | | | | |
| B | | | | | | | | |
| C | | | | | | | | |

Победитель — вариант с лучшей экономикой продажи при достаточном объёме, а не с самым дешёвым чатом.

## 12. После продажи

Авито-воронка не заканчивается оплатой:

```text
Выдача
→ NPS
→ отзыв после подтверждённого качества
→ контроль плёнки через 30 дней
→ касание через 60 дней
→ сезонный осмотр через 180 дней
→ уход, мойка, новые зоны, повтор
```

Для клиента из Авито источник первого привлечения сохраняется навсегда. Это позволит через 6-12 месяцев посчитать не только первую продажу, но и выручку когорты Авито.

## 13. Что уже готово

- оффер трёх вариантов;
- инфографика;
- варианты обложек;
- компактный Авито-скрипт;
- общий регламент первого касания;
- поля марка / модель в Битрикс24;
- карта статического номера Авито;
- бюджет на продвижение;
- базовый лендинг как дополнительный proof.

## 14. Что блокирует запуск цельной системы

1. Не подтверждена нативная интеграция Авито → Битрикс24.
2. Нет единого шаблона расчёта Light / Optimal / Max с актуальными ценами.
3. Не закреплён ответственный за расчёт и срок возврата.
4. Не все обещания инфографики подтверждены рабочим процессом.
5. Мало продуктовых PPF-кейсов по конкретным машинам.
6. Нет первой полной таблицы `расход → обращение → продажа → выручка`.
7. Не запущен обязательный post-care 30 / 60 / 180.

## 15. Минимальный запуск

## Главный вывод

Исходная воронка применима к Авито не как набор отдельных страниц, а как последовательность обязательств:

```text
Объявление обещает выбор
→ чат быстро собирает минимум данных
→ расчёт даёт реальную пользу
→ proof снимает конкретный страх
→ диагностика становится логичным следующим шагом
→ CRM не даёт потерять клиента
→ post-care превращает разовую покупку в LTV
```

Слабое место Левши сейчас находится не в отсутствии элементов. Элементы уже созданы. Риск — в разрыве между объявлением, ответом приёмщика, расчётом, фиксацией в Битрикс24 и последующим контролем.
