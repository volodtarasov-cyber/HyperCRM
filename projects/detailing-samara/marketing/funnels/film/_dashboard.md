## Целевая Связка

**Новый авто → квалификация → расчёт 3 вариантов → прогрев кейсами → диагностика → бронь → выдача → post-care.**

Что хотим получить на выходе: первую рабочую воронку Левши, где понятны сегмент, оффер, первый шаг, продажа, доказательства, метрики и следующий контакт после выдачи.

## Стадии Воронки

| Стадия | Сейчас | Что должно быть идеально |
|---|---|---|
| 1. Сегмент | Выбран: «только купил авто» | Один сегмент зафиксирован, не смешиваем с общей PPF-аудиторией |
| 2. JTBD / ЦА / CJM | Есть рабочие mind maps | Карты проверены звонками, интервью и CRM-данными |
| 3. Данные | Главный пробел | В CRM видно: новый авто, дата покупки, источник, пакет, отказ, следующий шаг |
| 4. Оффер | Мастер-оффер есть, но не доказан | Light / Optimal / Max подтверждены заказами, маржой и цехом |
| 5. Продажа | Есть общие скрипты и техника Виктора | Есть единый скрипт диагностики именно для нового авто |
| 6. Доверие | Есть гипотезы | Есть паспорт PPF-работ, гарантийные формулировки, фотофиксация, кейсы новых авто |
| 7. Прогрев | HYP-010 собрана как логика | Кейсы и касания встроены до визита к приёмщику |
| 8. Post-care | Есть план, не внедрён как обязательный путь | Каждый PPF-клиент получает контроль 7 / 30 дней и повод вернуться |
| 9. Измерение | Не собрано в одну панель | Видны конверсии: заявка → расчёт → диагностика → бронь → оплата → выдача → post-care |

## Главные Блокеры

1. Нет чистой разметки «новый авто» в CRM / заявках.
2. Нет доказанного соответствия пакетов Light / Optimal / Max реальным заказам и марже.
3. Нет обязательного доверительного стандарта PPF: фотофиксация, паспорт работ, гарантия, контроль качества.
4. Нет набора кейсов именно под новые авто.
5. CJM описан, но ещё не превращён в измеримую воронку.

## Что Забираем В YouGile

Рабочий список задач лежит здесь: [yougile-task-export.md](yougile-task-export.md).

Минимальный первый пакет для постановки:

- CRM-поля и ручная разметка 30 свежих PPF-заявок.
- Разбор 10 продаж и 10 отказов.
- Шаблон расчёта по фото.
- Чек-лист приёмки нового авто.
- 3 кейса новых авто.
- Follow-up после расчёта и post-care после выдачи.
