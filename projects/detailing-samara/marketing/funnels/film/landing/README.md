# Лендинг «Антигравийная плёнка Quantum · Левша»

MVP-версия, чистый HTML/CSS/JS без фреймворков. Открывается двойным кликом.

**Статус:** черновик к согласованию.
**Дата:** 2026-05-29.
**Референсы стилистики:** [smd-smolensk.ru](https://smd-smolensk.ru/), [fomichevd.com/kitchline](https://fomichevd.com/kitchline/).

---

## Как посмотреть

1. Открыть `index.html` двойным кликом в Finder — откроется в браузере.
2. Или из терминала: `open index.html` (macOS).
3. Для проверки мобильной адаптации — DevTools → Toggle device toolbar (Cmd+Shift+M в Chrome).

---

## Структура

- `index.html` — вся разметка (10 секций).
- `style.css` — стили, тёмная палитра + акцент-зелёный, mobile-first.
- `script.js` — квиз, бургер-меню, плавная прокрутка, отправка форм (заглушка в консоль).
- `assets/` — папка под реальные фото (пока пустая).

---

## 10 блоков MVP (сверху вниз)

1. **Header (sticky)** — лого, навигация, телефон, CTA «Посчитать», бургер на мобильном.
2. **Hero** — оффер, 3 буллита, 2 CTA, доверительные знаки (751 оценка, награда, №1).
3. **3 USP** — фотофиксация / паспорт защиты / гарантия 5–7 лет.
4. **Портфолио (4 работы)** — машины клиентов, плейсхолдеры под фото.
5. **Квиз-калькулятор (5 шагов)** — марка → зона → линейка → бюджет → контакты.
6. **Процесс работы (5 шагов)** — приёмка с фото → подготовка → поклейка → контроль → выдача.
7. **Quantum Pro vs Rocket** — сравнение двух линеек, цены за зоны риска и полную оклейку.
8. **Пакеты Light / Optimal / Max** — цены с подсветкой среднего пакета.
9. **Экскурсия по студии** — приглашение приехать без обязательств, посмотреть бокс, образцы плёнки, паспорта защиты. Снимает страх «впарят».
10. **Отзывы (3 цитаты)** — с Яндекс.Карт и 2ГИС.
11. **FAQ + финальный CTA + footer** — 8 вопросов, форма «пришлите фото», адрес/контакты.

## ❗ Что подменить перед публикацией

### Цены — `{{...}}` маркеры в `index.html`

Эти значения должен дать Андрей (собственник Левши):

- `{{ЦЕНА_PRO_ZONA}}` — Quantum Pro за зоны риска, ₽
- `{{ЦЕНА_PRO_FULL}}` — Quantum Pro за полную оклейку, ₽
- `{{ЦЕНА_ROCKET_ZONA}}` — Quantum Rocket за зоны риска, ₽
- `{{ЦЕНА_ROCKET_FULL}}` — Quantum Rocket за полную оклейку, ₽
- `{{ЦЕНА_LIGHT}}` — пакет Light, ₽
- `{{ЦЕНА_OPTIMAL}}` — пакет Optimal, ₽
- `{{ЦЕНА_MAX}}` — пакет Max, ₽
- `{{РАССРОЧКА_БЛОК}}` — есть ли партнёр-банк, % переплаты, срок

Поиск в любом редакторе: `Cmd+F → {{`.

### Индикатор активности в hero

Над кнопками «Рассчитайте стоимость» — плашка `🟢 Сегодня расчёт уже получили 4 человека` с пульсирующей точкой. Это динамический соцпруф.

Цифру (`4 человека`) можно дёргать вручную в HTML или сделать счётчик через GA / Б24. Пока — захардкожена.

### 360°-обзор (горизонтальный интерактив)

Между «Наши работы» и калькулятором — секция «Покрутите машину сами». Большой viewer 16:9, в котором клиент сам крутит машину мышкой или пальцем. Пока фото не залиты — показывается стилизованный плейсхолдер с авто-крутящимся 🌀 и инструкцией.

**Как залить машину:**
1. Снять **36 фото с равными углами** вокруг машины (через каждые 10°). Помогает приложение Snap360, iSpin или Cappasity — они подсказывают угол через гироскоп.
2. Положить файлы в `assets/spin360/01.jpg, 02.jpg … 36.jpg` (все одинакового размера, желательно 1920×1080).
3. JS-плеер сам обнаружит наличие первого кадра и заменит плейсхолдер на интерактив.

Настройки в `data-` атрибутах `<div id="spin360viewer">`:
- `data-frames="36"` — количество кадров (можно 24 для лёгкости)
- `data-path="assets/spin360/"` — папка с фото
- `data-format="jpg"` — расширение (png, webp тоже работают)

Поведение:
- При готовых фото — авто-крутка по умолчанию
- Зажал мышь / палец → крутишь сам
- Отпустил → через 3 сек снова авто-крутка
- Чувствительность — 12px на кадр (можно подкрутить в `sensitivity`)

### Видео на этапах работы

Каждый из 5 этапов процесса теперь — кликабельная карточка с фото-плейсхолдером и `▶` кнопкой по центру. По клику открывается модал с большим плейсхолдером (16:9) и текстом-пояснением «что и зачем».

Контент модала — массив `PROCESS_VIDEOS` в `script.js`. Что внутри каждого этапа:
- `title` — заголовок над видео
- `caption` — пояснение «зачем мы это делаем» (под видео)
- `placeholder` — описание, что должно быть на видео (для съёмки)

Чтобы заменить плейсхолдер на реальное видео — внутри `openVideo()` поменять `mediaEl.innerHTML` на `<video src="assets/process/step-1.mp4" controls autoplay></video>`.

### Сторис над hero-фото

4 кружка с градиентной обводкой: **Отзывы / Кейсы / Знакомство / Как клеим**. Клик открывает фуллскрин-оверлей, листается тапом / стрелками / Esc для закрытия. Авто-переход через 5 секунд.

Контент сейчас — текстовые плейсхолдеры внутри оверлея с описанием, **что должно быть на каждом слайде**. Все слайды собраны в массиве `STORY_DATA` в `script.js`. Чтобы заменить на реальное содержимое:

1. Снять/выбрать 4 коллекции по 3–4 вертикальных файла (видео или фото 9:16, 1080×1920).
2. Положить в `assets/stories/<reviews|cases|about|process>/01.mp4` или `.jpg`.
3. В `script.js` в `STORY_DATA[<key>].slides[i]` поменять описание на путь к файлу + при необходимости — на video-тег внутри `slideEl.innerHTML`.

Что заложено по содержанию (то самое, что Володя просил — отзывы, кейсы, знакомство + добавил «как клеим»):
