# Левша · прототип конструктора PPF-КП

Интерактивный прототип для менеджеров детейлинг-центра. Менеджер выбирает автомобиль, режим езды, срок владения, материал и 1–3 похожих кейса, после чего получает персональное предложение Light / Optimal / Max.

## Что работает

- более 200 популярных моделей с выбором марки и модели;
- автоматическое определение ценового класса автомобиля;
- единая матрица цен «класс × материал × пакет»;
- автоматическая и ручная рекомендация пакета;
- отдельная база кейсов с выбором 1–3 работ в КП;
- включаемый акционный блок на 7 дней с отдельной скидкой для каждого пакета;
- выбор даты осмотра или оклейки прямо в клиентском предложении;
- клиентская ссылка, готовое сообщение и печать в PDF;
- адаптивная версия для телефона;
- демонстрационные кейсы и цены, явно помеченные как выдуманные.

## Как обновлять данные без изменения кода

Таблицы лежат в [`public/data`](public/data/README.md):

- `vehicles.csv` — автомобили и их ценовые классы;
- `price-classes.csv` — цены по классам;
- `cases.csv` — кейсы;
- `config.json` — адреса источников данных.

В `config.json` можно указать опубликованные CSV-ссылки Google Sheets. Тогда менеджер базы добавляет строки в таблицу, а сайт подхватывает их при следующем открытии без пересборки.

## Локальный запуск

```bash
pnpm install
pnpm run dev
```

Проверка итоговой сборки: `pnpm run build`.
