# ТЗ дизайнеру: фото для услуг Левши в Яндекс Картах

Дата: 2026-05-22  
Задача: подготовить фото для раздела "Товары и услуги" в Яндекс Бизнесе и универсальные ресайзы для дальнейшего использования в карточках, Авито, 2ГИС, сайте, VK Рекламе, Яндекс Директе / РСЯ и соцсетях.

## Зачем

Нужно усилить карточку Левши в Яндекс Картах: у основных разделов и популярных услуг должны быть понятные фото, которые показывают реальную работу, премиальный уровень детейлинга и преимущества Левши.

Фото должны помогать клиенту быстро понять:
- что именно входит в услугу;
- почему работа стоит дороже обычной мойки или сервиса;
- что машина находится в чистом боксе и в руках специалистов;
- какой результат клиент получает после работы.

## Официальные ограничения Яндекса

Для фото в прайс-листе и карточке:
- формат: JPG или PNG;
- размер файла: до 10 МБ;
- обычные фото: от 320 x 240 до 5000 x 5000 пикселей;
- логотип: от 200 x 200 пикселей, соотношение 1:1;
- максимум в профиле: 500 фотографий;
- нельзя размещать телефоны, ссылки и персональные данные в тексте или на изображениях;
- если в категории фото добавлены только для двух или менее позиций, Яндекс может показать категорию в поиске без фото.

Источники Яндекса:
- https://yandex.ru/support/business-priority/ru/manage/price-list
- https://yandex.ru/support/business-priority/ru/manage/photos

Ориентиры для рекламных форматов:
- Яндекс Директ / РСЯ: https://yandex.ru/support/direct/ru/efficiency/images
- VK Реклама, учебные материалы: https://object2-ac.vk-apps.com/vk-education-0554ff56-27eb-4093-a702-685722cef6d9/media/7f/d97f5351b85b4b9fb11fdeae13800cf4.pdf

## Что подготовить по форматам

Для каждого выбранного кадра подготовить:

| Формат | Размер | Где использовать |
|---|---:|---|
| `yandex-square` | 1600 x 1600 px | Яндекс, карточки услуг, обложки |
| `yandex-4x3` | 1600 x 1200 px | Яндекс, 2ГИС, сайт |
| `ads-square` | 1080 x 1080 px | VK Реклама, Яндекс Директ / РСЯ, посты, универсальный квадрат |
| `ads-4x5` | 1080 x 1350 px | VK Реклама, Яндекс Директ / РСЯ, мобильная лента |
| `ads-16x9` | 1920 x 1080 px | VK Реклама, Яндекс Директ / РСЯ, сайт, баннеры, видео-превью |
| `ads-9x16` | 1080 x 1920 px | сторис, VK Клипы, вертикальные видео и креативы |
| `source` | максимальное качество | архив / будущие ресайзы |

Формат файлов: JPG, качество 85-90%, без сильного сжатия.  
Для Яндекса не ставить телефон, сайт, QR-код и ссылки на изображение.

## Дополнительные форматы для VK Рекламы и РСЯ

Для каждой популярной услуги из первого пакета сделать чистые рекламные ресайзы без текста. Эти файлы нужны как готовая база: рекламные тексты и преимущества будем наносить отдельно.

| Формат | Размер | Зачем нужен |
|---|---:|---|
| 1:1 | 1080 x 1080 px | универсальный квадрат для ленты и рекламных сетей |
| 4:5 | 1080 x 1350 px | главный вертикальный формат для мобильной ленты |
| 16:9 | 1920 x 1080 px | широкий формат для РСЯ, баннеров, сайта и видео-превью |
| 9:16 | 1080 x 1920 px | вертикальный формат для клипов, сторис и коротких видео |

Правило по тексту:
- для Яндекс Бизнеса нужна чистая версия без текста;
- для Яндекс Карт и 2ГИС дополнительно можно сделать версию только с названием услуги или категории;
- для рекламных ресайзов не добавлять преимущества, буллеты, цены, скидки, телефон, сайт и QR-код;
- рекламные тексты будем наносить отдельно на подготовленные шаблоны;
- название услуги или категории держать в центральной безопасной зоне, чтобы при автоматической обрезке не потерять смысл.

## Текстовые версии для Яндекс Карт и 2ГИС

Разрешённый текст на таких версиях — только название услуги или категории.

Примеры:
- Фирменная мойка
- Антигравийная плёнка
- Полировка кузова
- Химчистка салона
- Защитные покрытия
- Тонировка
- Ремонт стекол
- Удаление вмятин

Не добавлять:
- преимущества;
- буллеты;
- рекламные слоганы;
- цены и скидки;
- телефон, сайт, QR-код;
- длинные уточнения по классам авто.

## Визуальный стиль

Нужны не стоковые картинки, а реальные или максимально реалистичные фото Левши:
- чистый бокс;
- автомобиль крупным планом;
- руки мастера в процессе;
- понятная зона работы;
- аккуратный свет без грязных теней;
- без визуального шума на фоне;
- без лишних декоративных элементов.

Текст на фото:
- для Яндекса лучше делать чистую версию без текста;
- дополнительно можно сделать версию для Яндекс Карт и 2ГИС только с названием услуги или категории;
- рекламные ресайзы для VK / РСЯ делать без текста, как чистые шаблоны;
- текст не должен закрывать машину или результат;
- не добавлять цены на фото, чтобы не переделывать макеты при изменении прайса;
- для версий 4:3 и 4:5 текст всегда держать в центральной зоне, чтобы при обрезке до квадрата 1:1 он не обрезался.

## Именование файлов

Шаблон:

```

Примеры:

levsha_firmennaya-moyka_yandex-4x3.jpg

levsha_firmennaya-moyka_title-4x3.jpg
levsha_firmennaya-moyka_ads-square.jpg
levsha_firmennaya-moyka_ads-4x5.jpg
levsha_firmennaya-moyka_ads-16x9.jpg
levsha_firmennaya-moyka_ads-9x16.jpg
```

Вместо ID использовать короткое название услуги:
- латиницей;
- маленькими буквами;
- без пробелов, слова разделять дефисом;
- без цен, классов авто и лишних уточнений.

## Главные разделы, которые нужно закрыть фото

По каждому разделу нужно минимум 3 фото, чтобы категория не выглядела пустой.

| Раздел | Что показать | Преимущества, которые считываются |

| Химчистка | сиденья, ковры, пар/экстрактор, салон после | чистота салона, глубокая обработка, сушка |
| Защитные покрытия | нанесение состава, гидрофоб, капли воды | защита кузова, блеск, лёгкий уход |

## Что не использовать

- чужие фото и стоки;
- фото с грязным фоном и мусором;
- фото с номерами автомобилей без блюра, если нет согласия клиента;
- фото с лицами клиентов без согласия;
- телефон, сайт, QR-код, ссылки на фото;
- крупные цены на изображении;
- рекламные преимущества и буллеты на чистых рекламных шаблонах;
- перегруженные рекламные баннеры.
