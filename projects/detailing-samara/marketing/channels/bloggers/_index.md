## Зачем этот канал
Запись ~90%, общий трафик не нужен — нужен **точечный высокодоверенный вход** под маржинальное (плёнка/полировка/керамика) и рост узнаваемости бренда (обгон GoodZone по соц.доказательству). Блогер = доверие + охват + готовый кейс за раз.

## Ключевая механика — бартер-first (синергия с кейс-фабрикой)
Модель по умолчанию: **премиум-услуга на авто блогера в обмен на честный контент.**
- Блогеру — визуально сильная услуга (плёнка перед/фары, полировка, керамика, химчистка) бесплатно.
- Левше — (1) честный контент с охватом, (2) **готовый кейс** до/после силами нашего SMM (тот же поток кейс-фабрики), (3) авто блогера как «витрина».
- Совпадает с правилом Левши «промо через подарки/бонусы, не скидки».
- Платно / % (промокод) — вторым слоем, только для проверенных, кто дал отдачу.

## Кого берём (сегменты, по приоритету)
| Приоритет | Сегмент | Почему |
|:---:|---|---|
| **A** | Локальные авто-блогеры Самары (обзоры, тест-драйвы, тюнинг) — Instagram/VK/YouTube/TG | Прямое попадание в ЦА, гео-релевант, доверие |
| **A** | **A-клиенты Левши, у кого есть блог** | Уже лояльны — тёплый вход, органичный контент |
| **B** | Владельцы премиум/спорт-авто Самары с личным блогом (lifestyle+авто) | Их авто = premium-витрина под плёнку/керамику |
| **B** | Городские lifestyle-блогеры Самары | Охват города, узнаваемость бренда |
| **C** | Авто-паблики/сообщества VK Самары (не персональные) | Охват, но ниже доверие — под промо/розыгрыши |

**Ставка на микро/мид (1-30k):** выше вовлечённость и доверие, дешевле/бартер, легче договориться, чем с макро.

## Как собрать список (реальные источники, не фантазия)
1. **Клиентская база Левши** — прогнать A-клиентов: у кого блог/много подписчиков (спросить приёмщиков, глянуть соцсети). Самый тёплый вход.
2. **Геометки и хэштеги** Instagram/VK: «Самара», #самараавто #детейлингсамара #авто63 #самара163.
3. **Кто отметил конкурентов** (GoodZone, Манго, Youco) в постах/сторис → их клиенты-блогеры.
4. **VK авто-паблики Самары** → активные авторы и админы.
5. **YouTube/Rutube** поиск «Самара авто обзор / тест-драйв».
6. **2ГИС / Я.Карты** — кто оставлял видеоотзывы конкурентам.

## Пайплайн (статусы в CRM)
`Найден → Написали → Ответил → Переговоры → Согласован → Визит/съёмка → Публикация → Оценка → Постоянный / Отказ / Заморозка`

## Процесс (кто что делает)
- **Володя** — утверждает список приоритета A, финалит аутрич-сообщения (прогон через ассистента).
- **SMM / помощница** — наполняет CRM, ведёт переписку по шаблону, координирует визит, снимает кейс.
- **Приёмщик/мастер** — выполняет услугу как приоритетную (блогер = VIP-слот, лучше в будни).
- **Замер** — на каждого блогера промокод/UTM → лиды и записи считаем, не «на глаз».

## Метрики канала
Охват публикаций · переходы (UTM) · лиды по промокоду · записи · CAC барьером = себестоимость бартер-услуги · сколько кейсов получили. Цель цикла: **8-10 активных договорённостей, 15+ публикаций** (см. KPI в плане).
