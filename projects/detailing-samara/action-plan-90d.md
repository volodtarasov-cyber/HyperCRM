## Стратегическая идея

**Чинить воронку в порядке движения клиента. Приёмщик = продавец, но разгружен от непродажных мелочей:**

```
[Маркетинг]→[Мойка=вход/диагностика]→[Приёмщик-продавец]→[Допуслуги/запись на возврат]→[Возврат через 2-4 нед]
     3           1                          2                         2a                           4-5
                                              ↑
                    [Администратор/помощник]: соцсети, «готово ли?», входящая мелочёвка
```

**Ключевой сдвиг (по уточнению 24.04):** приёмщик **остаётся продавцом** — это его основная функция, убирать нельзя. Но с него **снимается непродажная нагрузка:** ответы в соцсетях, созвоны «когда готово», входящая мелочёвка. Эту работу забирает администратор/помощник. Освобождённое внимание приёмщика → в продажу допуслуг во время мойки/приёмки.

**Приоритет ресурсов по месяцам (обновлено 30.04 после встречи с Галией):**
- **Месяц 1:** диагностика + прямой контур подрядчиков + бюджетный ритм заранее + fast wins (наблюдение за приёмщиками, чек-лист мойки-диагностики, перебалансировка слотов между будни/выходные).
- **Месяц 2:** администратор/помощник (разгрузка приёмщиков), CRM, программа лояльности, NPS, маркетинг с расширенным бюджетом по data-приоритетам (плёнка/защитные составы/шиномонтаж как retention-якорь).
- **Месяц 3:** книга стандартов сервиса и продаж, новая мотивация приёмщиков, абонементы на выходные слоты, scale.

**Почему в таком порядке:**
1. Без прямого управления подрядчиками и заранее пополненного бюджета восстановление потока будет буксовать. Точную "неделю перелома" не ищем: практическое решение — усилить маркетинг примерно x1.5 и контролировать каналы напрямую.
2. Без работающего распределения **слотов будни/выходные** — даже восстановленный поток упрётся в очередь и уйдёт к конкурентам.
3. Только после этих двух блоков — наращиваем поток и шлифуем продажи через скрипты/мотивацию.

## Стратегическая цель (уточнена 24.04)

**Лидер рынка детейлинга в Самаре по объёмам продаж — референс, на который ориентируются все остальные.**

Это не лоукостер-стратегия (низкие цены × большой поток). Это **премиум-лидерская**: средний-высокий чек × качественный сервис × высокий LTV × широкий каталог × узнаваемый бренд. Объём приходит через retention (постоянные) + referrals (сарафан) + доминирование в premium-услугах (плёнка, керамика).

Совместимо со всем остальным планом: приёмщик-продавец, мойка-диагностика, разделение ролей, программа лояльности, NPS, книга стандартов — всё работает на это.

**Ближайший референс для обгона:** GoodZone (426 отзывов, №1 по соц.доказательству в Самаре). Через 12-18 мес — обогнать по отзывам. Через 24-36 мес — по узнаваемости и объёму.

### Неделя 2 (05.05 – 11.05) — Первые вмешательства

- **Скрипт приёмщика #1 — «Запись на следующую мойку»:** при выдаче авто — «Удобно, если через 2 недели мы сами перезвоним и запишем в свободное окно? Диктуйте телефон.» Или хотя бы узнать как часто моет машину. **Цель:** 60-80% согласия.
- **Чек-лист мойки-диагностики** — приёмщик при приёме авто быстро проходит пункты: сколы на капоте/бампере (→ плёнка), состояние салона (→ химчистка), матовая краска (→ полировка), тусклые фары (→ полировка фар). **Цель:** чек-лист заполнен для 100% моек. Приёмщик сам **продаёт** по заполненному чек-листу (1-2 фразы при приёме/выдаче), не передаёт никому. В каждую машину можно класть документ, КОТОРЫЙ ЗАПОЛНЯЕТ МОЙЩИК
- **Карта путей допродаж по типу визита** — майский deliverable для стойки: "клиент пришёл на X → какие 1-3 следующие услуги предложить". Минимум 7 входов: плёнка, мойка, полировка, химчистка, PDR, шиномонтаж, шумка. Выход: 1 страница для приёмщиков + короткие фразы, чтобы допродажа не зависела от памяти.
- **Разбор первой партии косяков в диалогах** — из наблюдений недели 1: 5-10 конкретных фраз «что приёмщик говорит сейчас» → «как нужно». Тет-а-тет с каждым приёмщиком, не на общем собрании.
- **120к бюджета май — распределение** (пересмотрено по data 28.04):
  - **управленческое правило:** деньги на следующий месяц выбивать заранее; не начинать месяц с пустыми кабинетами/ожиданием пополнения
  - 50к **на базовый вес каналов и восстановление спроса** — без попытки доказать одну "точку перелома"; проверяем связку SMM/таргет/контекст в прямом управлении
  - 25к **ретаргет на базу + reactivation спящих** (1 212 клиентов — список готов в [analytics/sleeping-clients-2026-04-28.csv](analytics/_archive/sleeping-clients-2026-04-28.csv))

  - 10к **тест шиномонтажа** как сезонного якоря
  - 15к **резерв** на гипотезы по ходу
- **Лия (маркетолог трафика) подключается** на детейлинг — 10-15% времени, первые креативы плёнки и тест Авито на шиномонтаж для VK/Авито.

- **CRM-минимум:** Google Sheets или CRM-lite (Битрикс-фри, amoCRM триал). Обязательно: каждый новый клиент записан, обязательное поле «телефон». Приёмщик не имеет права не записать.
- **Переобучение приёмщиков на продажи + сервис:** 2-3 тренинга (по 1-2 ч) на основе записей звонков и записей из зала. Фокус: скрипты на плёнку/керамику/шумку по чек-листу, обработка возражений, up-sell при выдаче, отсутствие панибратства.
- **🆕 Программа лояльности «Каждая 5-я мойка бесплатно»** — накопительная карта (физическая или в Telegram/WhatsApp). Запуск на всю базу. Стимулирует возвраты, помогает удерживать в условиях узкого горлышка боксов.
- **🆕 NPS запуск** — после каждого визита SMS или WhatsApp: «Оцените от 0 до 10, порекомендуете ли нас другу?». Если 0-6 — звонок клиенту в 24ч. Если 9-10 — запрос отзыва в 2ГИС / Я.Карты. Ответственный: администратор или Лия.
- **WhatsApp-рассылки напоминаний о мойке:** через 2-4 недели после визита. Шаблон. По когортам. **С предложением выходного слота** (где есть свободная мощность).
- **Лия на детейлинге 30-50%:** план удержания 6 z-1 клиентов закрыт без отдельной кампании, фокус Лии — плёнка-лидген, контент по кейсам плёнки, соцсети Левши. Массовый reactivation спящих (1 212 чел из CSV) вероятно закрывают сотрудники Левши после назначения внутреннего ответственного.
- **Маркетинг-бюджет с расширением (если согласован 200-250к)** — приоритеты по data:
  - 80-100к **главный канал привлечения** (по результатам мая)
  - 50к **плёнка-лидген** (главная воронка А-клиентов)
  - 30к **защитные составы** (недооценённый канал, retention 51%, LTV 103к)
  - 20к **шиномонтаж** (тест сезонной воронки, 50.6% возврата)
  - 20к Я.Карты + 2ГИС + контент
  - 20к резерв
- **Первая кампания по плёнке с кейсами:** съёмка 3-5 кейсов (до/после), публикация в соцсетях, таргет. Лия + подрядчик по видео.
- **🆕 Тест абонементов «выходные слоты»** — пилот на 30-50 клиентах. «4 мойки в месяц по субботам в 10:00» как закреплённый слот. Закрепляет постоянного клиента + заполняет пустые субботы (там 67% утилизация vs 102% в пятницу).
- **🆕 Скидка в выходные −15%** — переток спроса с забитых будней в свободные сб/вс. Проверка эффекта 4 недели.
- **Reactivation на 6+ мес когорты** — массово, WhatsApp / звонки. Приоритет на тех, кто покупал плёнку (LTV 119к).
- **Конкурентный анализ по ценам и офферам** — обновить competitors.md с таблицей по услугам. Что у GoodZone, Youco, Автолюкса, Манго по офферам и бонусам.

## МЕСЯЦ 3 (23.06 – 28.07) — Scale

**Цель месяца:** вывести связки «мойка → плёнка → регулярные возвраты» на стабильные обороты. **Написать книгу стандартов сервиса.** Подготовить следующую фазу (экспансия, расширение бюджета).

### Фокусы

- **🆕 Книга стандартов обслуживания и продаж** — единый документ: скрипты (приём / выдача / телефон / администратор), регламент осмотра и чек-листа, правила записи в CRM, NPS-обработка, reactivation-скрипты, мотивация. Всё, что сейчас «из уст в уста» — в один файл в общем доступе. Работа на 3-4 недели, основа для масштабирования (и для инфобиз-продукта HYP-PROD-001).
- **Приёмщики — новая система мотивации:** приёмщик = продавец, поэтому мотивация комбинированная — % от up-sell допуслуг (плёнка/керамика/шумка) + бонус за NPS 9-10 + бонус за % повторных визитов. Согласовать с Андреем.
- **Дашборд KPI:** простой отчёт для Андрея каждый понедельник. Выручка по услугам, динамика, конверсии, NPS, reactivation. **Автоматический сбор** через скрипт-аналитику + API кабинетов. Google Sheets + график.
- **Маркетинг-бюджет переговоры:** если результаты хорошие — запрос 400-500к с августа. Показать ROI: каждый рубль в retention принёс X, каждый в acquisition — Y. **С опорой на data: восстановление потока новых = главный аргумент.**
- **Масштабная кампания по плёнке:** собственный контент (видео кейсов), продвижение в 3-4 каналах одновременно. Связка Лия + приёмщик-продавец (для обработки лидов при визите) + администратор (для переписки с лидами).
- **Абонемент-пакеты — масштабирование пилота с мес.2:** «мойка-подписка по выходным + скидка на керамику раз в полгода». Если пилот сработал — на всю базу постоянных. Цель: 100-150 подписчиков к концу июля.
- **🆕 Целевой маркетинг на потенциальных постоянных** — фильтрация аудиторий по признакам (марка авто премиум, возраст 30-45, активность в авто-сообществах). Отдельная воронка для тех, кто **потенциально становится А-клиентом** (по data это плёночники с большим первым чеком).
- **Конкурентный мониторинг** как регулярный процесс: раз в 2 недели смотрим GoodZone, Youco, Автолюкс, Манго. Файл ведётся.
- **Лия на детейлинге 50-70%**, подготовка к возможности «младший партнёр» (по отдельной HYP).
- **🆕 Расширение мощности боксов** (если по факту мес 1-2 узкое горлышко не закрылось перетоком в выходные) — обсуждение с Андреем: возврат к историческому числу боксов / открытие 2-й точки / экспансия. По data текущие 4 бокса перегружены в пиковые периоды (110% утилизации в апр.26).
