Текущие стадии лидов

Количество и доля стадии внутри выбранного направления и периода

Периоды строятся по дате создания лида. Квал — фактическая стадия «Качественный лид». «Сделки» — все однозначно связанные сделки Б24. Успешные — стадии «Сделка успешна» и «Автомобиль выдан клиенту»; внутри этой колонки отдельно суммируется поле `Сумма` Б24, которое не является фактической выручкой. Остальные закрытые сделки считаются неуспешными, незакрытые показываются отдельно. Средний чек = фактическая выручка связанных заказов 1С / количество заказов с выручкой больше 0 ₽; нулевые заказы в расчёт не входят.
