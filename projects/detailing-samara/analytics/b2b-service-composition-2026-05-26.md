## Управленческий вывод

B2B в Левше неоднородный. Есть минимум три разных сценария:

1. **Разовая/редкая крупная плёнка.** Даёт большой чек, но без последующего маршрута быстро выпадает. Нужны контрольный осмотр плёнки, уходовая мойка, сезонная диагностика.
2. **Регулярная мойка/флот.** Даёт частоту и контакт с компанией. Нужны договор, приоритетные окна, один ответственный, отчёт по машинам.
3. **Сервисная задача.** Шиномонтаж, химчистка, полировка, ремонт. Это повод открыть отношения, но сам по себе не гарантирует повтор.

Для B2B нельзя использовать один общий оффер. Нужны отдельные маршруты: `флот/регулярка`, `крупная плёнка`, `разовая сервисная задача`, `корпоративный A-lost`.
