# Лиды × Wordstat понедельно — сырьё анализа, июль 2026

> ⚠️ **Выводы этого анализа в волте не записаны.** Здесь лежит только сырьё и построенные таблицы. Если анализ нужен как аргумент — сначала вытащить из него выводы в нормальную записку `analytics/*.md`, иначе он снова потеряется.

## Что это

Сопоставление недельной динамики лидов с частотностями Яндекс Вордстата по услугам Левши: плёнка, PDR, ШВИ, мойка. Цель — понять, идут ли лиды за спросом или за нашими действиями.

Папка приехала из `outputs/019f7e7b-…` при миграции на Windows (2026-08-11). До этого лежала в корневом `outputs/` под UUID-именем, вне какой-либо навигации волта — на неё не ссылалась ни одна заметка.

## Состав

| Что | Файлы |
|---|---|
| Сборка недельного отчёта по плёнке | `build_weekly_film_report.ps1`, `add_weekly_waves_chart.ps1` |
| Готовые таблицы по плёнке | `Левша_пленка_лиды_Wordstat_и_динамика.xlsx`, `Левша_пленка_лиды_и_Wordstat_понедельно.xlsx` |
| Источники | `leads_source.csv`, `wordstat_source.csv/xlsx` |
| Превью | `chart_preview.png`, `weekly_waves_preview.png`, `dashboard_preview.pdf` |
| По услугам | `film_primary/` (только первичные лиды), `pdr/`, `shvi/` и `shvi_v2/`, `wash/` — в каждой свой `build_*.ps1`, источник и собранный xlsx |

`shvi_v2/` — пересборка `shvi/`, актуальная версия там.

## Запуск

Пути в `.ps1` переписаны под текущее расположение (были захардкожены на `C:\Users\User\YandexDisk\HyperCRM\outputs\…`). Если папку двигать — править пути внутри скриптов снова.

```powershell
powershell -ExecutionPolicy Bypass -File build_weekly_film_report.ps1
```

## Удалено при миграции

Четыре каталога `*.files/` (~105 МБ) — служебные HTML-компаньоны Excel от «сохранить как веб-страницу», осиротевшие даже от своих `.htm`. Данные не затронуты: они в `.xls`/`.xlsx`/`.csv` рядом.
