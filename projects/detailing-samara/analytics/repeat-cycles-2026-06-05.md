# Циклы повторной сделки по услугам (для реактивации в Б24)

> Цель: дать роботам Б24 (R15 «дата следующей реактивации») фактические интервалы по каждой услуге вместо оценок на глаз.

## Важная оговорка по методу

Интервалы посчитаны **только по клиентам, которые вернулись** (≥2 визита). Это **естественный ритм активных клиентов**, а не «когда вернётся одноразовый». Для робота это рабочая логика — даёт две опорные точки:

- **Медиана** — обычный ритм, когда лояльный клиент приходит сам.
- **75-й перцентиль** — точка дрейфа: если клиент к ней не вернулся, он **уже отваливается**. Реактивацию бьём чуть раньше этой точки.

## Рекомендованные интервалы под робота R15

Берём точку **чуть раньше дрейфа** — дотянуться до клиента, пока не ушёл к конкуренту.

| Услуга | N для робота | Логика |
|---|---|---|
| **Мойка** | **~6 недель (45 дн)** | ритм 17 дн, потерян после 53 дн. b2b-парки занижают медиану → для частника берём 6 нед |
| **Полировка + защита** | **~3,5 мес (100 дн)** | дрейф 110 дн, совпадает с прежней оценкой «4 мес» |
| **Химчистка** | **~3,5–4 мес** | дрейф 123 дн, сезонная грязь |
| **ПДР** | **~3 мес — на доп (cross-sell), не на повтор** | разовая услуга, касание ради допродажи |
| **Шиномонтаж** | **сезонно (апр / окт)** | данные шумят (b2b-парки), цикл по сезону шин |
| **Антигравийная плёнка** | **по домену: 12–36 мес** | данные НЕ годятся, см. нюанс 1 |
| **Керамика** | **по домену: 12 мес** | сейчас смешана с защитой, см. нюанс 2 |

## 3 нюанса (не игнорировать перед заливкой в Б24)

1. **Плёнка — данные обманут.** Медиана 20 дн и повтор 17 дн — это визиты в рамках одной установки (докатать зоны), а не повторная продажа. Реальный цикл плёнки — годы. Робот ставим по домену (12–36 мес).
2. **«Полировка + защита» — смешанный котёл.** Туда падает и быстрый защитный спрей при мойке (отсюда 28 дн), и керамика (реально 12 мес). Нужно **разделить керамику в отдельную услугу** в Б24, иначе робот будет дёргать керамщиков ежемесячно. Это дыра неполного справочника услуг.
3. **Мойка/шиномонтаж занижены b2b-парками.** Корпоративные парки моются часто и тянут медиану вниз. Для частников реальный ритм мойки длиннее — поэтому взято 6 недель, а не 17 дней.

## Связка с новыми/повторными (контекст)

- В потоке 2025: 1209 новых клиентов / 4292 повторных обращения → повторные = 78% потока.
- 60% клиентов — одноразовые (one-and-done); главная течь — мойка (38% всех потерь, 50% невозврат).
- Самый горячий сегмент под реактивацию: «мойка + защита/полировка» (~95 чел) — дорогой первый чек + встроенный повод вернуться, который не использовали.
