# Фото-расчёт под тёплую базу (реактивация → плёнка)

> **Контекст:** клиент из базы (мойка 4-12 мес / тонировка / новая машина). Доверие к Левше есть — **не продаём студию, продаём пользу для его машины.** Цель — фото-расчёт «3 варианта» → диагностика 40 мин.
> Не путать с [холодным скриптом](film-diagnostic-sale-script.md) (там сначала доверие). Здесь — тёплый старт.

## Принципы (как в тёплую)
- **Опираемся на прошлый визит** — «вы были у нас на [услуга]» = мгновенный контекст и доверие.
- **Ведём пользой, не оффером** — «покажу зоны риска по вашей машине», не «у нас акция на плёнку».
- **Цена-мост, не стена** — вилку «от» даём сразу с ценностью, точную — на расчёте.
- **Честное вычитание** — сами говорим, где не клеить (приём Виктора).
- **Без давления** — «решите спокойно, смета у вас».

## Касание 1 — крючок + карта зон + кейс (тёплый старт)
```
[Имя], это Левша. Вы были у нас на [мойке/тонировке] в [месяц] — как [марка]?
По вашей модели хочу показать карту зон риска: где реально летят сколы с трассы,
а где можно не клеить. Соберу 3 варианта защиты плёнкой — без обязательств,
расчёт и диагностика бесплатные. Скину карту и пару наших работ на такой же [модель]?
```
→ отправляем **карту зон риска** + **1 кейс** (коробка, элемент 1–2).

## Касание-вопросы (квалификация, мягко)
1. Машина новая или с пробегом? *(новую — защитить сразу; с пробегом → полировка-подготовка в комбо)*
2. Где больше ездите — город / трасса? *(трасса → больше сколов, перед обязательно)*
3. Что важнее — максимум защиты или оптимум по цене? *(пакет)*
4. Когда думаете — на днях / в этом месяце / присматриваетесь? *(срочность)*

## Анти-якорь (показать разрыв)
```
По [модель] без защиты — стандартная история: сколы на капоте и бампере с трассы,
реагенты зимой. Локальный подкрас — от 5-7 тыс. за деталь, и видно при перепродаже.
За 3-4 года набегает больше, чем оклейка, а машина «уезженная». Плёнка снимает это.
```

## Фото-расчёт «3 варианта»
```
Чтобы дать точную цену и не продать лишнего — пришлите 5-6 фото (перед, капот,
фары, бампер). Соберу 3 варианта: перед / расширенный / полная — с ценой каждого
и пометкой, где можно не переплачивать. Если удобнее — бесплатная диагностика
40 минут в студии, мастер посмотрит ЛКП и даст 3 варианта на руки.
```
→ отправляем **смету-шаблон** (коробка, элемент 6) + **Pro/Rocket** на «дорого».

## Комбо-стандарт (из path-to-film)
Предлагать как готовый пакет, не разрозненно:
> «плёнка + полировка-подготовка кузова + уход/мойка после выдачи» — это стандарт визита.
Тонировщикам — «полная защита» (стёкла уже сделали → кузов плёнкой).

## Отработка возражений (тёплая версия)
- **«Дорого»** → Rocket (5 лет, дешевле) + начать с переда + анти-якорь подкраса. «На расчёте подберём под бюджет».
- **«Сделаю потом»** → «плёнка работает лучше **до** первого скола; после — клеим уже повреждённую деталь». Мягкий follow-up.
- **«Дешевле подкрасить»** → «подкрас от 5-7 тыс/деталь, видно при продаже; плёнка защищает сразу и снимается без следа».
- **«Сниму — краска слезет?»** → снятие под температурой, без следов, ЛКП заводской; фиксируем исходное.

## Закрытие
- Два слота на диагностику, не «когда удобно».
- В [трекер](../marketing/funnels/film/first-funnel-tracker-template.csv): статус, пакет-интерес, источник (база/реактивация), причина если «подумаю».
- «Подумаю» → follow-up по warming-sequence, не давление.

## Стандарт диагностики «40 минут / 3 варианта на руки»
1. Приветствие + подтверждение задачи (по прошлому визиту).
2. Осмотр ЛКП и зон риска под лампой.
3. **Фотофиксация исходного состояния** (снимает «отдаю машину»).
4. Объяснение Light / Optimal / Max по его машине и стилю езды.
5. Показ материала Pro / Rocket вживую.
6. **Смета «3 варианта» на руки** + срок + гарантия + образец паспорта защиты.
7. Честное вычитание: где НЕ нужно клеить.
8. Следующий шаг: слот записи / «подумайте, смета у вас» + follow-up.

> ❌ Диагностика ≠ обычная продажа. Не давить на full body. Дал смету, проговорил где не надо — уехал думать. Это и есть доверие (приём Виктора).
