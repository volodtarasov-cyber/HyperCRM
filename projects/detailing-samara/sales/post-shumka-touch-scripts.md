# Скрипты касаний постшумочного маршрута (+30 / +90 / +180)

**Дата:** 2026-06-15. Касания маршрута → [post-shumka-retention-plan.md](post-shumka-retention-plan.md). Касание +1 (памятка) → [post-shumka-care-memo.md](post-shumka-care-memo.md).
**Голос:** бренд, забота и сервис — не «купите ещё». Каждое касание = сервисный повод вернуть в студию.
**Подстановка:** `[Имя]`, `[машина]`, `[пакет]`, `[приёмщик]`, `[ссылка/телефон]`.

---

## +30 дней — TG / MAX · приёмщик
**Повод:** бесплатный контрольный осмотр + мойка. Вернуть до остывания.

```
[Имя], прошёл месяц после шумоизоляции вашей [машина] — как тишина, привыкли? 🙂

Приглашаем на бесплатный контрольный осмотр: проверим, что всё держится, нет ли скрипов после обкатки, и заодно помоем машину. Это часть нашей гарантии — для вас бесплатно.

Какой день удобнее на этой неделе — будни или выходные?
```

**Если молчит 3–4 дня — один мягкий повтор:**
```
[Имя], напомним про бесплатный осмотр шумоизоляции — слот ещё держим за вами. Сказать, когда есть окна?
```

## +90 дней — ЗВОНОК · приёмщик
**Повод:** подарок-сертификат на смежную услугу + короткий рассказ «что ещё умеем». Не продажа в лоб — дарим и заодно показываем спектр.

**Опорные точки разговора (не читать дословно):**

1. **Заход — сервис, не продажа.**
   «[Имя], добрый день, это [приёмщик], детейлинг-центр Левша. Звоню узнать — как машина после шумоизоляции, всё устраивает, ничего не беспокоит?»
   → выслушать. Если есть жалоба — сразу зовём на бесплатную коррекцию (гарантия), продажу не двигаем.

2. **Подарок (если всё хорошо).**
   «Вы наш клиент, и мы хотим вас поблагодарить. Дарим сертификат на [полировку фар / антидождь / экспресс-химчистку] — бесплатно, действует [30–45 дней]. Запишем, когда будет удобно заехать?»

3. **Короткое сервисное меню (только если клиент в диалоге).**
   «Многие после шумоизоляции не знают, что мы умеем ещё — защита салона и кузова, керамика, тонировка, полировка. Если что-то из этого думали сделать — у нас всё под одной крышей.»
   → не перечислять списком-простынёй; назвать 2–3 по интересу клиента.

4. **Закрытие.**
   «Тогда давайте запишу вас на [услуга по сертификату] — какой день удобен?»

**Правило:** если клиент не готов — не давим. Сертификат остаётся, фиксируем «подумает», ставим касание +180.

## +180 дней — TG / MAX · приёмщик
**Повод:** сезонный + достроить зоны (для точечных) / следующий уровень защиты / реферал / вторая машина.

**Вариант для тех, кто брал точечный пакет ([пакет] = Точка тишины):**
```
[Имя], полгода с тишиной в [машина] — как ощущения? 🔇

В прошлый раз мы закрыли [двери/пол]. Если где-то ещё остаётся гул — самое время добить [арки и пол]: уберём остаток и доведём до полной тишины. Для вас как для нашего клиента — на специальных условиях.

Подобрать вариант под вашу машину?
```

**Вариант для тех, кто брал комплекс:**
```
[Имя], полгода после шумоизоляции [машина] — надеемся, дорога стала заметно тише 🙂

Раз уж салон в тишине — логичный следующий шаг защитить и его вид, и кузов: керамика, защита салона, тонировка. Всё под одной крышей, без поиска новых мастеров.

И ещё: если кто-то из знакомых жалуется на гул в машине — приведёте к нам, сделаем приятно обоим. Рассказать, как это работает?
```

## Общие правила (метод сообщения)
- **Сервисный повод вперёд, оффер — следом.** Сначала «проверим/поможем», потом «можем ещё».
- **Одно касание — один следующий шаг.** Не валить весь спектр в одно сообщение.
- **Жалоба важнее продажи:** любой негатив → бесплатная коррекция по гарантии, апсейл откладываем.
- **Тон:** спокойно, по-человечески, без «спешите / только сегодня».
- Замеры результата — отклик на касание → визит (в гугл-таблице маршрута).
