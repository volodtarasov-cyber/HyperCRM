# ИИ-сервисы: выбор, доступ и оплата из РФ

**Слаг:** `ai-income-rf`
**Заведён:** 2026-08-06
**Статус:** разведка пройдена (полная), решение о самостоятельности проекта **отложено до Wordstat**

> ⚠️ Проект заведён под запрос «заработок на ИИ». Разведка дала **no-go на эту формулировку** и **go на переформулированную нишу**. Слаг оставлен историческим, чтобы не терять связь с исходным запросом; при подтверждении силоса папка сливается в [foreign-payments-rf](../foreign-payments-rf/).

## Паспорт проекта

- **Ниша / тема:** исходно — «заработок на ИИ»; по итогам разведки — выбор ИИ-сервиса под задачу + доступ и оплата из РФ
- **География:** РФ, федеральный онлайн-проект, города не нужны
- **На чём зарабатываю:** CPA / revshare (ИИ-сервисы, агрегаторы, карты/посредники), edtech-CPA вторично
- **Продукт / услуги:** каталог ИИ-сервисов с проверенными ценой, доступом из РФ и способом оплаты + сравнения + калькулятор
- **Кто клиент:** прикладной специалист, селлер на маркетплейсе, разработчик — люди, выбирающие платный инструмент под рабочую задачу
- **Тип сайта:** новый (или новый силос существующего)
- **Главная цель:** подтверждённые партнёрские действия
- **Ограничения:** домена нет; ресурс на тесты и обновления ограничен; параллельно ведётся foreign-payments-rf
- **Что уже есть:** отчёт разведки, список фраз к Wordstat
- **Доступ к данным:** Wordstat вручную, платных инструментов нет

## Вердикт разведки

- **Вердикт:** **no-go на «заработок на ИИ»** · **go 7/10 на `нейросети под задачу + доступ и оплата`**, но **как силос foreign-payments-rf, а не второй домен**
- **Скоринг:** «заработок на ИИ» — 3/10 · переформулированная ниша — 7/10
- **Стартовая подниша:** задачные запросы `нейросеть для [X]` + профессиональные хабы
- **Где деньги:** (1) `нейросеть для [задача]` → revshare ИИ-сервисов; (2) `как оплатить [ИИ-сервис] из России` → CPA карт/посредников
- **Главный барьер:** голова выдачи занята UGC-платформами (vc.ru, DTF, Хабр) с недостижимым весом домена
- **Главный wedge:** датированная проверяемая БД «цена в рублях × работает ли из РФ × чем оплатить» — то, чего листиклы структурно не дают
- **Отчёт:** [`01-razvedka/razvedka-zarabotok-na-ii-2026-08-06.md`](01-razvedka/razvedka-zarabotok-na-ii-2026-08-06.md)
- **Контент-модель:** [`03-kontent-plan/model-statya-nesuschaya-oplatu.md`](03-kontent-plan/model-statya-nesuschaya-oplatu.md) — статья под задачу с встроенным money-слоем; принята владельцем 2026-08-06
