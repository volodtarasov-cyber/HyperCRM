## Паспорт проекта

- **Ниша / тема:** криптобиржи — выбор площадки, доступ из РФ, ввод и вывод рублей, комиссии, обзоры
- **География:** РФ, федеральный онлайн-проект, города не нужны
- **На чём зарабатываю:** реферальные и партнёрские программы самих бирж — revshare с торговых комиссий
- **Продукт:** датированная база `биржа × доступ из РФ × KYC × P2P-рубли × комиссии` + обзоры + инструкции + калькулятор
- **Кто клиент:** активный трейдер (даёт доход), новичок с деньгами и вынужденный пользователь крипты (дают трафик и часть дохода)
- **Тип сайта:** новый, домена нет
- **Главная цель:** регистрации на биржах по рефералке, доходные по факту торговли
- **Ограничения:** **юридическая оценка исключена по указанию владельца**; регулирование учитывается только как фактор спроса и монетизации
- **Что уже есть:** отчёт разведки, список фраз к Wordstat
- **Доступ к данным:** Wordstat вручную, платных инструментов нет

## Вердикт разведки

- **Вердикт:** **осторожный go, 6/10** — лучшая money-модель из всех проектов папки при худшей устойчивости оффера
- **Стартовая подниша:** доступ и вывод («какая биржа работает с РФ», «как вывести в рубли»), **не** «как торговать»
- **Где деньги:** (1) доступ и выбор биржи; (2) ввод/вывод рублей и P2P; (3) брендовые обзоры
- **Главный барьер:** смертность оффера, а не конкуренция в выдаче
- **Главный wedge:** датированная проверяемая таблица доступа и комиссий — конкуренты публикуют «ТОП-25 бирж» без даты
- **Отчёт:** [`01-razvedka/razvedka-kriptobirzhi-treyding-2026-08-06.md`](01-razvedka/razvedka-kriptobirzhi-treyding-2026-08-06.md)

### Чем эта ниша отличается от двух других

| | foreign-payments | ai-income | **crypto-trading** |
|---|---|---|---|
| Модель | CPA за выпуск карты | Revshare с подписки | **Revshare с торговых комиссий** |
| Доход с реферала | Разовый, небольшой | Небольшой, стабильный | **Потенциально кратно выше** |
| Хвост | Нет | Пока платит подписку | **Пожизненный** |
| Устойчивость оффера | Средняя | Высокая | **Низкая** |
| Волатильность дохода | Низкая | Низкая | **Высокая, цикличная** |

Крипта — единственный из трёх проектов с потенциально кратным доходом на реферала и единственный, где оффер может исчезнуть целиком вместе со всем накопленным хвостом.
