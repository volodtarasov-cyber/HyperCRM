# ТЗ на визуалы для VK-рекламы

> Дата: 2026-05-05
> Назначение: быстро подготовить 3-5 визуалов для стартовых креативов без лишнего дизайна.

Визуалы должны выглядеть как B2B-разбор для владельца бизнеса, а не как реклама клининга или стирки ковров для конечного клиента.

---

## Общие правила

- Формат: 1:1 и 4:5 для VK.
- Стиль: деловой, чистый, без перегруза.
- Текст на визуале: 3-7 слов, не длиннее.
- Не использовать маркетинговые клише: "увеличим прибыль x10", "лиды гарантированно", "лучший таргет".
- Не обещать гарантированные продажи.
- Основная эмоция: ясность, контроль, диагностика.

## VIS-01 — Таргет был, результата нет?

Для креатива: CRE-02.

Текст на визуале:

> Таргет был. Заказов нет?

Сцена:
- схема воронки на светлом фоне;
- одно звено выделено красным / жёлтым;
- подписи: оффер, креатив, заявка, обработка, заказ.

Не использовать:
- фото ноутбука с графиком;
- абстрактный рост;
- деньги и стрелки вверх.

Цель: показать, что проблема может быть не только в кабинете.

## VIS-02 — Загрузить сезон ковров

Для креатива: CRE-03.

Текст на визуале:

> Сезон ковров нужно загружать

Сцена:
- цех стирки ковров;
- ковры в работе;
- машина забора / доставка, если есть;
- можно использовать коллаж "цех + заявка + календарь".

Не использовать:
- слишком грязные ковры крупным планом;
- дешёвую эстетику "до/после" из бытовой рекламы;
- скидку как главный элемент.

Цель: говорить с владельцем про загрузку цеха, а не с домохозяйкой про чистый ковёр.

## VIS-03 — Клининг после ремонта

Для креатива: CRE-04.

Текст на визуале:

> Не уборка. Готовность к въезду.

Сцена:
- квартира после ремонта;
- чистый светлый кадр;
- можно добавить маленькую схему: пыль -> расчёт -> бригада -> готово.

Не использовать:
- случайных людей с тряпками;
- стоковую улыбающуюся уборщицу;
- визуал "скидка на уборку".

Цель: показать, что мы умеем перепаковывать услугу в понятный результат.

## VIS-04 — Лиды есть, заказов нет

Для креатива: CRE-05.

Текст на визуале:

> Лиды есть. Где заказы?

Сцена:
- таблица заявок;
- колонки: новая, ответили, расчёт, заказ, отказ;
- несколько строк теряются на этапе "расчёт" или "не ответил".

Цель: зацепить владельца, который уже платил за рекламу и не понял результата.

## VIS-05 — 1-2 проекта на май

Для креатива: CRE-06.

Текст на визуале:

> 2 проекта на май

Подстрока:

> клининг / ковры

Сцена:
- спокойный деловой фон;
- чек-лист критериев: бизнес работает, бюджет есть, заявки считают.

Цель: ретаргет и тёплая аудитория, отбор без массовости.
