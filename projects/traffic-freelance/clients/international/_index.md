## Что это доказывает

1. **Диаспорный рынок реален.** Пять проектов за год на пяти рынках: США, Европа, Азия, Ближний Восток, Латинская Америка. Один канал — Мета, одна дисциплина — платный приток.
2. **Ниша повторяется.** Все пять — локальный сервисный бизнес с русскоязычным владельцем. Это готовый профиль клиента, а не набор случайных заказов.
3. **Химчистка обуви в Аргентине** — та же ниша, в которой Володя построил собственную мастерскую до 1 млн/мес. Совпадение продукта и личного опыта, сильнейший угол для кейса.
4. **Платёжные рельсы работают криптой** (уточнено 2026-08-19). Для проектных и рекуррентных агентских платежей это рабочая схема; условия и валютный риск фиксируются с конкретным клиентом.

## Что здесь не так

**Продаётся не тот продукт.** 530 $/мес ≈ 48к — это ниже Бинго и почти вдвое ниже Стиралкина, при том что американский рынок платёжеспособнее российского. Причина не в рынке: за рубежом продаётся **узкая услуга — ведение таргета**, а в РФ уже продаётся **сопровождение**, то есть управление плюс приток.

Экономика получается перевёрнутой: на более богатом рынке чек ниже. Лечится не повышением цены за ту же работу, а переносом продукта — того самого, который в РФ куплен дважды.

Тип лида нужно назвать в кейсе явно, иначе цифра читается как невероятная и подрывает доверие вместо того, чтобы его строить.

## Главное открытие: рынок не тот, что предполагали

Реклама шла на **англоязычную и местную аудиторию**, а не на русскоязычную диаспору. Значит формулировка входа меняется:

- ❌ было: «приведу тебе русскоязычных клиентов за рубежом»;
- ✅ стало: **«сделаю поток на твоём местном рынке — на английском, испанском, иврите; договариваемся по-русски»**.

Русский язык — про **клиента**, а не про его аудиторию. Это шире и сильнее: рынок — все русскоязычные предприниматели с бизнесом за рубежом, которым нужен маркетинг на местном рынке и которым тяжело объясняться с местным агентством. Языковой барьер, разница в деловых привычках и цена местных агентств работают на нас.

## Форма сбора данных по завершённым проектам

Заполнить по каждому из четырёх. **Минимум** — без этого кейса не существует, всё берётся из кабинета Меты за период работы.

| Поле | Монако, салон красоты | Бали, недвижимость | Израиль, клининг | Аргентина, химчистка обуви |
|---|---|---|---|---|
| Период работы (с — по) | | | | |
| Сколько месяцев | | | | |
| Потрачено всего + валюта | | | | |
| Целевое действие (лиды / переписки / звонки / заявки) | | | | |
| Сколько получено | | | | |
| Стоимость обращения | | | | |
| **Язык и аудитория:** русскоязычные в стране или местные на местном языке | | | | |

**Желательно** — усиливает кейс кратно, но не блокирует:

| Поле | Зачем |
|---|---|
| Что было до меня: откуда шли клиенты, в чём была проблема | без точки А результат нечем измерить |
| Сколько дошло до продажи, средний чек, выручка | переводит кейс с языка заявок на язык денег |
| Лучшая связка: какая аудитория и креатив сработали | показывает механизм, а не удачу |
| Особенность рынка, которая мешала или помогала | доказывает, что работал именно с этим рынком, а не вслепую |
| Скриншот кабинета (названия можно закрыть) | визуальное подтверждение |
| Готов ли клиент подтвердить результат или дать отзыв | по правилу слоя доказательств нужен человек, который подтвердит |

**Ключевой вопрос — про язык и аудиторию.** Если реклама шла на **местную** аудиторию на местном языке, то кейс сильнее, но он про другое: «веду рекламу на незнакомых рынках», а не «работаю с русскоязычными». Тогда «русскоязычные по всему миру» — это про **клиентов**, а не про аудиторию, и позиционирование диаспорного входа надо формулировать иначе.

## Что из этого можно использовать (уточнено 2026-08-20)

По Израилю, Бали и Монако Володя работал **подрядчиком**: прямых контактов с владельцами не осталось, доступа к кабинетам нет. Подтвердить цифры некому и нечем. По Аргентине контакт есть, запрос отправлен.

**Отсюда разделение, которое стоит держать в голове всегда:**

| | Что это | Где применимо |
|---|---|---|
| **Кейс** | число + подтверждение + возможность показать | холодная реклама, лендинг, публичный контент |
| **Опыт** | то, что можешь рассказать и объяснить | разговор один на один, диагностика, квалификация |

Израиль, Бали и Монако остаются **опытом**, а не кейсами. В рекламе их цифры использовать нельзя, в разговоре с клиентом — можно и нужно: «вёл клининг в Тель-Авиве, там работало вот что». Это не проверяют, это создаёт доверие в диалоге.

**География сама по себе — доказательство, не требующее цифр.** «Работал с бизнесами в Израиле, на Бали, в Аргентине, сейчас в Калифорнии» проверяемо, честно и говорит ровно то, что нужно: чужой рынок не пугает.

## Калифорния стала критически важной

Это **единственный международный проект с доступом и контактом**, то есть единственный источник будущего полноценного кейса на диаспорном рынке. Отсюда:

- вести с фиксацией цифр **с первого дня** — потрачено, обращения, стоимость, что дошло до продажи;
- 530 $ здесь не про деньги, а про доказательство целого рынка;
- результат по ней окупает вход в диаспору в разы больше собственного чека.

## Прежняя формулировка следующего шага

**Достать цифры по четырём завершённым проектам.** Апселл Калифорнии на сопровождение сейчас не продаётся: проект только запускается, результата ещё нет, а без результата поднимать чек втрое не с чем. А вот четыре закрытых проекта — готовые кейсы для диаспоры, если у них есть числа. Именно они, а не Калифорния, открывают холодный вход на Мету.
