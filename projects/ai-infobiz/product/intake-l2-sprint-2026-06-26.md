# L2-Спринт — глубокая анкета + клиентский отчёт

> **Когда:** после оплаты/брони спринта (90к). L1 уже квалифицировал и предзаполнил часть — клиент не повторяется.
> **Цель:** собрать факты по одному направлению, чтобы стартовое интервью шло по сути, а не по сбору базы. Самозаполнение где можно + **доступы обязательны**.
> Структура зеркалит скрининг-модель (рынок→продукт→упаковка→реклама→продажи→аналитика).

## Часть A — самозаполнение клиентом (до интервью)

**1. Бизнес и направление**
- ниша / город / сколько на рынке · направление под разбор (одно) · выручка/мес · команда (размер/роли) · сезонность

**2. Экономика направления**
- средний чек · маржинальность (если знает) · LTV / частота повторных · % выручки от повторных vs новых · рекламный бюджет/мес

**3. Каналы и метрики** *(что есть — то и дайте)*
- какие каналы привлечения работают · CPL / CPA по каналам (если считаются) · конверсии по этапам (лид→заявка→продажа) · кто ведёт трафик (свои/подрядчики)

**4. Продажи**
- кто продаёт (отдел/собственник/приёмщик) · есть ли скрипт/CRM · конверсия обращение→продажа · где, по ощущению, теряете

**5. Удержание / повторные**
- есть ли работа с базой · реактивация · программа лояльности/реферал · % спящих

**6. Конкуренты**
- 2-3 главных конкурента · чем они сильнее/слабее · почему клиенты выбирают их/вас

**7. Цель и ограничение**
- главная бизнес-цель на 90 дней · что считаете узким местом · что уже пробовали и не сработало · стоп-лист (что точно не хотите трогать)

## Часть B — доступы (обязательны, без них диагноз неполный)
- [ ] выгрузка по продажам/выручке (1С / CRM / таблица) за 6-12 мес
- [ ] доступ (или скрины) рекламных кабинетов (Директ / VK / Авито)
- [ ] метрики сайта (Метрика/GA) если есть
- [ ] доступ к CRM (гостевой) или выгрузка воронки
- [ ] ссылки: сайт, карты, соцсети, реклама

> Назначить **одного человека** на стороне клиента за сбор данных (условие нормального результата из оффера).

## Часть C — что заполняет аналитик в процессе
Скрининг по [модели параметров](../agency-os/methods/screening-analysis-spec.md): рынок/спрос · продукт/компания · упаковка · реклама · продажи · аналитика → диагностика по разделам → главное ограничение → причинная цепочка → 1-2 рычага.

# Шаблон клиентского отчёта (дельиверабл за 90к)

> Закрывает дыру дашборда «нет упакованного дельиверабла». Это то, что клиент получает на руки.

## 1. Резюме (1 страница)
- главное ограничение одной фразой · 3 причинных вывода · 1-2 рычага на 90 дней · чего НЕ делать сейчас.

## 2. Карта коммерческой системы
- путь `продукт → оффер → канал → продажа → CRM → возврат` с пометкой, **где теряются деньги** (узкое место).

## 3. Диагностика по разделам
- рынок/спрос · продукт/упаковка · реклама · продажи · удержание · аналитика — что ок, что просело (с фактами из данных клиента).

## 4. План 0–30 / 31–60 / 61–90
- карточки действий: что · владелец · метрика · срок. 1-2 рычага, не «всё сразу».

## 5. Недостающие данные
- что собрать/настроить, чтобы решения были на фактах (часто — атрибуция/CRM-разметка).

## 6. Рекомендуемые модули Agency OS
- какие модули внедрять под рычаги (скрининг → оффер → марк-система → удержание).

## 7. Решение по следующему шагу
- самостоятельно / в группу (сопровождение) / стоп. Честно: если силами команды клиента — так и скажу.
