# Нога 3 — инфобиз ИИ×маркетинг: дорожная карта H2 2026

> **🔄 Обновление 2026-06-23:** лестница переупакована — фракц-CMO как продукт **убран**, добавлены **2 группы (10-15к/мес)** между клубом и консалтингом; клуб закреплён как **community-first** (племя/поддержка/ритм, контент = растопка). Появилась **команда из 3 топов на %** и **слои монетизации** (рекламный кешбек, аффилиат, рефералы). Актуальная модель целиком → [private-practice-model-v2-2026-06-23.md](private-practice-model-v2-2026-06-23.md) и [life/decisions.md](../../../life/decisions.md) (2026-06-23). Помесячный план посева ниже остаётся в силе, читать через новую лестницу.

## Решение по формату

**Курс — нет** (production-тяжёлый, устаревает в ИИ-нише).
**Ядро — клуб/коммьюнити** (recurring + воронка на CMO/пул + под природу Володи).
**Платформа — Telegram** (Skool/Circle в РФ не вариант).

**Старт — клуб В ЛОБ по тёплому ядру** (founding-набор), без марафона. Тёплая сеть (десятка, клиенты, знакомые) доверяет и так — ей не нужен прогрев через челлендж. Это совет Айзенберга: тестируй платно рано, на ядре, не жди тысячи.

**Марафон (платный челлендж) — опционально, на масштабирование.** Нужен только когда тёплая сеть исчерпана и льём из холодного трафика: холодный не покупает recurring «в лоб», ему нужен дешёвый конечный вход. Сам по себе марафон — операционка; не запускать, пока клуб наполняется тёплыми напрямую.

Последовательность: **контент → founding-клуб по своим (recurring) → [опц.] марафон для холодного трафика → масштабирование клуба**.

## Аудитория

- **Кто:** частные спецы (таргетологи, авитологи, маркетологи, фрилансеры) + предприниматели малого бизнеса, кому нужен ИИ×маркетинг.
- **Тёплое ядро на старте:** сеть Володи — текущие клиенты, десятка Илюшина, подрядчики, знакомые предприниматели.
- **Каналы дистрибуции (решено 2026-06-08):** TG + YouTube + Instagram + Threads. Один стержневой контент («мастер») → переупаковка под каждый канал, а не четыре отдельных потока. **Клуб (ядро, recurring) живёт в TG** — остальные каналы это верх воронки на него.
- **Бренд-канал (решено 2026-06-08):** переобуваем **@lazyhim** под ИИ×маркетинг, новый не плодим (тёплая сеть уже там). См. [positioning.md](positioning.md).
- **Метрика везде:** не охваты, а тёплое ядро (кто реагирует, пишет, готов платить).

## План по месяцам

### Июль — позиционирование + контент-ритм
- Каналы решены (TG + YouTube + Instagram + Threads, клуб в TG, бренд-канал = переобутый @lazyhim).
- Позиционирование ноги 3 зафиксировано → [positioning.md](positioning.md): острие — частные спецы; большая идея «один маркетолог с ИИ = отдел»; отстройка через доказательство (изнанка проектов), не claim.
- **Поднять автопайплайн дистрибуции** (генерация каруселей Instagram + автовыкладка из одного источника) — см. секцию «Автоматизация дистрибуции».
- Контент 2-3/нед из уже идущей работы (Левша-кейсы, AI-система, разборы решений) — конвейер уже есть в [content-pipeline.md](../content-pipeline.md).
- Задача в свободную минуту: 1 мастер-пост за раз (voice → каркас → дожим), дальше переупаковка автоматом.

### Август — тест тяги + сбор ядра
- 1-2 бесплатных живых разбора/эфира «ИИ в маркетинге» → смотрим явку и запросы.
- Завести лист ожидания / закрытый чат ядра (первые 20-50 тёплых).
- Из запросов понять боль: за что реально готовы платить.

### Сентябрь — первый платный разовый формат (посев + кеш)
- Закрытая мастер-группа / интенсив 8-12 чел, высокий чек (15-30к), 2-4 недели, на реальных ИИ-кейсах.
- Это первые деньги ноги 3 + ядро будущего клуба + проверка формата.
- Метрика: дошли / заплатили / остались довольны.

### Октябрь — упаковка клуба на собранном ядре
- Ядро клуба = участники интенсива + лист ожидания.
- Определить: чек подписки (ориентир 3-5к/мес), ритм (созвон, разборы, база материалов, чат-движ), что внутри.
- Анонс + ранний набор по своим.

### Ноябрь — запуск клуба (recurring старт)
- Открыть клуб, первый платящий набор.
- Цель: 20-40 платящих → 60-150к recurring.
- Ритм: 1 созвон / 1-2 нед, разборы, живой чат.

### Декабрь — раскачка + связка на CMO
- Удержание первого набора (в recurring главное — не отток).
- Из клуба органически: лиды на CMO-проекты (нога 2) и подрядчики в пул (нога 1).
- Цель ноги 3: ~100-150к (по [финплану](../../../life/finance/plan-300-600-2026.md)).

## Автоматизация дистрибуции

> Решение 2026-06-08: один человек ведёт 4 канала только через автоматизацию. Принцип — **один мастер-контент → авто-переупаковка**, ручная работа только на исходнике (voice → каркас → дожим).

**Поток:**
```
мастер-пост (md)
   ├─→ TG        — текст как есть
   ├─→ Threads   — нарезка на тезисы/тред
   ├─→ Instagram — карусель (PNG-слайды в фирменном стиле)
   └─→ YouTube   — скрипт под Shorts/ролик
```

**Карусели Instagram (приоритет, самый частый формат):**
- Подход: шаблон HTML/CSS → рендер в PNG через **Playwright** (уже стоит в `.tools/`, та же связка, что snapshot.py).
- Скрипт `.tools/projects/ai-infobiz/content/carousel.py`: вход — md с разбивкой на слайды (`---`), выход — пронумерованные PNG 1080×1350 в фирменном стиле (обложка + контент-слайды + финал-CTA). Стиль наследуем от КП Ананаса (тёмная обложка + жёлтые акценты).
- Это высоколиквидный быстрый винт: production каруселей руками = главный пожиратель времени, а тут он уходит в скрипт.

**Автовыкладка (по реалистичности доступов):**
| Канал | Как | Сложность |
|---|---|---|
| Telegram | Bot API, постинг сразу | 🟢 авто из коробки |
| Instagram | Graph API (нужен Business-аккаунт + связка с FB-страницей) | 🟡 авто после настройки доступов; до того — генерим карусель, постим руками/через буфер |
| Threads | Threads API (Meta, тот же контур доступов, что Instagram) | 🟡 как Instagram |
| YouTube | YouTube Data API (OAuth) | 🟡 авто после OAuth |

**Реалистичный старт (июль):** `carousel.py` + автопостинг в TG сразу (1-2 дня работы). Instagram/Threads/YouTube — сначала генерация+ручная выкладка, авто-API подключаем по мере, когда поток стабилен. Не строить весь комбайн вперёд контента.

## Реалистичность к декабрю

- 100-150к от клуба = 20-50 платящих по 3-5к. С холодной аудитории амбициозно, но тёплая сеть (десятка, клиенты, знакомые предприниматели) даёт фору.
- Если контент Q3 заходит медленнее — декабрь ближе к 50-80к (нижняя граница финплана). Не катастрофа, план это держит.

## Риски

- **Время.** Q3-Q4 параллельно с Левшей 5/2. Посев лёгкий (контент из работы), но интенсив (сент) и клуб (ноя-дек) = живая операционка по вечерам/выходным → конфликт с 20ч семьи. Держать в рамках 40ч работы, не залезать в семью.
- **Клуб не наберётся** (аудитория не созрела) → сдвиг запуска на Q1 2027, нога 3 в 2026 = только разовый интенсив. План это переживёт (база 370 + Левша держат floor).
- **Отток в клубе** (recurring мрёт без ритма) → нужен живой ритм с дня 1, иначе деньги уходят так же быстро.
