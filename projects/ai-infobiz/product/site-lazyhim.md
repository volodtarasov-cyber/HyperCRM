# Сайт @lazyhim — продуктовая площадка ноги 3

**Создан:** 2026-06-09/10
**Где лежит:** `~/projects/lazyhim-site/` (вне vault и вне Яндекс.Диска — там node_modules)
**Стек:** Astro (статика), шаблон blog. Node лежит локально в `~/projects/lazyhim-site/.node/` (brew/node в системе нет).
**Назначение:** собственная площадка ноги 3 (блог + лид-ловушка), верх воронки на клуб. См. [positioning.md](positioning.md), [клуб](../club.md).

## Как запустить локально
```
cd ~/projects/lazyhim-site/site
export PATH="$HOME/projects/lazyhim-site/.node/bin:$PATH"
npm run dev        # → http://localhost:4321/
npm run build      # → dist/ (статика под выкладку)
```

**Домен:** volodtarasov.ru (reg.ru, прописан в `astro.config.mjs`). Двойная роль: личный лендинг под CMO-лиды (нога 2) + блог/ловушка под клуб (нога 3).

## Страницы
- `/` — **полноценный лендинг** (13 блоков): hero с фото-плейсхолдером + пруф-бар → боли → подход → пакеты → цифры → кейсы (4 с ananasm.ru) → отзывы → процесс → гарантии → обо мне + видео → FAQ → контакт → блог-тизер. Дизайн под КП Карнелии.
- `/blog` + `/blog/4-sloya/` — блог, первая статья «4 слоя»
- `/prompt` — лид-ловушка (оффер промпта + форма имя/контакт)
- `/spasibo` — выдача магнита (промпт «4 слоя») + намёк на клуб

## Как писать контент
Статья = markdown-файл в `src/content/blog/*.md` с фронтматтером (title, description, pubDate). Кладёшь файл → появляется на сайте. Флоу: voice → каркас → дожим → положить md.

## Бренд
Тёмный `#2B223A` + жёлтый `#FFBA24`, шрифт **Manrope** (self-hosted через Astro Fonts, с кириллицей). Бренд-имя @lazyhim.

## Форма / захват ядра
Форма на `/prompt` шлёт через **Web3Forms** (бесплатный бэкенд для статики), ключ уже вставлен в `src/pages/prompt.astro`. Заявки падают Володе **на почту** = список тёплого ядра. Работает только из браузера (server-side Web3Forms блокирует).

## ⚠️ Публично сайт не работает

`volodtarasov.ru` и `www.volodtarasov.ru` отдают **self-signed сертификат** — браузер покажет предупреждение, поисковики такой сайт не индексируют. То есть публично не работают ни лендинг, ни блог, ни форма на `/prompt`, а значит **тёплое ядро через сайт сейчас не собирается вообще**.

Проверено запросом к обоим адресам. Что именно сломано — деплой не сделан, стоит заглушка хостинга или не выпущен сертификат — по внешней проверке не видно, нужен доступ.

**Следствие:** выкладка и валидный сертификат — предусловие ко всему, что связано с сайтом: посадочная под оффер сопровождения, лид-магнит, органический канал. До этого сайт не актив, а черновик на диске.
