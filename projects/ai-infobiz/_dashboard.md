## Что это

Частная практика Володи как внешнего коммерческого/маркетинг-директора для сервисного бизнеса (кластер чистоты: детейлинг, химчистки, клининг). **Все продукты — на одной методологии Agency OS.** Контент — лишь один из каналов привлечения, не сам продукт.

- **Большой курс — на паузе** (запись только после 10+ платных консультаций и 3+ повторяющихся запросов).
- **Активный путь 2026:** консультация → спринт → фракц-CMO → корп-обучение → живая группа.
- **Цель:** +~200к чистыми/мес к декабрю поверх базы Левша (250к) + трафик (~149к) = 600к.

> Это и есть «прогнать инфобиз по новым материалам»: каждый модуль → продаваемый дельиверабл + готовность.

| Ветка | Модуль | Продукт лестницы | Готовность как продукт | Что нужно |
|---|---|---|---|---|
| ① Скрининг | [business-market-screening](../agency-os/modules/business-market-screening.md) | **консультация 20к + спринт 90к** | 🟢 **working** — обкатан на Левше, КП Карнелии (180к) подтвердил спрос | Оформить в воспроизводимый клиентский дельиверабл (отчёт + презентация) |
| ② Конкур. поле | [competitive-field-analysis](../agency-os/modules/competitive-field-analysis.md) | часть спринта 90к | 🟡 draft, не продан | Обкатать на реальной задаче (PPF-конкуренты Левши) → довести до working |
| ③ Продукт+аудитория | [niche-icp-jtbd-research](../agency-os/modules/niche-icp-jtbd-research.md) | часть спринта + сопровождения | 🟡 draft, не продан | Прогнать на живом клиенте; добрать лекцию про боли/барьеры |
| ④ Марк. система | [marketing-system-design](../agency-os/modules/marketing-system-design.md) | **фракц-CMO 150-180к** | 🟡 draft, не продан | Это ядро сопровождения — упаковать в «что я делаю за 150к/мес» |
| × production-loop | [метод](../agency-os/methods/production-loop-planner-agent-evaluator.md) | сопровождение + группа | 🟢 метод есть, тест идёт | Обкатать на hero Левши и на черновике контента |

**Честный вывод прогона:** из 5 веток продаваемо сейчас **одно — скрининг** (доказан деньгами: Левша + КП 180к). Спринт можно собирать (скрининг + конкуренты), но конкуренты/аудитория/система ещё draft. **Практика может продавать диагностику уже сейчас; сопровождение и группу — после того как ②③④ дозреют из draft в working на живых клиентах.**

## Упаковка: что отдаём, что держим (слой IP)

Прямая связь с [решением по 3 слоям](../agency-os/backlog.md):

- **Консалтинг/сопровождение** → клиенту уходят только результаты (скрининг-отчёт, КП, система), методология остаётся.
- **Живая группа / обучение** → отдаём метод (слой 1+2: пустая ОС + шаблоны), держим слой 3 (набитые кейсы + суждение + фасилитация).
- Механизм: `distribution: core | shippable | client` — пока не введён, см. бэклог.

## Главные дыры (🔴)

1. **Оффер не продан ни разу через холодную сеть** — финплан требует 5 продаж через тёплую сеть до платной рекламы на себя. Сейчас 0 спринтов продано.
2. **3 из 5 модулей — draft.** Продавать спринт/сопровождение полноценно нельзя, пока ②③④ не обкатаны на живых клиентах. Активный полигон — Левша; Карнелия остановлена 2026-07-14.
3. **Нет упакованного клиентского дельиверабла** даже по working-скринингу (отчёт есть, продуктовой обёртки «вот что вы получаете за 20к/90к» — нет).
4. **Воронка касаний не запущена** — 15-20 тёплых касаний/мес как норма не идёт.

## Главный рычаг на сейчас

**Упаковать working-скрининг в продаваемый продукт** (консультация 20к + спринт 90к): клиентский шаблон отчёта + одностраничное КП «что вы получаете». Это единственный модуль, доказанный деньгами, — с него и начинаются продажи практики. Параллельно дозревают ②③④ на Левше, переходя из draft в working по мере применения.
