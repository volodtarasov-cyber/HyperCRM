# Контент — структура

## Папки

- `drafts/` — черновики. Один файл = одна тема. Внутри могут жить несколько форматов (длинная статья, короткий пост, структура для видео, альт-заголовки).
- `published/` — опубликованные финальные версии + метаданные (где, когда, как зашло). Это архив «как было на самом деле», чтобы использовать как примеры в дальнейшем.

## Жизненный цикл темы

1. **Идея** → `content-pipeline.md` (раздел «Сырые идеи»).
2. **Черновик** → файл в `drafts/` (`NNN-slug.md`). В `content-pipeline.md` помечаем «черновик».
3. **Публикация** → финальные версии копируются в `published/NNN-slug.md` + добавляются метаданные (канал, дата, ссылки, первая реакция).
4. **Результат** → через неделю-две вернуться и дописать «что зашло / что нет».

## Формат файла черновика

```markdown
---
slug: zachatki-ai-systemy
status: draft | ready | published
channels_planned: TG, VK, Twitter, YouTube
created: YYYY-MM-DD
---

## Угол / тезис
(одна строка)

## Структура
(пункты для пересказа / видео)

## Версии
### Длинная (статья)
### Короткая (TG/VK)
### Видео-скрипт (опционально)

## Варианты хука / заголовков
```

## Формат файла published

То же + блок «Публикация»:
```
## Публикация
- TG: ссылка, дата, реакция (коротко)
- VK: ...
- YT: ...
- Комментарии / что зашло: ...
```
