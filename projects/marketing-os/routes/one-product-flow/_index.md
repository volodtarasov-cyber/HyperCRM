# One Product Flow — маршрут одного продукта

**Статус:** active v3 — канонический маршрут
**Владелец:** Володя

> Задача маршрута — собрать работающую воронку одного продукта от первого касания до покупки и проверить её одним измеримым тестом. Глубину дают движки Marketing OS; OPF удерживает фокус и порядок решений.

Термины маршрута используются только в значениях из [словаря Marketing OS](../../core/glossary.md). В клиентском разговоре английские aliases заменяются русскими рабочими названиями.

## Каркас

```text
диагностика → фокус → сборка → тест
```

`проблема → работы клиента → стартовый сегмент → четыре силы прогресса → уровень осознанности → продукт → оффер → источник → карта пути → продажа и дожим → метрики`.
