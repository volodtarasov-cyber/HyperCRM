# S8 · CJM — путь касаний с точками перелома

> **Фаза 3 · Сборка.** Цель: карта реального пути выбранного сегмента ОТ точки входа до оплаты и удержания — с эмоциями и **точками перелома**, где путь рвётся. Это то, что мы проектируем. Один продукт, один сегмент, один вход.

**Вход:** S3 (силы, барьеры), S4 (уровень входа), S5-S6 (продукт, оффер), S7 (источник).

## 1. Что фиксируем на каждом шаге пути

| Ось | Вопрос |
|---|---|
| Действие | что человек делает |
| Мысль | какой вопрос в голове |
| Эмоция | балл + короткий лейбл |
| Точка контакта / канал | где касание |
| Барьер | что мешает шагнуть |
| Доказательство для клиента / материал | чем снимаем барьер |
| Метрика | что считаем |

Шкала эмоции: `−2 не верю · −1 сомневаюсь · 0 нейтрально · +1 теплею · +2 хочу дальше`. Провал ≤ −1, пик ≥ +1. (Можно шкалу 1-10: провал ≤4, пик ≥7.)

## 2. Универсальный путь (сжать/добавить под продукт), ~8-10 шагов

| # | Шаг пути | Эмоция | Барьер (типовой) | Доказательство для клиента / материал |
|--:|---|---|---|---|
| 1 | Триггер / момент слома | −1 тревога | не связывает с решением | контент боли |
| 2 | Осознание проблемы | 0 → +1 | «проблема не в этом» | пост-объяснение, чеклист |
| 3 | Поиск и сравнение | +1 интерес | «все обещают одно» | разбор альтернатив |
| 4 | Первое касание с нами | +1 → 0 | «ещё один продавец» | точка входа + лид-магнит |
| 5 | Оценка и доверие | −1 сомнение | **главный страх (тревога перехода)** | доказательство для клиента под конкретный страх |
| 6 | Заявка / квалификация | +1 | «во что ввязываюсь» | понятный next step |
| 7 | Решение / оплата | −1 → +2 | цена vs доказанность | гарантия процесса, чёткий результат |
| 8 | Онбординг / старт | 0 | «купил, а результата нет» | сопровождение, первые шаги |
| 9 | Результат / удержание | +2 | «дальше сам не потяну» | замер, следующий шаг |
| 10 | Рекомендация | +2 | не просят вовремя | запрос отзыва в момент +2 |

## 3. Точка перелома

Нарисовать линию эмоции по шагам. **Точка перелома — ОДНА (или две) на сегмент:** шаг, где эмоция проваливается сильнее всего и отваливается больше всего людей (узел да/нет). Для дорогой продажи часто две: **доверие** (пик тревога перехода) и **внедрение** («получил, а результата нет»).

Правило: **весь доказательство для клиента и контент вешаем на точки перелома, а не размазываем ровным слоем.**

## 4. Барьеры — из негатива конкурентов + тревога перехода клиента

Два источника: страхи клиента (S3) + **негатив по конкурентам** (отзывы, что бесит в их опыте — S1).

| Шаг | Барьер | Откуда | Чем снимаем |
|---|---|---|---|
| 5 | «продадут, а толку нет» | тревога перехода + критика конкурентов | осязаемый пример/образец до оплаты |
| 5 | «не поймут мой случай» | негатив «шаблонно» | разбор на его продукте |
| 7 | «дорого без гарантии» | тревога перехода + критика обещаний | гарантия процесса, чёткий результат |

## 5. Для каждого шага пути — глубоко (полная версия)

- **3 дословные цитаты** внутреннего диалога от первого лица;
- **15+ поисковых запросов** (эволюция: осознание → сравнение → локальные → цена → процесс → уход);
- **места поиска клиентов** — конкретные инстансы, не «соцсети»: VK группы/паблики · Instagram · TikTok · YouTube · Telegram каналы/чаты · форумы/блоги/отзовики · лидеры мнений · offline-ареалы · входящие партнёры;
- **лид-магниты на шаг** (несколько): тип · какой барьер снимает · как донести (канал по тёплости) · альтернатива.

## 6. Green / red конфликты

- **Green (усиливает движение):** осязаемый артефакт, разбор на его случае, честность обещаний, быстрый первый шаг.
- **Red (ломает путь):** пустые обещания, шаблонность, тишина после интереса (нет дожима по контексту).

Правило: red на точках перелома убивает конверсию сильнее слабого оффера. Сначала убрать red на переломных шагах.

## 7. Сквозные приоритеты — 3 действия, чинящие точки перелома

```text
1.
2.
3.
```

## Критерий готовности — перейти к S9 только после подтверждения

- [ ] Путь 8-10 шагов с эмоцией и барьером на каждом.
- [ ] Одна (максимум две) точка перелома.
- [ ] Барьеры + доказательство для клиента под каждую переломную точку; green/red названы.
- [ ] Лид-магниты + каналы по шагам; 5 (или 3) сквозных приоритетов.

> **Оговорка:** CJM до реальных диалогов — гипотеза [Г] о пути. Факт появляется, когда путь проверен на 5-10 сделках и видно, где реально отваливаются.

## Рекомендация этапа — проверить наличие доказательство для клиента (не обязательно)

На каждой точке перелома свериться: есть ли **реальное** доказательство под конкретный страх (кейс, образец, фото до/после, гарантия)?
- Есть → вешаем на переломный шаг.
- Нет → это пробел; лучше создать образец/кейс ДО запуска, иначе путь рвётся именно здесь.
