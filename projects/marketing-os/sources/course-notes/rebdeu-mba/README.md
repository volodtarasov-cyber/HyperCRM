## Сквозные принципы курса (красная нить)

1. **От задачи к инструменту**, а не наоборот (#0).
2. **Принцип > факты**: одна логика рассуждений на любую нишу (#1).
3. **От мотива/JTBD, не от персонажа** (#2, #3).
4. **Релевантность — главный рычаг**; дерево результата снизу вверх (#4).
5. **Конкуренция — в голове клиента**; быть первым в голове, не в рейтинге (#1, #5).
6. **Данные — сырьё**, прогнать через фильтры → конфигурировать своё (#1).
7. **Всё бьётся по финмодели**; стратегия = как, тактика = чем (#4, #5).
