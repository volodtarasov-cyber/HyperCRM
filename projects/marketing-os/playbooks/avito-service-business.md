# Авито для сервисных бизнесов

**Статус:** draft  
**Тип:** лидген + упаковка + CRM / обработка  
**Где применяем:** трафик-портфель, будущее Авито-направление, партнерство с авитологом  
**Владелец:** Володя / Лия  
**Дата создания:** 2026-05-03  
**Последнее обновление:** 2026-05-03  

---

## Суть

Модуль превращает Авито из набора объявлений в управляемый канал продаж:

```text
ниша → упаковка объявлений → заявки → обработка → CRM → сделка → отчетность
```

Это может быть:

- самостоятельная моно-услуга;
- модуль внутри агентского клиента;
- основа для Авито-агентства;
- инструмент для партнерств с операторами.

---

## Для кого

Идеальные ниши:

- детейлинг;
- химчистка мебели / ковров;
- клининг;
- ремонт;
- окна / двери;
- автосервис;
- аренда оборудования;
- сервисы с понятным чеком и повторяемыми заявками.

Не подходит:

- очень низкий чек;
- нет маржи;
- мастер-одиночка без учета;
- клиент не фиксирует сделки;
- нет ответственного за обработку заявок.

---

## Какая боль

- объявления есть, но они не управляются как система;
- непонятно, какие объявления дают выручку;
- заявки теряются;
- нет дожима по контексту;
- нет CRM;
- владелец смотрит только на просмотры и сообщения, а не на сделки.

---

## Оффер

Рабочая формулировка:

```text
Настраиваем Авито как управляемый канал продаж для сервисного бизнеса:
упаковка, объявления, заявки, обработка, учет и отчет по деньгам.
```

---

## Связка

```text
1. Источник / канал: Авито.
2. Точка входа: объявления под конкретные услуги / сегменты.
3. Обработка заявки: скрипт, быстрый ответ, квалификация.
4. CRM / учет: источник, услуга, сумма, статус, следующий шаг.
5. Дожим по контексту: дожим тех, кто спросил цену и пропал.
6. Отчетность: заявки, сделки, выручка, стоимость заказа.
7. Повторная продажа: база клиентов, сезонные касания, допродажи.
```

---

## Артефакты

- чеклист аудита Авито;
- шаблон структуры объявлений;
- шаблон описания услуги;
- шаблон фото/визуала;
- скрипт обработки заявки;
- CRM-воронка;
- отчет по объявлениям;
- шаблон КП для продажи услуги.

---

## Метрики

- просмотры;
- контакты;
- стоимость контакта;
- квалифицированные заявки;
- продажи;
- выручка;
- стоимость продажи;
- конверсия заявка → сделка;
- скорость ответа;
- доля заявок с дожимом по контексту.

---

## Условия запуска

- есть услуга с понятным чеком;
- есть ответственный за обработку;
- клиент готов вести учет;
- можно отличить заявки Авито от других каналов;
- есть фото/кейсы/доказательства.

---

## Риски

- Авито воспринимается как "дешевый канал";
- клиент не считает сделки;
- много мусорных обращений;
- слабая обработка убивает экономику;
- конкуренты демпингуют;
- изменения правил площадки.

---

## Первый запуск

Где запускаем:

```text
1. Левша — пленка / детейлинг.
2. Трафик-портфель — клиенты с Авито-направлением.
3. Потенциальное партнерство с авитологом — как агентская система.
```

Что считаем успехом за 30 дней:

- есть понятный пакет услуги;
- есть 1-2 клиента / пилота;
- видна экономика заявка → сделка;
- можно понять, строить ли моно-направление.
