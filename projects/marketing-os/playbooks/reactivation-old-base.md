# Реактивация старой базы

**Статус:** draft  
**Тип:** retention + повторные продажи  
**Где применяем:** детейлинг, ковры, химчистка, клининг, сервисные бизнесы  
**Владелец:** Володя  
**Дата создания:** 2026-05-03  
**Последнее обновление:** 2026-05-03  

---

## Суть

Модуль возвращает клиентов, которые уже покупали, но давно не приходили:

```text
старая база → сегментация → персональное касание → оффер → заказ → повторное напоминание
```

Это один из лучших модулей для модели "фикс + процент", потому что выручку кампании легче атрибутировать.

---

## Зачем это стратегически: «железный забор» (ПсихоМаркетинг)

Старая база — это **собственная коммуникационная среда** (рассылка, сообщество, клуб, личный кабинет, регулярный сервис), которая снижает зависимость от рекламных алгоритмов и повторную конкуренцию за уже купленного клиента. В экономике внимания дефицитный актив — доверие, поэтому небольшая отфильтрованная база часто эффективнее массовой аудитории.

Сравнивать базы нужно не по числу контактов, а по:

- выручке и марже на 100 контактов;
- доле покупателей;
- частоте повторной покупки;
- стоимости удержания;
- доле активных рекомендателей.

> Связь с ногой 3: тот же принцип «железного забора» — основа клуба AI×маркетинг.

## Для кого

Идеально:

- есть база клиентов;
- есть повторяемая услуга;
- есть сезонность или понятный цикл возврата;
- можно отправлять WhatsApp/SMS/email;
- можно посчитать выручку кампании.

Ниши:

- стирка ковров;
- химчистка мебели;
- клининг;
- детейлинг;
- химчистка одежды;
- автосервис.

Не подходит:

- нет базы;
- нет согласия / канала коммуникации;
- разовая услуга без повторяемости;
- невозможно отследить заказ.

---

## Какая боль

- деньги лежат в старой базе, но с ней не работают;
- бизнес покупает новые заявки, забывая про прошлых клиентов;
- нет сегментации;
- нет сезонных напоминаний;
- нет понятного оффера на возврат.

---

## Оффер

Клиентская формулировка:

```text
Вернем клиентов из вашей старой базы и посчитаем выручку, которую принесла реактивация.
```

---

## Связка

```text
1. Источник / канал: старая база клиентов.
2. Точка входа: WhatsApp / SMS / email / звонок.
3. Обработка заявки: быстрый ответ, запись, расчет.
4. CRM / учет: сегмент, дата касания, статус, сумма заказа.
5. Дожим по контексту: повторное касание через 2-5 дней.
6. Отчетность: охват, ответы, заказы, выручка.
7. Повторная продажа: календарь следующего касания.
```

---

## Условия запуска

- выгрузка базы;
- согласованный канал коммуникации;
- оффер;
- ответственный за обработку;
- учет заказов из кампании.

---

## Риски

- база грязная;
- старые телефоны;
- слабый оффер;
- администраторы не успевают отвечать;
- клиент смешивает выручку кампании с общей кассой;
- есть юридические ограничения по рассылкам.

---

## Первый запуск

Где запускаем:

```text
Кандидаты: Левша / клиенты ковров и химчистки / будущие партнерства.
```

Что считаем успехом за 7-14 дней:

- база очищена и сегментирована;
- отправлено первое касание;
- есть первые ответы и заказы.

Что считаем успехом за 30 дней:

- выручка кампании посчитана;
- понятна экономика;
- можно предложить повторный цикл.
