# S2 · JTBD-карта сегментов

> **Фаза 1 · Диагностика.** Цель: разложить продукт на 5-7 работ (jobs) и понять, кто и зачем его нанимает. Это широкий, поверхностный слой анализа ЦА — вглубь по одному выбранному сегменту пойдём в S3.

**Вход:** S1 (текущая ситуация; негатив конкурентов → точки слома; главное ограничение; дословные фразы клиентов).

## 1. Тип ниши — как сегментировать

- **Мягкая ниша:** под одним словом («плёнка») прячутся разные работы (защитить новую машину / скрыть сколы на старой / перепродать дороже / «как у друга»). → сегментируем **по работам**.
- **Жёсткая ниша:** работа одна, различаются только люди. → 1-2 сегмента, не плодим искусственно.

## 2. Что описываем на каждый сегмент (5-7 штук)

| Поле | Что это | Формат |
|---|---|---|
| **Core Job** | работа от лица клиента | «Когда [ситуация/триггер], хочу [действие], чтобы [результат]» |
| **Big Job** | большая эмоц.-функц. цель за Core Job | одна фраза + критерии «работа выполнена» |
| **Кто / триггер** | типаж и что запускает покупку | короткое описание |
| **Тип опыта А/Б** | А = впервые (обучать) · Б = знающий («лучше привычного») | А или Б |
| **Точка слома** | главный барьер сегмента | из негатива конкурентов + возражений/отказов (S1) |
| **Чек + спрос** | привлекательность | средний чек + объём спроса с числом («бронеплёнка купить — 86/мес») |
| **Готовность купить** | горячо/тепло/холодно | по интенту запросов и типу спроса |
| **Сложность убеждения** | легко/средне/сложно | по силе страхов и длине цикла |
| **Мотивация-лейбл** | одно слово, что движет | «защитить», «сэкономить», «статус» |

## 3. На базе чего делаем выводы (источник каждого поля)

Ни одно поле не берётся из головы — каждое опирается на данные из S1. Нет базы → `[нет данных]`.

| Поле | На базе чего (из S1) | Тип |
|---|---|---|
| Core Job | дословные фразы + триггеры клиентов (VoC) | факт-цитата |
| Big Job | инференс из VoC: большая цель за Core Job (что хотят / чего боятся) | оценка [Г] |
| Тип опыта А/Б | формулировки запросов («что такое плёнка» = А, «suntek ppf купить» = Б) + типажи | оценка на данных |
| Точка слома | негатив конкурентов + возражения/отказы | факт-цитата → вывод |
| Чек | учёт (1С/CRM) | факт |
| Спрос с объёмом | Wordstat: запросы + объёмы | факт |
| Готовность купить | интент запросов (транзакц. vs инфо) + тип спроса/момент | оценка на данных |
| Сложность убеждения | VoC-страхи/возражения + тип опыта (А сложнее) + цикл/чувствительность к цене | оценка [Г] |

**Факт** (чек, объём) — из учёта/Wordstat. **Оценка/[Г]** (опыт, готовность, сложность) — всегда со ссылкой на конкретную фразу, запрос или цифру.

## 4. Приоритизация — 3 корзины

- **Ядро:** максимальный чек + прямой спрос + совпадение с сильной стороной. Строим воронку в первую очередь под него.
- **Быстрые деньги:** острый триггер, короткий цикл, лёгкое убеждение. Быстрый сигнал.
- **Не первым:** сложное убеждение, спрос вне поиска, долго греть.

**Гард-рейл приоритета:** приоритет = функция текущего ограничения (из S1). Если простаивает мощность — грузим её, даже если сегмент «сложный». Приоритет диктует не только привлекательность, но и где сейчас рвётся поток.

## Критерий готовности — перейти к S3 только после подтверждения

- [ ] 5-7 сегментов со всеми полями, каждое поле со ссылкой на источник (VoC/запрос/цифра) или `[нет данных]`.
- [ ] Чек и объём спроса — из учёта/Wordstat (факт); опыт/готовность/сложность помечены как оценка/[Г].
- [ ] Точки слома со ссылкой на конкурента/VoC.
- [ ] Приоритизация с привязкой к цели И ограничению.
