# S4 · Уровень осознанности (Шварц)

> **Фаза 2 · Фокус.** Цель: выбрать ОДИН уровень осознанности, с которого заходим. Не всегда с холодных, не всегда только горячих — уровень выбирается под проблему, силы, proof и доступный источник. Воронка строится ОТ выбранного уровня: ошиблись с уровнем — оффер, трафик и посадка говорят не в тот момент.

**Вход:** S3 (доминирующая сила).

## 1. Пять уровней осознанности

```text
1. Не осознаёт (unaware)        — «у меня всё нормально»
2. Осознаёт проблему (problem)  — подступ: «осознаёт симптом» → «надо понять причину»
3. Осознаёт решения (solution)  — «какие есть способы?»
4. Осознаёт продукт / вас (product) — «похоже, подходит, надо поверить»
5. Максимально осознан (hot)    — «нужно прямо сейчас, дайте следующий шаг»
```
Две позиции — **не уровни, а точки на CJM** (берём, только если работаем с базой): *зависший лид* (вошёл и застрял на барьере) и *существующий клиент* (стадия удержания).

## 2. Мост «доминирующая сила → уровень» (главное правило)

Уровень не выбирается «на вкус» — он выводится из сил (S3):

| Что доминирует в силах | Уровень | Что дать |
|---|---|---|
| push есть, слов для проблемы нет | осознаёт симптом | назвать проблему (чеклист, пост) |
| push сильный, ищет причину | осознаёт проблему | диагностику (scorecard / mini-screen) |
| pull сильный, активно сравнивает | осознаёт решения | разбор механизма, сравнение подходов |
| anxiety именно про нас/риск | осознаёт продукт | proof, пример результата, гарантии процесса |
| push+pull высоки, держит только habit | максимально осознан | прямой следующий шаг + снятие цены входа |

## 3. Карта уровней — где искать и что давать

| Уровень | Что в голове | Где искать / кого слушает | Что давать | CTA |
|---|---|---|---|---|
| Не осознаёт | "всё нормально" | лента, рекомендации, блогеры | контент с узнаваемой болью | подписаться / прочитать |
| Осознаёт симптом | "что-то не так" | посты, чаты, YouTube | назвать проблему, показать симптом | чеклист / видео |
| Осознаёт проблему | "надо понять причину" | поиск, экспертные посты | диагностика, scorecard | пройти диагностику |
| Осознаёт решения | "какие способы?" | обзоры, сравнения, кейсы | механизм, сравнение подходов | разбор / созвон |
| Осознаёт продукт | "надо поверить" | кейсы, отзывы, личка | proof, пример результата, гарантии | заявка / купить разбор |
| Максимально осознан | "нужно сейчас" | поиск, карты, каталоги, Avito | прямой оффер, цена, сроки | заявка / расчёт / оплата |

## 3a. Рекламный формат и угол по уровню

| Уровень | Формат касания | Угол / хук | Вход |
|---|---|---|---|
| Не осознаёт | охватное видео/пост, интеграция | «почему [проблема] случается, даже если…» | подписка / просмотр |
| Осознаёт проблему | чеклист/квиз/scorecard, пост-объяснение | назвать проблему и её причину | лид-магнит / диагностика |
| Осознаёт решения | сравнение подходов, вебинар, разбор | почему наш механизм ≠ альтернативы | разбор / созвон |
| Осознаёт продукт | кейсы, отзывы, пример результата, гарантии | proof под конкретный страх | заявка / расчёт |
| Максимально осознан | прямой оффер, карточка, форма/звонок | цена / срок / гарантия + срочность | заявка / оплата |

Конкретные каналы (Директ, РСЯ, VK, Telegram, Avito, карты…), таргетинг и экономика под каждый уровень — в S7.

## 4. Как выбрать уровень — скоринг

Оценить каждый возможный уровень по 0-2 (макс 14):

| Критерий | Вопрос |
|---|---|
| Срочность | клиенту надо решать сейчас? |
| Спрос | люди уже ищут/обсуждают это? |
| Доступ | можем до них добраться? |
| Proof | есть чем снять сомнение на этом уровне? |
| Оффер | можем дать понятный следующий шаг? |
| Скорость теста | будет сигнал за 14-30 дней? |
| Цена входа | канал не слишком дорогой? |

Выбираем уровень с лучшей суммой, с двумя ограничениями:
1. Нет proof → не идти сразу в «максимально осознан» на холодном рынке.
2. Нет понятного продукта → не запускать трафик, начинать с «осознаёт проблему» + диагностика.

## 5. Матрица офферов по уровням (какой оффер уместен)

| Уровень | Тип оффера |
|---|---|
| Не осознаёт | боль / узнавание |
| Осознаёт симптом | объяснение причины |
| Осознаёт проблему | диагностика |
| Осознаёт решения | механизм |
| Осознаёт продукт | proof |
| Максимально осознан | прямой вход (цена/срок/форма) |

## Критерий готовности — перейти к S5 только после подтверждения

- [ ] Выбран один уровень.
- [ ] Обоснование от доминирующей силы (мост из п.2).
- [ ] Понятно, где эти люди находятся и как формулируют (вход в источник S7).
