# S7 · Источник (реклама по уровню Шварца)

> **Фаза 3 · Сборка.** Цель: выбрать ОДИН проверяемый канал, где выбранный сегмент на выбранном уровне уже есть, и понять, **каким форматом и с каким углом** туда заходить. Один источник — чтобы тест был чистым.

**Вход:** S4 (уровень осознанности), S3 («первые 10 минут после слома» — прямая наводка на канал).

## 1. Принцип: канал = функция уровня и поведения после слома

Канал не выбирается «где умею». Он выводится из двух вещей: **уровня Шварца** (S4) и **что человек делает в первые 10 минут после слома** (S3). Ищет в картах/звонит → hot-каналы. Гуглит причину → поиск/проблемные. Листает ленту → охватные/проблемные соцсети.

## 2. Детальный подбор источника по уровню Шварца

> РФ-стек по умолчанию. Приём заявок — **Telegram + MAX + телефон + форма** (WhatsApp и Авито-чат не используем). Meta (FB/IG) и Google/TikTok — для не-РФ гео или где доступны.

### Уровень 1 — Не осознаёт (unaware)
- **Каналы:** РСЯ (охватные, авто-таргет) · VK Реклама (интересы, look-alike от базы) · посевы в Telegram-каналах · Дзен · блогер-интеграции · короткие видео (VK Клипы / Shorts / Reels). *Глобально:* Meta broad/interest, TikTok.
- **Формат:** охватное видео/креатив «узнавание боли», нативная интеграция, статья.
- **Таргет:** широкие интересы, look-alike от купивших, авто-таргет.
- **Угол/хук:** «почему [проблема] случается, даже если ты…» — показать симптом, ничего не продавать.
- **Вход/CTA:** подписка / чтение / просмотр (НЕ заявка).
- **Метрика:** охват, CPV/CPM, CTR, ER, прирост брендовых запросов и подписок.
- **Нюанс:** заявок сразу не даёт → **редко годится для 30-дневного теста**; берём, только если цель — растить спрос вдолгую.

### Уровень 2 — Осознаёт проблему (problem-aware)
- **Каналы:** Яндекс Директ Поиск (инфо/проблемные ключи) · РСЯ по проблемным ключам · Telegram Ads (по тематике и каналам конкурентов) · VK-таргет на проблемные сообщества · экспертный контент + промо · Дзен. *Глобально:* Google Search (problem terms), Meta problem-aware.
- **Формат:** пост-объяснение, чеклист, квиз/scorecard, видео «проблема не в X».
- **Таргет:** инфо-интент ключи, тематические сообщества/каналы, интересы + look-alike.
- **Угол/хук:** назвать проблему и причину — «дело не в лидах/цене, а в…».
- **Вход/CTA:** лид-магнит / диагностика / чеклист / квиз (мягкий вход), дальше прогрев.
- **Метрика:** CPL на лид-магнит, прохождение квиза, конверсия лид-магнит → заявка.
- **Нюанс:** нужен 2-й шаг (прогрев/дожим, S9) — закладываем в тест сразу.

### Уровень 3 — Осознаёт решения (solution-aware)
- **Каналы:** Директ Поиск (сравнительные ключи: «как выбрать», «способы», «X или Y») · РСЯ-ретаргет на вовлечённых · YouTube-обзоры/эфиры · VK/TG на читавших сравнения · вебинар. *Глобально:* Google Search comparison, Meta retargeting engaged.
- **Формат:** сравнение подходов, кейс-разбор, вебинар/эфир, гайд «как выбрать».
- **Таргет:** сравнительные ключи, ретаргет вовлечённых с уровней 1-2.
- **Угол/хук:** почему наш механизм ≠ альтернативы (из S3), разбор без воды.
- **Вход/CTA:** разбор / консультация / демо / вебинар.
- **Метрика:** CPL, конверсия в квал-лид / созвон.

### Уровень 4 — Осознаёт продукт / вас (product-aware)
- **Каналы:** ретаргет (РСЯ / VK / Telegram) по посетителям и вовлечённым · брендовый Директ · Яндекс Карты / 2ГИС / отзовики · email/CRM-касания · кейс-контент. *Глобально:* Meta retargeting/DPA, brand Search.
- **Формат:** кейсы, отзывы, пример результата (deliverable), гарантии, FAQ, «мы vs альтернатива».
- **Таргет:** ретаргет тёплых, брендовые ключи, look-alike от купивших.
- **Угол/хук:** proof под конкретный страх (anxiety из S3) + гарантия процесса.
- **Вход/CTA:** заявка / расчёт / купить разбор.
- **Метрика:** конверсия заявка → оплата, CPO/CPA, ROMI.

### Уровень 5 — Максимально осознан (hot)
- **Каналы:** Директ Поиск (транзакц. ключи «купить / цена / заказать» + гео) · Яндекс Бизнес / Карты (приоритетное размещение) · 2ГИС · Avito (объявления + продвижение) · брендовый трафик · ретаргет «брошенная заявка». *Глобально:* Google Search transactional, Google Maps/LSA, PMax/Merchant.
- **Формат:** прямой оффер (цена / срок / гарантия), карточка, форма/звонок, посадка на заявку.
- **Таргет:** транзакц. ключи + гео-радиус, горячий ретаргет.
- **Угол/хук:** прямой оффер + срочность + снятие последнего барьера.
- **Вход/CTA:** заявка / звонок / расчёт / оплата.
- **Метрика:** CPL, конверсия в оплату, CPO, ROMI, доля выкупа.
- **Нюанс:** самый быстрый сигнал за 30 дней → **приоритет для первого теста, если готовый спрос есть.**

## 3. Канал по механике решения (перекрёстная проверка)

- **срочный цикл** → поиск / карты / локально / отзывы (уровни 4-5);
- **отложенная потребность** → контент / разрешительный маркетинг / ретаргет (уровни 1-3);
- **долгий дорогой цикл** → несколько касаний / материалы по этапам / входные продукты;
- **узкий сегмент** → маркеры, сообщества, авторитеты, партнёрства.

## 4. Экономика и объём — тест обязан сойтись (гейт)

Прежде чем выбрать канал, проверяем сходимость на 30 дней:

```text
объём (запросы / аудитория) × CTR × конв. в заявку  ≥  N заявок за 30 дней
при CPL ≤ допустимый CAC (из S5, маржа юнита)?
```
- Не сходится (мало объёма ИЛИ CPL выше допустимого CAC) → **сменить канал или уровень**, не запускать заведомо нестатзначимый тест.
- Чем выше уровень (ближе к hot), тем быстрее и дешевле сигнал → для первого теста предпочитаем готовый спрос.

## 5. Атрибуция — без неё результат недоказуем

- **UTM-разметка** на все ссылки; отдельная посадка/лендинг под тест.
- **Колл-трекинг** (подменный номер) — иначе звонки не привяжутся к источнику.
- **Промокод / кодовое слово** — для офлайна и мессенджеров.
- **Один источник истины** (CRM), куда стекается всё. Определения совпадают с S1.

## 6. Критерии выбора источника

совпадает с уровнем · есть объём · есть доверие · можно донести оффер · **можно измерить (атрибуция стоит)** · экономика сходится · реально запустить своими силами.

## Критерий готовности — перейти к S8 только после подтверждения

- [ ] Один источник выбран: канал + формат + таргет + угол под уровень Шварца.
- [ ] Экономика теста сходится (объём × конверсия ≥ N заявок при CPL ≤ CAC).
- [ ] Атрибуция настроена (UTM / колл-трекинг / промокод / один источник истины).
- [ ] Понятно, куда ведём (посадка) и что считаем (метрика).
