# One Product Flow Scorecard v0.1

> Диагностика зрелости пути клиента вокруг одного продукта. Можно использовать как форму, пост, Tally/Google Form, Telegram-опрос или структуру mini-screen в личке.

## 1. Для кого

Для человека, у которого:
- есть один продукт/услуга/программа;
- уже были продажи;
- заявки идут случайно;
- контент, трафик, посадка и дожим не собраны в единую систему.

Не для тех, у кого продукта ещё нет.

## 2. Инструкция для клиента

Выберите один продукт, который хотите продавать стабильнее. Не весь бизнес и не все услуги.

По каждому пункту поставьте:

```text
0 - нет / не знаем / не используется
1 - частично / на ощущениях / есть кусками
2 - да / понятно / используется в продаже
```

Максимум: 30 баллов.

## 3. Вопросы

### A. Product Focus

1. У вас выбран **один фокусный продукт**, который нужно продавать стабильнее?
2. Клиент может понять за 10 секунд, что именно он покупает и какой следующий шаг?
3. У продукта понятен чек, маржа или хотя бы минимальная экономика?

### B. Buyer Job

4. Вы можете одной фразой сказать, какую проблему клиент "нанимает" этот продукт решить?
5. У вас есть 5-10 реальных формулировок клиентов: вопросы, сомнения, отказы, причины покупки?
6. Понятно, какой сегмент покупает продукт быстрее и дороже остальных?

### C. Доказательство для клиента

7. Есть 3-5 доказательств именно по этому продукту: кейсы, отзывы, цифры, фото/видео, разборы?
8. Эти доказательства закрывают главные страхи клиента, а не просто показывают "мы молодцы"?
9. Доказательство для клиента используется до заявки и после заявки, а не лежит в архиве?

### D. Touchpoints

10. Есть понятный путь: где человек впервые видит продукт, куда переходит, как оставляет заявку?
11. Контент/реклама/страница говорят одним языком, а не разными кусками?
12. После первого интереса человек получает следующий логичный шаг, а не "напишите нам" в пустоту?

### E. Конверсия и дожим по контексту

13. Есть сценарий обработки заявки: вопросы, квалификация, что отправить, как закрыть на следующий шаг?
14. Есть дожим по контексту для тех, кто заинтересовался, но не купил сразу?
15. Вы считаете минимум 3 метрики: касания/переходы, заявки/созвоны, оплаты/выручку?

## 4. Интерпретация

| Балл | Диагноз | Что это значит |
|---:|---|---|
| 0-8 | Продукт продаётся вручную | Нет системы. Реклама и контент будут усиливать хаос |
| 9-15 | Есть куски, но путь рвётся | Клиент где-то теряет смысл, доверие или следующий шаг |
| 16-22 | Есть рабочая основа | Можно чинить 1-2 главных места, где теряем клиента и запускать первые тесты |
| 23-27 | Система почти собрана | Нужно докрутить метрики, доказательство для клиента и дожим по контексту |
| 28-30 | Сильный продуктовый flow | Можно масштабировать трафик осторожно и измеримо |

## 5. Быстрый диагноз по блокам

| Блок | Максимум | Если низко |
|---|---:|---|
| Product Focus | 6 | Вы продвигаете слишком размыто, клиент не понимает продукт |
| Buyer Job | 6 | Вы говорите своим языком, а не языком покупки |
| Доказательство для клиента | 6 | Доверие не доходит до нужного момента |
| Touchpoints | 6 | Касания не складываются в путь |
| Конверсия и дожим по контексту | 6 | Заявки и интерес теряются после первого шага |

## 6. CTA после scorecard

### Если 0-15 баллов

> Вам рано масштабировать рекламу. Сначала нужно выбрать один продукт, собрать смысл, доказательство для клиента и следующий шаг. Можно начать с платного OPF Diagnostic: за 90 минут найдём 3 главных места, где теряем клиента и соберём план на 30 дней.

### Если 16-22 балла

> У вас уже есть основа. Скорее всего, деньги теряются в 1-2 конкретных местах: доказательство для клиента, посадка, обработка или дожим по контексту. Подходит OPF Diagnostic или короткий спринт.

### Если 23-30 баллов

> У вас зрелый flow. Вопрос не в "собрать с нуля", а в метриках, масштабировании и улучшении слабого блока. Подходит точечный аудит или спринт по одному узкому месту.

## 7. Сообщение для лички

```text
Давай быстро проверим один продукт по One Product Flow.

Выбери продукт, который хочешь продавать стабильнее, и ответь по 15 пунктам от 0 до 2.
Я посмотрю не весь маркетинг, а где именно рвётся путь:
продукт → клиент → доказательство для клиента → касания → заявка → дожим → метрики.
```

## 8. Внутреннее правило для Володи

Mini-screen бесплатно:
- максимум 3-5 наблюдений;
- без полноценной стратегии;
- без разбора всех каналов;
- без созвона "просто поболтать".

Платный OPF Diagnostic:
- карта, где теряем клиента;
- 3 приоритета;
- список материалов/касаний;
- что не трогать;
- next step.

## 9. Что фиксировать после каждого прохождения

| Поле | Зачем |
|---|---|
| Сегмент | Проверка beachhead |
| Продукт | Понимание, какие продукты подходят |
| Балл общий | Зрелость |
| Самый слабый блок | Повторяющиеся места, где теряем клиента |
| Фраза боли клиента | VoC |
| Готовность платить | Проверка спроса |
| Возражение | Материал для оффера |
| Следующий шаг | Диалог / диагностика / не подходит |

## 10. Ограничение

Scorecard не доказывает, что рост будет x2-3. Он показывает зрелость пути клиента и помогает выбрать, что чинить первым.
