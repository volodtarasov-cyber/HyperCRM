# S5 · Продукт / юнит

> **Фаза 3 · Сборка.** Цель: собрать продукт под выбранный сегмент и уровень — так, чтобы он закрывал работу и снимал доминирующий страх.

**Вход:** S1 (ограничение), S3 (силы, работа, язык), S4 (уровень).

## 1. Формула продукта

```text
проблема + сегмент + силы + уровень + результат + механизм + формат + доказательство для клиента + первый шаг
```
Продукт = ответ на Core Job выбранного сегмента, упакованный под его уровень осознанности.

## 2. Чек-лист юнита

- **Состав и границы** — что входит, что нет (пакеты/зоны).
- **Чек и маржа** — из учёта.
- **Целевой JTBD/сегмент** — под кого именно.
- **За что готов / не готов платить** — из критериев найма (S3).
- **Доказательства (доказательство для клиента)** — кейсы, фото, гарантия.
- **Низкострессовый первый шаг** — минимальный безопасный вход (снимает тревога перехода/инерция текущего способа).
- **Доминирующий КФВ** — ключевой фактор выбора, по которому клиент сравнивает.
- **Экономика** — допустимый CAC · частота · LTV · канал.

## 3. Четыре уровня ценности (проверить, какую реально даёт)

- **Функциональная** — решает задачу;
- **Эмоциональная** — как себя чувствует;
- **Меняющая жизнь** — сдвиг в большой цели;
- **Социальная** — как выглядит для других.

Слабый продукт бьёт только в функцию. Сильный — сознательно закрывает 2-3 уровня (функцию продаём, эмоцию снимаем, социальное подсвечиваем).

## Критерий готовности — перейти к S6 только после подтверждения

- [ ] Юнит собран: состав, границы, первый шаг, доказательство для клиента.
- [ ] Понятны чек/маржа и доминирующий КФВ.
- [ ] Первый шаг снимает доминирующий страх/инерцию (из S3).
