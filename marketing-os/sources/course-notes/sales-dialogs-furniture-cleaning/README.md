# Продажи в переписке и по телефону для химчистки мебели

**Спикер:** Данил — владелец химчистки мягкой мебели; в примерах — компания Eco Clean (по слайдам).
**Где лежит:** YouTube-канал «Тарасов Владимир // Ананас маркетинг», видео по ссылке от 2023-12-11. Владимир упоминается как соавтор: одна из техник называния цены взята у него.
**Состав:** 6 модулей, 15 видео, слайды к модулям → [[materials-notes|раздаточные материалы]]. Сам скрипт звонка, скрипт переписки и скрипты отработки возражений пока не получены.

**Назначение:** основа скилла продавца, по которому агентство пишет скрипты продаж под клиентов → [доп «Разработка скрипта продаж»](../../../../agency/product/boxes.md).

## Транскрипты

`transcripts/l01…l15.transcript.txt` — автоматические субтитры YouTube, вставленные вручную. Таймкоды приведены к виду `[м:сс]`, текст не правился. Уроки пронумерованы в порядке получения; он совпадает с логикой курса.

> Распознавание ошибается в названиях оборудования, химии и в именах. Конспекты собраны по смыслу; замечания ассистента отделены от тезисов спикера.
