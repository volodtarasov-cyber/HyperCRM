# Ключи для карт: химчистка, прачечная, ремонт одежды — универсальный список

**Проверено:** 2026-11-03

**Где применяется:** продвижение карточек в Яндекс Картах и 2ГИС, [ответы на отзывы](../playbooks/reputation-review-responses.md), посты и новости для карт ([geo-news-production](../playbooks/geo-news-production.md)).

**Как пользоваться:** список — стартовый набор для любого клиента этой ниши. Берём только те ключи, которые клиент реально оказывает: сверка со списком услуг идёт до публикации, а не после. Ключ в ответе на отзыв — по [правилам площадки](../../knowledge/rules/yandex-maps-reviews.md): точная форма без склонения, 1–2 в позитиве, 1 в негативе.

## Откуда список

- Первые 48 строк — набор Володи, общие и «рядом / цены / отзывы» запросы.
- Следующие 37 — ядро Unisec Новосибирск: самые частотные активные фразы по точной частотности `[!WS]`, Wordstat от 2026-09-28 → [семантика Unisec](../../clients/unisec-novosibirsk/semantics/cluster-summary.md).
- Последние 14 — следующий слой того же ядра, выбраны по смыслу без дублей.

Частотность во всех этих данных относится к Новосибирску. Для другого города частоты надо мерить заново, а порядок и состав — проверять по спросу.

## Что подтверждать у клиента перед использованием

Эти ключи в список входят, но используются только если услуга есть:

- **На дому, выезд на дом, доставка на дом** — формат у Unisec не подтверждён и в запуск не входил.
- **Стирка спецодежды** — B2B, отдельный контур.
- **Биочистка, озонирование** — специальные услуги, у Unisec подтверждены не все.
- **Для инвалидов, оплата картой, акции, скидки, вежливый персонал, время ожидания** — не услуги, а свойства сервиса: в ответах и постах можно использовать, только если факт подтверждён. Про скидку за отзыв писать нельзя.
- **Ковры и мебель** в список не входят: у Unisec их нет.
