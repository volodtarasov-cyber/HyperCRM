# Marketing OS — система коммерческого исследования

## 0. Основание

### Архитектура Хранения

- Скрининг организации
  - верхний уровень проекта
  - `_dashboard.md`
  - `_index.md`
  - отчеты screening / scorecard
- Продуктовые подпроекты
  - папка продукта / воронки
  - `_dashboard.md` — стадия и текущая связка
  - `research/` — карты, доказательства, CJM, сегменты
  - `yougile-task-export.md` — список задач для переноса
  - оффер / лендинг / скрипты / креативы
- Правило
  - организация задает ограничения и приоритеты
  - продуктовая папка владеет внутренней воронкой
  - YouGile владеет исполнением задач
