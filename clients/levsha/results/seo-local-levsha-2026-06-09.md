## 🔴 Critical / High (под Самару)

**1. Нет связки сайт ↔ Яндекс.Карты / 2ГИС.**
В РФ локальную выдачу решают именно они. На сайте нет ни ссылок, ни виджета карты, ни отзовик-блока. Нужно:
- убедиться, что карточки **заведены и верифицированы** в Яндекс.Бизнес и 2ГИС;
- проставить на сайт (футер/контакты) ссылки на них + виджет Яндекс.Карт;
- категория в карточке = **детейлинг** (правильная основная категория — фактор №1 локального ранжирования).

**2. Нет LocalBusiness-схемы** (0 JSON-LD на сайте). Готовый блок — ниже, ставить на главную и/или контакты.

**3. H1 главной = «Записывайтесь»** (из общего аудита) — должен быть локальный: «Детейлинг-центр Левша в Самаре». Сейчас гео-сигнал в H1 потерян.

**4. Отзывы — главный недомерянный рычаг.**
В РФ это отзывы на Яндекс.Картах и 2ГИС. Правило ритма: без новых отзывов 2-3 недели — позиции в локале проседают. Нужна система запроса отзыва (привязать к твоему постплёночному маршруту: касание +1 день уже содержит NPS → довольных вести на Яндекс/2ГИС). **Связка с post-film-care-pilot-plan.md.**

## Готовая LocalBusiness-схема (поставить на сайт)

`AutomotiveBusiness` — ближайший тип под детейлинг. Гео и часы — заполнить точными (координаты взять из Яндекс.Карт, 5+ знаков после запятой):

```json
{
  "@context": "https://schema.org",
  "@type": "AutomotiveBusiness",
  "name": "Детейлинг-центр «Левша»",
  "image": "https://levsha-group.ru/<фото-студии>",
  "url": "https://levsha-group.ru/",
  "telephone": "+7-846-211-63-11",
  "email": "info@levsha163.ru",
  "priceRange": "₽₽",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "ул. Ново-Садовая, 162Б",
    "addressLocality": "Самара",
    "addressRegion": "Самарская область",
    "postalCode": "<индекс>",
    "addressCountry": "RU"
  },
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": "<широта из Я.Карт>",
    "longitude": "<долгота из Я.Карт>"
  },
  "openingHoursSpecification": [
    {"@type":"OpeningHoursSpecification","dayOfWeek":["Monday","Tuesday","Wednesday","Thursday","Friday","Saturday","Sunday"],"opens":"<чч:мм>","closes":"<чч:мм>"}
  ],
  "sameAs": [
    "https://vk.com/levshapro",
    "https://t.me/levshasamara",
    "<ссылка на карточку Яндекс.Карт>",
    "<ссылка на карточку 2ГИС>"
  ]
}
```
