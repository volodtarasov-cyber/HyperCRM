# Стандарт работы с клиентом @agency

**Проверено:** 2026-11-11

> Один стандарт для всех клиентов (решение Володи 2026-11-11, заменяет приоритеты P_1–P_3 от 2026-09-15). Путь клиента — нишевый продукт или услуга под задачу — и состав работ → [каталог](../agency/product/boxes.md#два-пути-продажи-решение-2026-11-11); путь каждого клиента → [реестр](_index.md).

| | Стандарт |
|---|---|
| Ответ клиенту, в рабочее время | 30 минут |
| Отчёт | раз в 2 недели: кабинет + данные клиента; разборы с собственником — по составу пакета |
| Главная метрика | стоимость [квалифицированного обращения](../marketing-os/core/glossary.md#term-qualified-inquiry), если клиент даёт данные о квалах; иначе стоимость [лида](../marketing-os/core/glossary.md#term-lead) |
| Диалоги покупателей | по каналам, которые ведём, читаем и выгружаем для внутренней аналитики |
| Работа с продажами | входит в нишевый пакет; на пути услуг — отдельная услуга под задачу. Разбираем основные ошибки в диалогах и звонках, метрика — [CAC](../marketing-os/core/glossary.md#term-cac), отчёт раз в неделю до денег; скрипт продаж — разовый доп |

Покупателям в диалогах отвечает клиент — агентство не ведёт переписку ни на одном пути.

**Кабинет + данные клиента** — расход → обращения → стоимость обращения → стоимость квалифицированного обращения по квалам клиента; деньги клиента показаны рядом, но нашей метрикой не являются.
**До денег** (работа с продажами) — расход → обращения → квалифицированные → продажи → сумма, и всё это наша метрика.

Если клиент не дал данные к отчёту, их строка остаётся пустой с пометкой, а не исчезает.

Премии за квал нет. Премия за доход — только когда продажи связаны с источником → [тариф](../agency/product/boxes.md#как-растёт-чек).
