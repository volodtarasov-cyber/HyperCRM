## Что куплено

Продуктовые единицы из [каталога коробок](../../agency/product/boxes.md). Одним чеком снаружи — разложением внутри.

| Единица | Что входит | Кто исполняет |
|---|---|---|
| | | |

Что **не** куплено — назвать явно. Граница продажи важнее состава: она решает, за что мы отвечаем в разговоре через три месяца.

## Данные клиента

| Что | Ответ |
|---|---|
| Что клиент возвращает (только заявки / квал / продажи по источнику) | |
| Откуда берётся (CRM, кабинет, свои переписки, таблица, на словах) | |
| Кто передаёт и с какой периодичностью | |
| Чего не хватает до следующего шага | |

То, что клиент возвращает, определяет допустимое обещание: продажи по источнику — можно продавать [уровень 3](../../agency/product/boxes.md#три-уровня-как-растёт-чек) и премию за доход. Перевести канал на следующий уровень обычно сильнее, чем добавить канал.

## Результат

Только измеренное: период, вложено, обращения, стоимость обращения, продажи, сумма. Оценка со слов помечается как оценка.

| Период | Единица | Вложено | Обращений | CPL | Продажи | Сумма |
|---|---|---:|---:|---:|---:|---:|
| | | | | | | |

Кейс, когда результат подтверждён и клиент разрешил → [agency/cases/](../../agency/cases/_index.md).
