# Формат: рассылка по базе (мессенджер)

Источник: скилл copywriter-a, [russian-copywriter-skill](https://github.com/kachkanfim369-svg/russian-copywriter-skill) (MIT, автор Дима, @dima_dima369). Нормы — заявленные автором, не наши замеры: после первой реальной рассылки сверяем с фактом.

## Единица

Одна рассылка = один смысл и одно действие. Если смыслов два — это две рассылки. Рассылка читается без предыдущей и следующей: на вчерашнее можно сослаться одной фразой, но суть внутри. Сообщение автоворонки — тоже рассылка.

## Нормы

- Длина 300–1300 знаков; чуть лучше работает 800–1300, короткие не хуже среднего.
- Имя читателя в тексте или первой строке. Переменная (`{имя}`, `%name%` — уточнить, как подставляет система клиента) только в именительном падеже или в обращении: «{имя}, это для вас», не «для {имя}».
- Обращение на «ты» или «вы» — по проекту клиента. Без указания пола: «тебе», а не «дорогая».
- Абзац 1–3 строки, между абзацами пустая строка.
- Перед призывом палец: 👇 если ссылка ниже, 👉 если справа. Время и дату события выделяем.
- Действие названо от первого лица: «Записываюсь», «Забираю», «Хочу во вторник». Не «перейдите по ссылке».
- **Три ссылки** подряд, одинаковые по тексту, каждая — CTA от первого лица: `ЗАБРАТЬ ПОДАРОК: ссылка` ×3. Ссылки уникальные (разные UTM), иначе клики не различить.
- Ключевые мысли выделяем. Капс — для эмоции, не на весь текст; «!!!» и растянутые слова («УЖЕ БЕГУУУ») допустимы только в рассылках по базе и только если это голос клиента.
- Цепочка по базе — не длиннее 3 дней. Два сообщения подряд с одним углом не отправляем.

## Эмодзи

- Короткий текст: 1–3. Средний: 4–5. Длинный: не больше 7.
- Эмодзи приучают глаз, а не украшают.
- **Один смысл = один эмодзи, всегда тот же.** Время 🔔, подарок 🎁, деньги 💰, срочность 🚨.
- Выделяем время и дату, оффер, реальные триггеры (сгорающие места, истекающее время).

## Бонус-хвост

К утренней и вечерней рассылке допустим второй блок через разделитель `______` — например, доступ к закрытому каналу с подарками. Он добавляет второе действие и не заменяет главное. Бонус только реальный.

## Пример: слабо → сильно

Слабо:

```
Друзья! Уникальное предложение для вас! Запишитесь на пробное занятие в нашей студии и откройте для себя мир танца! Количество мест ограничено!
```

Сильно:

```
{имя}, вы смотрели наше видео про первое занятие 💡

Пишу лично, потому что вы досмотрели до конца, а таких немного.

Пробное занятие длится 45 минут. Приходите в удобной одежде, остальное возьмём на себя. В группе начинающих в этот вторник свободно 4 места из 12.

👇 Напишите в ответном сообщении «Хочу во вторник», и я запишу вас

[НУЖНО: подтвердить дату и число мест]
```

Есть причина написать именно этому человеку, конкретика (45 минут, 4 из 12), одно действие от первого лица.

## Самопроверка

1. Один смысл, одно действие, читается без соседних?
2. Первая строка даёт причину открыть сейчас (→ [hooks.md](hooks.md))?
3. Каждый факт — от клиента; пробелы помечены `[НУЖНО: …]`?
4. Длина 300–1300, эмодзи по норме, палец перед призывом, переменная имени не склоняется?
5. Финальный проход — `/humanize-text` с корректором.
