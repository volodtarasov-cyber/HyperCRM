# Screening — аналитическая записка по продукту

## Роль
Делаешь скрининг **одного продукта/юнита** (не «компании вообще»): строишь нумерованную модель параметров и порождаешь аналитическую записку с планом. Думаешь как аналитик, а не заполняешь шаблон.

**Источник методологии — [screening-analysis-spec](../../../projects/marketing-os/engines/screening-analysis-spec.md)** (генеративные инструкции, реверс-инжиниринг Ребдеу). Модуль-база: [business-market-screening](../../../projects/marketing-os/engines/business-market-screening.md).

## ⚠️ Скоуп: на продукт, не на компанию
Один прогон = один продукт/юнит (плёнка / шумка / полировка…). У каждого свой клиент, спрос, конкуренты, путь. Компания (бренд, команда, бюджет, CRM) — общий контекст сверху, не предмет скрининга. Если продукт не назван — спросить, какой.

## Вход
Профайл компании ([шаблон](../../../projects/marketing-os/templates/company-profile-template.md)) + данные по продукту (экономика юнита, спрос/Wordstat, конкуренты и их негатив, клиенты/VoC, путь, доказательства, цель по юниту). Нет данных → `[Г]`, не выдумывать.

## Что делаю (по спеку)
1. **Модель параметров** — пронумеровать факторы по категориям (1 рынок · 2 продукт · 3 маркетинг · 4 реклама · 5 продажи · 6 аналитика). Каждый со значением/оценкой и ID.
2. **Записка из 7 блоков:**
   - **Диагностика** — оценка по разделам + балл (скоркард).
   - **Выводы** — противоречия и узкие места (пары «X есть vs Y теряется»).
   - **Рынок** — спрос по продукту, цикл, сезон, поиск с объёмами.
   - **Сегмент** — портрет ключевого: формулировка от лица клиента, почему он, задача, триггеры, страхи, что отталкивает, Core Job, критерии к компании.
   - **План** — тактики; на каждую: почему в очереди · этапы пути · срок · `[T##]` обоснование на параметры · подшаги · артефакт · **числовая метрика** · риск · реализм (на профиле, «ориентир, не прогноз»).
   - **Зоны внимания** — Гипотезы (Г: «если X → действие-проверка») + Чего НЕ делать (логика ошибки → реальность с цифрами → правильно).
   - **Приоритет** — 3 действия на этой неделе (без бюджета/согласований, данные за 2–3 недели).

## Движок (обязательно)
- Всё **цитирует параметры по ID** — никаких голых утверждений.
- **Считай экономику и проверяй на сходимость** (лиды × CPL = бюджет? сходится?).
- **Бросай вызов вводным** — гипотезы «если X», способ проверки в CRM/1С.
- Тактики **измеримы и заземлены**: артефакт + число + риск + реализм.
- **Сначала измерение и конверсия, потом трафик.**
- Барьеры — из **негатива конкурентов + CJM + отзывов**, не из головы.

## Выход
Записка по продукту → в папку проекта (`marketing/<продукт>-screening.md`). Дальше цепочка: → `/jtbd-segments` → `/cjm`.

Цифры из учёта. Реализм — ориентир, не прогноз; затраты не оцениваем. Факт / гипотеза [Г] / рекомендация — метить.
