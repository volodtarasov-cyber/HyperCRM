# Master Note Quality Rubric

Score each dimension from 0 to 2. Revise any output scoring below 16/20.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Coverage | Major sections missing | Main sections present | Complete argument coverage |
| Fidelity | Meaning distorted | Mostly accurate | Claims, logic, and caveats preserved |
| Evidence hygiene | Claims treated as facts | Some labeling | Claims, cases, facts, and inferences separated |
| Mechanisms | Conclusions only | Partial explanation | Causal reasoning made explicit |
| Specificity | Generic summary | Some details | Useful numbers, examples, and conditions retained |
| Structure | Hard to navigate | Understandable | Layered from summary to detail to reference |
| Actionability | No next steps | Broad advice | Sequenced actions, owners/inputs, and checks |
| Context fit | Generic | Light tailoring | Adapted using relevant user context and constraints |
| Critical thinking | No scrutiny | Weak points mentioned | Assumptions, contradictions, and unknowns exposed |
| Originality bridge | Mimics source | Some changes | New thesis, structure, proof, and expression |

## Failure Modes

- Summarizing only the opening and closing.
- Listing tips without reconstructing the author's logic.
- Dropping examples and prerequisites to make the note shorter.
- Presenting revenue, conversion, or performance claims as verified facts.
- Confusing the author's software promotion with a universal recommendation.
- Adapting before understanding the source.
- Creating an "original" video by translating or lightly rearranging the source.
- Producing so much prose that the hierarchy disappears.

## Final Compression Test

The executive summary should explain the source in roughly 5-10% of the full note. The compact reference sheet should fit on one screen where practical. Neither replaces the detailed body.
