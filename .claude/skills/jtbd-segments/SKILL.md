# JTBD Segments — сегментация продукта по работам (генеративно)

## Роль
Сегментируешь **один продукт/юнит** по работам. Думаешь как аналитик, не заполняешь поля. Полная методология — модуль [niche-icp-jtbd-research](../../../projects/agency-os/modules/niche-icp-jtbd-research.md), раздел «Генеративный спек».

## ⚠️ Скоуп: под продукт, не под компанию
Один прогон = один продукт (плёнка / шумка / полировка…). У каждого свой клиент и спрос. Продукт не назван → спросить.

## Что делаю
1. **Тип ниши** (мягкая/жёсткая). Мягкая → сегментировать по работам.
2. **5–7 сегментов**, на каждый: **Core Job** (от лица клиента: «когда X, хочу Y, чтобы Z») · Big Job · критерии выполнения · кто это/триггер · **тип опыта А/Б** · **разрыв/точка слома** · привлекательность (чек+спрос) · готовность купить · сложность убеждения · мотивация-лейбл.
3. **Приоритизация:** ядро / быстрые деньги / не первым.
4. **Глубина по beachhead — 4 силы** (для ВЫБРАННОГО приоритетного сегмента). Разложить силы прогресса: **push** (толкает от «как есть») · **pull** (притягивает к новому) · **anxiety** (страх перемен и нас) · **habit** (держит на старом) + критерии найма/увольнения + дословный язык клиента (VoC). Прогресс = Push+Pull > Anxiety+Habit; оффер усиливает push+pull, гасит anxiety+habit. **Доминирующая сила → уровень осознанности для входа** (мост к `/cjm`). Полная механика — [OPF jtbd-module](../../../projects/one-product-flow/method/jtbd-module-2026-07-06.md).

## Движок (думай так)
- **Точку слома НЕ выдумывай** — бери из **негатива конкурентов** (отзывы) + CJM + своих отказов. Точка слома = барьер CJM = негатив конкурента (кросс-ссылка).
- **Опыт А/Б → тип контента** (А впервые → обучающий; Б → «лучше привычного»).
- **Привлекательность с цифрами:** чек + поисковый спрос **с объёмом** («бронепленка купить — 86/мес»).
- **Приоритет условен:** (а) цель бизнеса (поток vs премиум-маржа); (б) **текущее ограничение** (простаивающую мощность грузим, даже если сегмент «сложный»).

## Планка качества
✅ Core Job от лица клиента · точка слома со ссылкой на конкурента/VoC · спрос с объёмом · приоритет с привязкой к цели И ограничению.
❌ абстрактные сегменты · барьеры из головы · приоритет «по ощущению».

## Вход / выход
Вход: продукт + скрининг + профайл + негатив конкурентов + VoC. Нет данных → `[Г]`.
Выход: карта сегментов продукта → `marketing/<продукт>-jtbd.md`. Дальше → `/cjm`.
