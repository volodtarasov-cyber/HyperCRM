# Personal CRM — Vault для решений, гипотез и проектных материалов

## Что это

Vault на Claude Code + Obsidian + Google Sheets для работы с проектами через диалог.

**Задачи живут в YouGile** (с 2026-05-13). Vault — это база знаний, стратегия, решения, гипотезы и рабочие материалы. Не задачник, не дневник.

## Для кого

Один человек (маркетинг + продажи) + агентская команда. 2-3 проекта параллельно.

## Команды

| Что сказать | Что произойдёт |
|-------------|---------------|
| «зафиксируй решение» | Запись в `life/decisions.md` (стратегия) или в `hypotheses.md` проекта |
| «зафиксируй гипотезу» | Запись в `projects/*/hypotheses.md` по формату |
| «статус [проект]» | Обзор по `_index.md` + гипотезам + свежим артефактам проекта |
| «неделя» / «ретро» | Недельный обзор **по запросу** — собирается из материалов, не из дневника |
| «отчёт в десятку» | Помощь собрать черновик; дедлайн вс 23:59 Володя помнит сам |
| «отчёт для [клиент]» | Клиентский отчёт по трафику |
| «разбери inbox» | Раскидать записи из `inbox.md` по нужным файлам |

## Быстрый захват

Файл `inbox.md` в корне — свалка для мыслей, идей, ссылок.
Разбирается по запросу.

## Структура

Подробно — в `CLAUDE.md`. Кратко:

```
vault/
├── CLAUDE.md             ← мозг системы
├── README.md
├── inbox.md              ← быстрый захват
├── projects/
│   ├── detailing-samara/   ← основной проект
│   ├── ai-infobiz/         ← контент-машина
│   └── traffic-freelance/  ← агентский портфель
├── life/                 ← decisions.md, ten-report/, финансы
├── team/                 ← команда агентства
├── knowledge/            ← фреймворки (JTBD, Hormozi, RDB, Шварц, AARRR)
└── system/
    ├── changelog.md      ← история изменений системы
    ├── templates/        ← шаблоны (актуальные)
    └── migrations/       ← разовые миграции (YouGile export и т.д.)
```

### Архив (заморожено с 2026-05-13)

```
├── tasks.md              ← старый журнал задач
├── recurring/tasks.md    ← старые ритуалы
├── daily/                ← старые daily-планы
├── reviews/              ← старые недельные обзоры
└── projects/*/backlog.md ← старые бэклоги
```

Эти файлы оставлены как история. Новые записи туда не делаются.

## Приватность

1. **Только я** — `life/`, `team/`, `daily/` (архив), `_notes.md` в проектах
2. **Для клиента** — `projects/*/reports/`, Google Sheets
3. **Шаблон для передачи** — структура + `CLAUDE.md` + актуальные шаблоны, без данных
