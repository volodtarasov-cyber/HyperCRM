# Jobs To Be Done — Фреймворк

> Канонические определения терминов → [словарь Marketing OS](../../marketing-os/core/glossary.md). Этот файл объясняет фреймворк, но не является вторым словарём.

## Суть
Люди не покупают продукты. Они "нанимают" их для выполнения работы (job) в своей жизни.

## Формула Job Story
**Когда** [ситуация/контекст], **я хочу** [мотивация/действие], **чтобы** [ожидаемый результат].

## Четыре силы переключения
1. **[Давление текущей ситуации](../../marketing-os/core/glossary.md)**.
2. **[Притяжение результата](../../marketing-os/core/glossary.md)**.
3. **[Тревога перехода](../../marketing-os/core/glossary.md)**.
4. **[Инерция текущего способа](../../marketing-os/core/glossary.md)**.

Определения и границы живут только в карточках по ссылкам выше. Здесь фиксируется отношение сил: `давление + притяжение > тревога + инерция`.

## Как применять
1. Выпиши все "работы", для которых клиент мог бы нанять продукт
2. Для каждой работы опиши 4 силы
3. Определи главную работу — где давление и притяжение достаточно сильны для изменения
4. Строй оффер и коммуникацию вокруг этой работы

## Ошибки
- Путать Job с фичей продукта
- Описывать Job слишком абстрактно
- Игнорировать тревогу перехода и инерцию текущего способа
