# Jobs To Be Done — Фреймворк

## Суть
Люди не покупают продукты. Они "нанимают" их для выполнения работы (job) в своей жизни.

## Формула Job Story
**Когда** [ситуация/контекст], **я хочу** [мотивация/действие], **чтобы** [ожидаемый результат].

## 4 силы переключения
1. **Push** — недовольство текущей ситуацией (что бесит сейчас)
2. **Pull** — привлекательность нового решения (что манит)
3. **Anxiety** — страхи перед новым (а вдруг не получится)
4. **Habit** — привычка к текущему (и так нормально)

Переключение происходит когда Push + Pull > Anxiety + Habit.

## Как применять
1. Выпиши все "работы", для которых клиент мог бы нанять продукт
2. Для каждой работы опиши 4 силы
3. Определи главную работу — где Push + Pull максимальны
4. Строй оффер и коммуникацию вокруг этой работы

## Ошибки
- Путать Job с фичей продукта
- Описывать Job слишком абстрактно
- Игнорировать Anxiety — именно он убивает конверсию
