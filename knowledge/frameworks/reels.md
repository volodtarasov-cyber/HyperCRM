# Reels / Shorts — короткие видео с хуками (2026)

> Рабочая шпаргалка для необязательного агентского контента @lazyhim. Собрано из практики + веб-разведки 2026-06-09.
> Связано: [positioning](../../projects/ai-infobiz/product/positioning.md), [content-pipeline](../../projects/ai-infobiz/content-pipeline.md).

## Главное правило — первые 3 секунды
До 50% уходят в первые 3 сек. Хук решает всё.
- **Pattern interrupt:** никаких лого, интро, «привет, сегодня расскажу». Сразу в самый сочный момент.
- **Хук = одно из:** дерзкое утверждение / вопрос / контрарианство / разрыв любопытства / шок-визуал. Драйверы — любопытство, удивление, эмоция, узнавание.
- **Текст на экране с первого кадра** — 50% смотрят без звука, хук должен читаться глазами.

## Структура (образовательный контент)
`Хук (0-3с) → Проблема → Быстрое решение → Доказательство → CTA (последние 3-5с)`
Этот паттерн — выбор №1 у 73% аудитории.

Базовый каркас удержания: `Хук (0-3с) → Тело/эскалация (3-80%) → Payoff (последние 15-25%) → CTA/loop`.

## Удержание важнее длины
10 сек с 80% досмотра бьют 60 сек с 30%. Хочешь длиннее — заслужи каждую секунду.
- Движение / jump-cut в первые 3с → +72% к виральности.
- Спад внимания добивай микро-сменами: план, ракурс, текст, перебивка.

## CTA по данным
- «**Сохрани**» — поднимает охват на 7-14 дней (для рилс мощнее лайка).
- «Напиши **слово** в комменты» — ×1.5-2.2 к комментам.
- B2B / экспертка — хуки на доказательстве и цифрах на экране.

## Хуки — сильные паттерны
- Жёсткая правда / скрытая цена («Твой ИИ врёт тебе про конкурентов»).
- Контраст до/после, иллюзия/реальность.
- «Раньше думал X — теперь понимаю Y».
- Конкретная цифра в первой строке.
- Сцена, намекающая на урок побольше.

## Шаблон сценария (talking head, 50-70 сек)
| Тайминг | Что | На экране |
|---|---|---|
| 0-3с | ХУК (разрыв любопытства) | крупный текст-хук |
| 3-8с | проблема / вопрос | подпись |
| 8-15с | разворот / секрет | jump-cut |
| 15-40с | суть по пунктам | по слову на пункт |
| 40-55с | payoff (результат + цифра) | `9 из 10 · за 30 мин` |
| 55-65с | CTA (сохрани + ютуб) | `СОХРАНИ · разбор на YouTube` |

**Темп:** говоришь быстро, без пауз, jump-cut на каждой смене мысли. Снимай телефоном, без вылизанного монтажа — сырое от практика заходит лучше глянца.
