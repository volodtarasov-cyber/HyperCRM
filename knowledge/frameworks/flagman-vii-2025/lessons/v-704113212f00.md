# Два способа расширить каркас до гибридной структуры

**Источник:** Антон Маркин, «Флагман VII» (2025), трафик, часть 1 → методы расширения.
**ID:** `v-704113212f00` · около 9 минут. **Прочитан:** полный транскрипт. **Дата:** 2026-10-29.
**Полный текст:** [транскрибация](../../../../.tools/local/flagman-vii/transcripts/v-704113212f00.md).

## 00:00–04:09. Уточнить основу

На входе каркас одного сайта, на выходе нужна гибридная структура, объединяющая полезные направления лидеров. Организационные хабы файла не обязательно будут реальными страницами: они служат группировке и могут не иметь собственной семантики.

Автор исправляет работу своего помощника: «цены» следует конкретизировать до «цен на бурение скважин». «Карта глубин» даёт озёра и реки, поэтому ищет подходящий URL и его видимость в Keys.so, выбирает «карта глубин скважин на воду». Регион зависит от проекта. Это демонстрация того, почему ветка должна обозначать самостоятельный смысл, а не любое название из меню. Детальная актуализация ещё впереди, но осмысленное название сокращает будущую работу.

Разделы коммерческих факторов уже собирались в аудите; их можно оставить в этой карте для удобства либо вести отдельно. Они не заменяют семантическое расширение.

## 04:09–08:15. Две методологии

| Метод | Действие | Предпочтения и ограничения автора |
|---|---|---|
| По конкурентам | Выгрузить видимость лидера с привязкой запросов к URL, дополнять каркас недостающими направлениями | Часто удобен для услуг; в каталогах может давать много мелких товарных данных |
| По семантике | Получить запросы, кластеризовать, по группам дополнить каркас | Иногда удобнее для каталогов |

Каждая группа включает много вариантов. В основном блоке показывается по одному, а не все возможные способы. Ниша и источник влияют на результат: один сервис может дать слабую выгрузку, другой в той же теме — качественную. Упомянуты Keys.so, SpyWords и Мутаген. Для специфических, в том числе серых тематик часть способов может быть неудобна или недоступна.

Потоковый специалист часто выбирает один удобный вариант и работает им. Это авторское описание практики, не требование всегда ограничиваться одним источником.

## 08:15–09:24. Когда сочетать

При приоритете глубины и качества пройти расширение по конкурентам **и** по семантике, затем при необходимости использовать дополнительные источники из отдельных материалов. Для основного учебного процесса автор считает достаточным выполнить показанные шаги; дополнительных способов не объявляет обязательными для каждого проекта.

**Вход:** логически сгруппированный базовый каркас. **Выход урока:** выбор источников расширения с учётом типа сайта и цели по глубине. **Критерий:** название ветки осмысленно, источник даёт пригодные данные, вариант процесса выбран сознательно.
