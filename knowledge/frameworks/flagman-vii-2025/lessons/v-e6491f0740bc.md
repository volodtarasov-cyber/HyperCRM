# Скрытие частей контента: уточнение методов

## 00:00–04:06. Не полагаться на один JavaScript

Лектор возвращается к собственной экспериментальной статье. В тесте сочетание noindex/Google Off чаще скрывает фрагмент от Яндекса, но не от Google. Обычные JavaScript и AJAX больше не считает надёжным универсальным способом и для Яндекса: часть проверяемого текста уже находится поиском. Настройка рендеринга в Вебмастере тоже описывается как рекомендация без гарантии.

Предпочтительный по его опыту вариант: нужный фрагмент подгружается AJAX из отдельного файла, который сам закрыт в robots.txt для нужных роботов. На примере третьего уровня меню показывает отдельную загрузку и соответствующий запрет. Объявление способа универсально работающим — **вывод лектора по своим тестам**, не наша внешняя проверка. Полный скрипт обещан приложением, из речи его нельзя восстановить точно.

## 04:06–06:13. CSS и копирование

Второй предпочтительный вариант — `content` в CSS-псевдоэлементах `::before/::after`: текст присутствует в стилях, а не в обычном HTML-блоке. Считает это также затруднением обычного копирования и типового парсинга конкурентов, но признаёт возможность специально настроить парсер. Это не абсолютная защита содержимого.

Визуальная демонстрация, копирование и поиск тестовой строки решают разные вопросы; частный результат на его статье не превращается в обещание для любой реализации.

## 06:13–09:19. Остальные варианты и границы

Текст картинкой считает обычно неучитываемым, но прямо допускает распознавание при отдельной задаче поисковика. Атрибуты, по его новым наблюдениям, читаются обоими поисковиками; больше не предлагает использовать их как скрытие.

Iframe признаёт историческим рабочим вариантом, но не рекомендует из-за архитектуры. Клоакинг объясняет как различное содержимое по User-agent; для небольших элементов считает применимым, **одновременно признаёт возможность санкций**, хотя лично их не встречал. WebWorker считает излишне сложным и ненадёжным относительно будущего рендеринга.

**Итог автора:** основной выбор — AJAX с закрытым ресурсом либо CSS-псевдоэлементы; небольшое разовое скрытие допускает через User-agent с оговоркой. Это уточняет прежний [урок индексации](v-3e0bed8993c3.md): простой JavaScript не объявляется гарантированно невидимым.

**Вход:** конкретный фрагмент и цель его исключения. **Выход:** выбранная по модели лектора реализация и тест по целевым роботам. **Приёмка:** не перепутано визуальное скрытие с отсутствием в поисковом документе, готовый код взят из реального приложения/проекта и проверен, ограничения метода сохранены. Полного универсального кода этот текст не содержит.
