## Механизм — 00:00–00:06

Лектор предлагает брать коммерческие формулировки из органической семантики крупного тематического агрегатора. Для товаров демонстрирует Яндекс Маркет: Мутаген → мегаинструмент → отчёт по домену → ключи в органике. Это источник запросов, а не готовая структура собственного сайта.

В фильтр «ключ содержит любое из» передают подготовленные базисы без окончаний. Пример для сантехники — основы «кран» и «смесит». Частичное совпадение приносит также башенные краны, отопительную арматуру и другие темы. Этот избыток допускается на входе: важнее полнота базисов и последующая чистка.

Минусовать прямо в отчёте можно только очевидно неподходящее. Подстроки многозначны: «экран» может обозначать предмет около раковины; «Алиса» — интеграцию умного дома. Лектор предостерегает от исключений без знания ассортимента.

## География и выгрузка — 00:08–00:12

Фильтр наличия топонима позволяет отдельно скачать запросы без географии и с географией. Для своего региона можно дополнительно использовать текстовые варианты названия. Короткая подстрока вроде «моск» способна захватить область и другие совпадения: их нужно просмотреть. Выбор Москвы в отчёте сам по себе не означает, что в тексте каждой фразы будет только нужная география.

Результат выгружают в CSV. Для следующего шага сохраняют как минимум запрос и URL, по которому он найден. Числа в демонстрации — десятки тысяч запросов — относятся к примеру, а не к нормативу полноты.

## Что делать с результатом — 00:10–00:14

URL Маркета с читаемыми русскими хвостами используются как вспомогательный классификатор при чистке следующего урока. Нельзя автоматически кластеризовать всё по этим URL: страницы агрегатора пересекаются и не задают корректные посадочные проекта.

Автор предлагает аналогично искать источники под задачу: Яндекс Услуги для услуг, Авито и другие крупные агрегаторы своей ниши. По её наблюдению, Ozon приносит больше смешанного информационного спроса. Она не объявляет этот способ достаточным для любой тематики: остальные источники семантики остаются нужны.

Вход: тематические базисы, тип спроса и нужная география. Выход: CSV «фраза → URL источника», ещё требующий чистки. Приёмка: выгружены все нужные варианты базисов; геосрезы различимы; URL сохранён; агрегатор не скопирован как структура сайта.

Инструменты: Мутаген, Яндекс Маркет; как альтернативные источники названы Авито, Яндекс Услуги, Ozon и другие тематические агрегаторы.
