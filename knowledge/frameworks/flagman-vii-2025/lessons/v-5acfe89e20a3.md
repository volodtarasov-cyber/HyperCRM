## 00:00–08:42. Найти то, что не приходит в голову

Базис здесь — исходное название/синоним для дальнейшего расширения. Один предмет может иметь разные формулировки, а слово «кран» — обозначать совсем разные предметы. Поэтому широкий конкурентный сбор иногда удобнее предварить поиском вариантов и ограничить чужие смыслы.

Мутаген → **расширение семантического ядра**: исходное понятие, по умолчанию крупная база Москвы; при локальном термине добавить соответствующую географию. В примере использует топ-20 и небольшой вес ключа 1–2 для ширины. Не все экранные галочки названы в речи, полный пресет по ASR не восстанавливается.

Отфильтровать количество слов: сначала одно, затем при необходимости два. На беговеле находит беговелик, бегоход, велобег и другие названия; не каждый вариант автоматически тот же товар, смысл нужно понимать. На газобетоне упоминает «газокирпич». Это заготовки для дальнейшего раскрытия, не готовые H1.

Преимущественно однословные синонимы в этом уроке **не противоречат двух-трёхсловным базисам** расширенного сбора услуг: здесь задача найти названия предмета/бренда, там — ограничить смысл широкого направления.

## 08:42–14:56. Брендовые формы

На Volkswagen показывает множество написаний/сокращений, включая ошибки и раздельные формы. Посмотреть и одно-, и двусловные варианты. Собрать через выбор строк, CSV/список или буфер, при копировании подтвердить соответствующее окно. Убрать лишние склонения/явный мусор, при необходимости объединить несколько сервисов в мастер-файл.

Русское/латинское написание выбирается не по вкусу: в конкретной базе популярность отличается. Частотности примера — исторические значения сервиса, не текущая оценка бренда. Словарь поисковика, по мнению лектора, не всегда сводит все редкие варианты автоматически.

## 14:56–21:15. Применения

Найденный набор можно использовать разными способами:

- Для дальнейшего расширения семантики и разнообразия кластера.
- Для уместного упоминания распространённых форм/сокращений на странице, без бессмысленного перечисления любого мусора.
- Для стоп-слов, когда чужой бренд не нужен: одной правильной формы недостаточно.
- Для отдельной рекламной группы по нестандартным вариантам.
- Для разнообразия анкоров, если форма естественная.
- Для исследования собственного брендового спроса, который не всегда полностью виден в одной консоли.

ПФ по менее конкурентным вариантам также предлагает как возможный эксперимент. Предположение о большей эффективности прямо требует проверки; доказанного результата такого теста в уроке нет. Разговор об ошибках в имиджевой рекламе иллюстративен, конкретный подтверждённый кейс лектор не называет.

## 21:15–24:33. Согласовать с маркетингом

Не спорить с тем, как реально ищут, но выбирать осмысленное применение. Список направлений не исчерпывающий; обсудить с маркетологом. Плохие варианты не становятся обязательным текстом сайта только из-за факта попадания в базу.

**Вход:** понятие/бренд и задача расширения либо исключения. **Выход:** очищенный банк синонимов и форм для следующего шага. **Приёмка:** чужие смыслы отделены, формы сохранены понятно, отбор объясним, популярные варианты и мусор не смешаны. **Инструменты:** Мутаген, Wordstat как альтернатива, Excel/Блокнот; аналитика/консоли упомянуты для сравнения полноты.
