# При слиянии сохранить связь с существующими страницами

## 00:00–06:05. Что именно объединяется

Сервис может объединить несколько маркеров: «бурение на воду под ключ», «пробурить скважину», «бурение скважин». Это на данном шаге кластер из маркеров, каждый прежде представлял группу запросов. Перед удалением проверить каждую ветку в основной структуре **по полному совпадению**, не по случайному вхождению.

Если лучший по частотности маркер был синим, а соответствующая ему страница уже есть под жёлтым названием, удаление жёлтого и сохранение синего потеряет факт существования страницы. Позже это способно привести к созданию дубля и каннибализации. Решение автора: **переименовать существующую жёлтую ветку подходящим маркером, сохранив её статус**, а лишнего нового кандидата удалить. Смысл не в конкретном цвете, а в связи с реальным URL.

Если в кластере уже несколько реальных страниц своего сайта, на этом этапе их **не сливать**. Оставить соответствующие ветки и в структуре, и в таблице данных. Массовая группировка маркеров не даёт достаточного основания для склейки URL.

## 06:05–10:16. Развилки

Вспомогательную выгрузку тоже можно разметить по существованию страниц, чтобы при обработке группы видеть происхождение маркеров. Для нового сайта этой проблемы нет: сохранять соответствие существующим страницам не требуется.

Новичкам автор прямо рекомендует не менять старые страницы в рамках этого шага. Опытный специалист может отдельно изучить, какие запросы закреплены за каждым URL, и решить, оставить ли страницы либо какую с какой склеивать. Это самостоятельное решение после анализа, а не обязательное следствие кластеризации.

Годовую частотность предлагает собирать сразу для наглядности. На демонстрации в ноябре бурение вне активного сезона выглядит слабым при месячном срезе. Нули сохраняются; это не означает обязательного создания страниц под каждый нулевой кандидат.

## 10:16–12:36. Граница текущей работы

Пока это черновая доработка, её не надо бесконечно доводить до идеала: дальше будет подробный ручной этап. Автор вновь объясняет роль базового каркаса — сохранить важные направления, которые текущая частотность не показывает. Нельзя считать все нули одинаково бесполезными.

**Вход:** результаты кластеризации и основная карта с наличием страниц. **Выход:** очищенные маркеры с сохранённым соответствием реальному сайту. **Приёмка:** новый маркер не превратил существующую страницу в «отсутствующую»; несколько действующих URL не склеены механически; изменения согласованы между картой и данными. Для запуска с нуля развилка сохранения старых URL неприменима.
