# Как предоставить и отозвать доступ к аналитике

## Суть

Короткая демонстрация выдачи индивидуального доступа к Яндекс Метрике, Яндекс Вебмастеру и Google Search Console. Показываются выбор прав и удаление пользователя. Новые аккаунты и доступы в ходе этого разбора не создавались.

## Последовательность из записи

- **Метрика:** настройки → доступы → индивидуальный доступ → добавить пользователя. Ввести Яндекс-аккаунт, выбрать права; для просмотра в примере достаточно чтения. Можно добавить пояснение, кому и зачем выданы права.
- **Вебмастер:** настройки/права доступа → управление → добавить. Выбрать просмотр, редактирование или ограничение по задаче. Для операции требуется подтверждённое владение сайтом.
- **Search Console:** управление пользователями → добавить аккаунт, в демонстрации адрес Gmail → ограниченные права.
- **Отзыв:** открыть пользователя в соответствующей системе и удалить либо изменить права, когда доступ больше не нужен.

**Вход:** подтверждённый владелец ресурса и аккаунт получателя. **Выход:** пользователь с выбранными правами. **Приёмка по показанному действию:** доступ выдан конкретному аккаунту; его можно найти, изменить и отозвать. Это описание интерфейса записи, без проверки современных экранов.
