# Продвинутая настройка текстовой релевантности

Источник: «Флагман VII», модуль 2, урок 26. ID: `v-dd7571b68a75`. Длительность: около 29,8 минуты.

Прочитан полный транскрипт. Дата обработки: 2026-10-29. [Транскрипт](../../../../.tools/local/flagman-vii/transcripts/v-dd7571b68a75.md).

## Для чего усиливать страницу — 00:00–00:07

Автор различает топ по одному маркеру и страницу, которую поиск считает исчерпывающей по теме. Во втором случае ожидает дополнительный спрос, включая редкие, случайные и меняющиеся запросы. Названные им «60% скрытого трафика» — положение урока, без представленного расчёта универсальной доли.

Текстовая релевантность — часть комплекса: не исправляет проблемы индексации, фильтры, МПК, историю домена и неудобство. Коммерческая страница должна превращать подходящий трафик в заявки, информационная — удерживать читателя. Автор ссылается на эксперимент с топорами как демонстрацию временного роста неудобного документа. Он также считает, что при накрутке конкурентов главный запрос может оставаться недоступен, хотя широкий спрос приносит обращения. Это его интерпретация, не обещание результата.

Входной уровень: уже выбран правильный тип страницы и маркер, внедрены базовые связанные слова и настроены пропорции ключей. Продвинутая работа предназначена для наиболее важных страниц; применять ко всему сайту подряд автор не предлагает.

## 1. Расширить источники связанных слов — 00:07–00:12

Автор располагает четыре шага по убыванию значимости. Первый — дополнительные связанные слова сверх обычного анализа слов конкурентов.

В GAR Classic показываются три источника: классический список по страницам топа, семантические графы/векторная семантика и поисковые подсказки. В полном наборе есть слова, встречающиеся хотя бы у двух конкурентов; основной набор строже. Граф может предложить слово, которого нет на страницах конкурентов.

Внедрять по смыслу, по возможности используя аналогичный содержательный элемент, как у конкурента. Источники дополнения без GAR, названные в уроке: подсказки Яндекса, Google, YouTube и правая колонка Wordstat, в том числе через парсеры подсказок. Автор не раскрывает устройство закрытого сервиса настолько, чтобы объявить эти альтернативы точной технической заменой графового алгоритма.

## 2. Распределить слова по зонам — 00:12–00:18, 00:21–00:25

Общий состав слов может выглядеть корректно, но в ссылочной зоне `<a>` преобладать посторонний термин. В примере по бурению наверх выходит «район», хотя в общей картине ключи и связанные слова присутствуют. Сравнивают отдельно всю страницу, ссылочную зону и остальной текст, исправляя избыток/недостаток в нужной области.

Пропорции в таблице сверяют с топом. Лектор несколько раз уточняет, где среднее, медиана и число пересечений, поэтому названия колонок и смысл значений нужно читать, а не переносить числа между ними. Конкретный расчёт снятия лишних повторов относится к разобранному сайту.

Дополнительный инструмент GAR — «семантические коконы», адаптированные автором для ссылочного распределения по вертикальным зонам документа. В его интерпретации вверху уместна навигация по видам услуг, в теле — сопутствующие темы и материалы, ниже — география, в подвале — общая навигация и служебное. Это идеи для страницы по примеру, а не универсальная одинаковая разметка всех сайтов.

Автор прямо говорит: красный индикатор кокона не означает, что нужно обязательно менять элемент. Сначала понять роль ссылки и возможность полезного размещения. Точное совпадение анкора, по его словам, не обязательно.

## 3. Проверить N-граммы — 00:18–00:20, 00:25

В Relevantus — другой версии инструмента GAR — смотрят устойчивые сочетания из двух/трёх слов. Это отдельная проверка сверх числа одиночных слов. Сопоставляют медиану по топу с собственной страницей по главным сочетаниям.

Пример: «бурение скважин» — медиана 5, на странице 6, автор не видит проблемы. Гипотетический недостаток 6 вместо 11 исправлял бы добавлением сочетания целиком. Упомянутые числа демонстрационные; по соседней колонке пересечений нельзя рассчитывать недостающее число повторов.

## 4. Проверить словоформы — 00:20–00:21, 00:25–00:29

Для основных слов маркера отдельно сравнить формы: «скважина», «скважин», «скважины», «скважину». Совпадение общей леммы не означает одинаковое распределение форм. Работать таблицей или последовательным исключением уже рассмотренной формы из визуального облака сервиса.

При «отсечении» меняется анализ в сервисе; это не команда удалить данное слово со страницы. Автор последовательно исключает формы и мешающие «район/районе», чтобы увидеть, какой основной формы не хватает. Такой просмотр помогает диагностике, но не подменяет правку конкретного документа.

## Выход и приёмка

Выход: важная страница с дополнительными осмысленными связями, проверенными зонами, основными N-граммами и словоформами. Сохраняются содержание и удобство пользования. Приёмка по уроку: базовые проблемы сайта решены; термины встроены в полезные элементы; области измерения не смешаны; цвет рекомендации не стал автоматическим ТЗ; результат оценивают шире одного жирного запроса.

Инструменты: GAR Classic/ГАР и Relevantus — закрытые инструменты сообщества в записи; публичный доступ не установлен. Подсказки Яндекс/Google/YouTube и Wordstat — дополнительные источники, Excel — работа с выгрузкой.
