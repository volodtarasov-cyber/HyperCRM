## Для действующего сайта — 00:00–00:08

Продолжает [первую часть](v-72ac4ac51e8b.md): трафик и видимость уже есть, сайт по его условию не должен находиться под понижающими санкциями. Новому сайту без исходных запросов способ не подходит.

Берёт старую выгрузку Ламмеда с отмеченными фактическими переходами, создаёт проект Wizard.Sape по Москве. При расчёте оставляет ссылочный модуль ради доступа к текстовому анализу и добавляет контекстную рекламу. Покупать арендные ссылки в этом эксперименте не собирается. Его резкое замечание о бесполезности Sape для Яндекса относится к этой записи; в других материалах роль ссылок описывает иначе.

Задача — быстро обнаружить большие отклонения, не выровнять каждый показатель каждой страницы. Прогноз движения медианы позиций на 1–3 и результата через 2–4 недели — ожидание автора, не замер после показанного внедрения.

## Мини-тексты из отсутствующих связей — 00:08–00:18

Выбирает товар «Аппарат Рота» по запросу с фактическими переходами. Через JustMagic «Акварель-генератор» получает связанные слова, отделяет однословники и проверяет наличие на странице/в коде. Помечает присутствующие и отсутствующие. Скрытая вкладка может содержать нужное слово даже если обычный поиск по видимой странице его пропустил; точное место следует посмотреть, а не объявлять слово отсутствующим по одному поиску.

В этой задаче допускает любую подходящую словоформу, поиск по основе помогает её найти. Наличие лишь в служебном атрибуте не считает равным содержательному употреблению. В меню слово тоже учитывает. Пример связан с описанием оборудования, медицинских рекомендаций по применению автор здесь не разрабатывает.

Из реально недостающих связанных слов предлагает копирайтеру небольшой невводный текст примерно 500–1000 знаков по теме. Не все ассоциации надо превращать в утверждения о свойствах товара. Альтернативный путь — ГАР, который сразу сопоставляет страницу со списком и отмечает отсутствующее; в демонстрации первая задача падает, повторная завершается.

## Сбои старой выгрузки и рекламный модуль — 00:18–00:23

Получается большой список, примерно 484 страницы. Допускает предварительное сокращение по важности, чтобы объём был посильным. Сначала ошибку анализа объясняет старой удалённой карточкой, затем уточняет, что часть ошибок — сбой самой Sape. Эти причины нельзя смешивать в подтверждённое отсутствие URL.

По рекламе показывает много фраз, не прошедших модерацию в медицинской тематике, называет 923. Прошедшие части описывает как автоматически запущенные. Сам признаёт настройку грубой по меркам эффективности контекста: задача этого примера — быстро дать целевой трафик из активной семантики, а не показать качественно настроенную рекламную стратегию. Расходы, цели и устойчивый результат рекламного периода здесь не измерены.

## Править большие расхождения — 00:23–00:29

В текстовом анализе смотрит относительные баллы страниц и открывает красные низкие значения, например 44%. Не трактует каждый совет как обязательный: общую рекомендацию уменьшить объём, переставить форму один раз или убрать один повтор пропускает.

Выделяет два значительных перекоса на примере катетеров: многочисленные повторы предмета в заголовках и «купить» по всей странице. Совет убрать 10/18 повторов не выполняет буквально, предлагает снизить часть и оценить изменение. Новое полезное слово в title может добавить. Утверждение об автоматическом пенальти за переспам — его модель причины, балл не доказывает санкцию.

Текстовый анализ Sape в этом процессе относит к глубине, ширину получает отдельно через JustMagic/ГАР. В успешном отчёте ГАР показывает и возможные особые словоформы: общая рекомендация «в любой форме» не отменяет явно указанную важную форму в конкретном задании.

Вход: актуализированная активная семантика и пары запрос–URL. Выход: приоритетные массовые исправления, отдельный список ширины и показанная возможность рекламного подлива. Приёмка: возраст выгрузки учтён; ошибка сервиса не названа ошибкой сайта без проверки; все рекомендации не превращены в обязательные; рекламная модерация не спутана с успешной кампанией; обещанный срок роста не выдан за результат.
