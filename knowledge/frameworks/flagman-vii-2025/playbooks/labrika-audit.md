# Массовый аудит и разбор переспама в Labrika

Статус: процесс [урока Маркина](../lessons/v-c2fb2c7e825a.md), без внешней проверки. Вход: сайт, завершённый полный отчёт, доступ к истории видимости/переходов. Выход: адресные исправления и страницы, которые следует оставить.

1. Добавить сайт, выбрать достаточный лимит и полный анализ. В демонстрации форма требует хотя бы одну фразу и поисковик/регион.
2. Дождаться расчёта. Число ошибок само по себе не трактовать как оценку поискового результата.
3. Сначала посмотреть доступность, зеркала, запреты боевых URL и неожиданные ответы. Проверить, какие предупреждения касаются важных страниц и роботов.
4. Найти тонкие и точные дубли. Сопоставить URL с видимостью и Метрикой, выбрать наполнение, уникализацию, объединение либо закрытие по назначению.
5. Открыть отчёт переспама и его предупреждение. Для каждого кандидата посмотреть **историю отдельного URL**, а не одного домена. При отсутствии базы видимости проверить фактические переходы.
6. Растущую страницу с хорошими позициями оставить. Ровную без понятной причины — скорее оставить. Падающую с явным избытком — разбирать для сокращения. Служебные и нетрафиковые материалы рассматривать отдельно.
7. При массовом обвале автор допускает широкий проход, начиная с наиболее выраженных случаев. Его 6/5/4% — порядок конкретного примера, не универсальный диагноз.
8. Исправление направлять на причину: повторяющийся шаблон, заголовки либо содержание. Не обнулять все слова, попавшие в отчёт.
9. После внедрения сопоставить те же URL и показатели. График уменьшения ошибок не заменяет видимость, обращения и работоспособность сайта.

Дополнительный модуль семантики требует корректной связи маркеров с URL. Автор показывает его возможности, но сам не подтверждает качество всех расчётов и не предлагает принимать нулевой показатель без выбранной страницы за её реальную ширину.

Приёмка: приоритет основан на масштабе и эффекте; данные по URL отделены от доменных; пустая база не равна отсутствию всех переходов; полезные страницы сохранены; результаты проверяются тем же срезом. Оговорка автора «не трогай то, что работает» — часть этого процесса.
