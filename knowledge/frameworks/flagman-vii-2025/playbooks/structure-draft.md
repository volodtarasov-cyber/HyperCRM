# Сбор черновой гибридной структуры по курсу

**Тип:** импортированный процесс «Флагмана VII», сборка по полностью прочитанным урокам. Не свидетельство применения агентством.
**Источники:** [карта процесса](../lessons/v-fd03fbfb6566.md), [выбор объёма](../lessons/v-1b8197a93a87.md), [каркас](../lessons/v-61bd4706e1ac.md), [методы](../lessons/v-704113212f00.md), [конкуренты](../lessons/v-d15f9818ca56.md), [семантика](../lessons/v-66b9cf0a8811.md), [дополнение](../lessons/v-e4126645b925.md), [задание](../lessons/v-3d9bacd563f4.md).

## Когда и с чем запускать

После блока аудитов, перед актуализацией веток. Нужны бизнес-направления, свой сайт при наличии, список сопоставимых лидеров, Excel/XMind и источник семантики. Результат — **черновик кандидатов**, не готовая архитектура для немедленного создания всех страниц.

## 1. Выбрать объект

Сравнить число видимых страниц у похожих лидеров. Авторские ориентиры: до 500 — обычно весь сайт; свыше 1000 — самостоятельные направления; промежуток изучить отдельно. Для услуг и узкого магазина часто подходит сайт целиком. В широком каталоге выбрать материнскую самостоятельную категорию, не мельчить до тесно связанных дочерних: иначе работа повторится.

**Контроль:** число относится к базе видимости, а не полному обходу сервера. Измеряется порядок работы, не устанавливается универсальный SEO-порог.

## 2. Построить каркас

Взять свой проработанный сайт либо максимально близкого лидера. Для нового/слабого сайта автор предпочитает лидера. Согласовать соответствие ассортименту и услугам с владельцем.

Ручным проходом меню создать логические группы и важные ветки. Организационные хабы без собственного маркера обозначить отдельно. Названия содержательных веток должны быть понятны без родителей: «горячее водоснабжение», «цены на бурение скважин». Информационные статьи складывать отдельно. Непонятное — в «распределить».

Вспомогательно использовать HTML-карту или sitemap через спайдер. Для XML-карты посмотреть адрес в robots.txt. Ручной каркас сохраняет сезонные и бизнес-значимые направления, которые могут не иметь заметной текущей частотности.

## 3. Дополнить видимостью исходного сайта

Выгрузить запросы, URL и очень точную частотность. Отсортировать частотность по убыванию, затем сгруппировать по URL. Выбрать маркер по смыслу страницы и намерению выдачи; не брать максимум частотности автоматически. Для статьи заголовок может быть рекламным и не соответствовать маркеру.

При работе с разделом отфильтровать URL по общей маске. Если плоская архитектура не позволяет отделить нужный раздел, выбрать иной источник для этого способа. В каталогах сосредоточиться на категориях; отдельные товарные смыслы брать, только если они подходят как потенциальные категории.

## 4. Расширить конкурентами

Выбрать похожих лидеров с большой видимостью и числом страниц. Для одного раздела допустим соответствующий участок широкого сайта. Пройти выгрузки тем же способом, добавляя новые смыслы.

Очевидные повторы не добавлять; спорные не вычищать долгим поиском сейчас. Неизвестные термины выяснять по выдаче, странице, объяснениям и с владельцем. Сначала важен охват. Автор называет обычными 2–3 источника, новичку полезен более широкий проход; это не жёсткое количество.

## 5. Расширить семантикой

Выбрать основной запрос с выдачей похожих бизнесов. Получить дополняющие фразы/хвосты. При необходимости удалить явный мусор, лишние регионы и чрезмерно низкую частотность; небольшой список не обрезать бездумно.

Кластеризовать в Keys.so, Мутагене или Arsenkin Tools. Просмотреть группы и все нераспределённые запросы. Выделить маркеры новых коммерческих, информационных и региональных направлений. Добавить их в каркас. Если источник даёт слабый результат, попробовать другой; Букварикс даёт бесплатный массив с дополнительной необходимостью чистки.

**Развилка из дополнения автора:** полный проход по конкурентам не исчерпывает спрос и не заменяет семантическое расширение. Для полного учебного маршрута используются оба подхода. Сокращения потоковых специалистов не подменяют этот вариант.

## 6. Сделать результат передаваемым

Отметить ветки, которые уже есть **на своём сайте**, и новые кандидаты разными цветами, добавить легенду. Для нового сайта все кандидаты новые. Статус наличия на своём сайте не наследуется от конкурента, с которого взят каркас.

Сохранить Excel/XMind. В файл входят группировка, самостоятельные маркеры, блок статей, неразобранное и легенда. По требованию учебной платформы XMind можно приложить архивом.

## Приёмка и следующий этап

- Важные направления не исчезли из-за сезона, нуля или отсутствия в базе.
- Маркер характеризует конкретный смысл; чужие запросы одного URL не приняты автоматически за единый настоящий кластер.
- Конкурентный и семантический проходы выполнены, новые кандидаты видны.
- Каталог не превращён в перепись всех товаров.
- Черновые дубли и спорные направления сохранены для актуализации, а не отправлены сразу в производство страниц.

Далее: быстрая ручная проверка → полуавтоматические параметры → детальная ручная доработка. Только после этого сопоставлять с существующими URL, готовить теги и создавать страницы.
