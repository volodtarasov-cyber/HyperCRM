# Измерение позиций и изменений в Topvisor

**Тип:** импортированный процесс по урокам [позиции](../lessons/v-5fec31c2ea32.md) и [дополнительные инструменты](../lessons/v-aed88d1be0bf.md). Вход: домен, группы внедряемой семантики, назначенные URL, системы и география.

## Настроить исходное измерение

До внедрений создать проект либо получить доступ к уже существующему проекту клиента. Импортировать запросы с группами, при необходимости папками, релевантными страницами и тегами. Назначенный URL — ожидаемая посадочная, которую затем сравнивают с фактически найденной.

Указать систему, регион, устройство, глубину и учёт поддоменов. Выбрать снимки выдачи/сниппеты только при их использовании: в записи они оплачиваются дополнительно. Добавить подходящих конкурентов, проверить состав и стоимость. Тарифы и включённые лимиты из записи не считать текущими.

Снять частоты нужного типа и региона, выполнить исходную проверку. Выбрать осмысленное расписание либо проверки по требованию. Не создавать параллельное платное измерение, если нужный проект уже доступен.

## Читать динамику

Сравнивать позиции и поисковый трафик вместе, отдельно по системам и географии. Учитывать сезонность. Смотреть группы/страницы, доли в топах, видимость, рост и падение. Видимость и прогнозируемый трафик сервиса не равны измеренным визитам.

Проверять дату: серые значения могут быть прежними, не переснятыми на текущий момент. Для длинного периода выбрать опорные даты, если интерфейс ограничивает число колонок.

Разбирать запросы за топ-100/50 и несовпадения назначенного URL с найденным. Проверить наличие и индекс страницы, её соответствие запросу и кластеризацию; при признаках конкуренции использовать [процесс каннибализации](cannibalization.md). Не объяснять любое несовпадение одной причиной.

## Проверять конкретное внедрение

После изменения выбрать группу, систему и регион, обновить позиции **по фильтру**, затем проверить новые дату и URL. Для единичного вопроса переснять один запрос. Остальной проект остаётся со старыми измерениями — это учитывать при сравнении.

Переход в выдачу из строки открывает заданный регион. Автор советует инкогнито для уменьшения персонализации браузерной проверки. При сортировке частот различать общий и региональный показатель: при необходимости скрыть общий и отсортировать снова.

## Дополнительное наблюдение

При необходимости загрузить выбранные страницы в проверку индексации и Radar. Настроить расписание. Смотреть изменения тегов, содержимого и ответов после работы разработчиков. Технический аудит действует по переданному списку; проверить его полноту и важность замечаний.

Отдельный конкурентный отчёт по базе помогает исследовать чужие запросы, тематики и сезонный прогноз. Не смешивать его расчёты с собственной Метрикой. Подключённые визиты по видимым поисковым фразам остаются неполным срезом из-за скрытых запросов.

## Выход

История позиций с понятными датами и срезами, найденные проблемы посадочных, выбранные отчёты и история технических изменений. При необходимости подготовить экспорт или гостевое представление; отправка клиенту — отдельное действие.

Приёмка: исходный замер есть; группы и URL заданы; свежесть измерений ясна; системы/регионы не смешаны; прогноз и реальные переходы различены; вывод о причине подтверждается разбором страницы, а не только графиком.
