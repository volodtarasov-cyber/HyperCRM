# Расширенный сбор и чистка запросов по курсу

**Тип:** импортированный дополнительный процесс. **Источники:** Наталья Карлина, полностью прочитанные [расширение](../lessons/v-7b97ea37e797.md) и [чистка](../lessons/v-bad18ed20dcb.md). Не заменяет основной [процесс карты маркеров](structure-draft.md): здесь собирается подробный пул запросов.

## Когда применять

Базовый источник не даёт достаточного охвата, есть редкие услуги/региональные особенности либо нужен более глубокий сбор. Дополнительные источники факультативны: их количество выбирается по недостаточности результата, а не ради большого числа строк.

**Вход:** тема, действительные услуги и география, основной запрос, Keys.so и место сохранения выгрузок.

## 1. База и базисы

Собрать дополняющие фразы основного направления. Для глубины лектор использует Яндекс Москву, затем чистит по целевому региону. При местных особенностях добавить соответствующую базу. Не переносить этот выбор Москвы в последующую кластеризацию — там анализируется нужный регион.

Дополнительно собрать Google. Отобрать двух-трёхсловные базисы и удалить неявные дубли, проверить слишком широкие слова и чужие смыслы. Сохранить и расширить через ключевые слова/хвосты. Похожесть подбирать по реальному мусору, высокий порог способен потерять нужное.

## 2. Конкуренты и дополнительные источники

Открыть похожие бизнесы, определить подходящие домены, сформировать групповой отчёт Keys.so. Не путать его с видимостью одной страницы. Базовое конкурентное расширение обязательно в этом варианте, Google факультативен.

По необходимости добавить Мутаген: Супергидра по доменам, расширение по базисам, массовые хвосты. МегаИндекс: похожие запросы, органические/рекламные базы по доменам. Подсказки Keys.so: базисы, нужная география, разбивка по лимиту. Другие источники допустимы при недостатке.

Каждый отчёт сохранить с понятным именем. Несколько вкладок сервиса могут менять базу/регион друг у друга — проверить перед импортом, особенно при странно одинаковых числах.

## 3. Объединить

Добавлять запросы из источников в основной групповой отчёт по доменам через список/файл. Большие входы разбивать на посильные порции; в записи списочный ориентир около 10 тысяч. Условия конкретных лимитов не считаются текущими для всех тарифов.

Сохранять исходные файлы, проверять кодировку и состав. Импорт большого файла может долго считаться; число новых записей не обязано совпадать с размером входа из-за повторов и пересечения баз. Пока это черновой массив, не страницы к публикации.

## 4. Удалить заведомо чужое

Сначала просмотреть малый **вес ключа** — число выбранных сайтов с запросом. В демонстрации вес 1 почти весь нерелевантен, но узкая тема может иметь ценные единичные варианты. Переходить к 2/3 постепенно, не удалять все уровни одним слепым порогом.

После каждого шага сбрасывать фильтры и проверять общий результат. Отличать удаление отмеченной страницы отчёта от всей отфильтрованной выборки.

## 5. География и вопросы

Выделить топонимы, сохранить реальную географию, проверить сокращения и ложные подстроки. Москва/область/города — разные варианты бизнес-охвата. Пример «мск» случайно сохраняет Омск.

Если нужен только коммерческий остаток, отобрать вопросы, но сначала защитить коммерческие формулировки «сколько стоит», «цена», «под ключ» и другие по смыслу. При сборе также информационного направления его сохранять отдельно, а не безвозвратно удалять весь вопросный срез.

## 6. Смысловая дочистка

Проверить висячие предлоги/союзы с учётом пробела. Разложить запросы на уникальные слова, посмотреть соответствующие фразы и удалить чужие услуги/товары/вакансии/бренды.

Не удалять одним стоп-словом пограничные нужные услуги: кессон, чистка, насос, обвязка могут быть частью предложения. При сомнении посмотреть выдачу и уточнить бизнес. Редкое спорное можно оставить до кластеризации.

## 7. Передать чистый список

В экспорте включить ключевые фразы. Скопировать колонку фраз отдельно, нормализовать лишние пробелы, удалить повторы, допроверить остатки географии/брендов и снова убрать дубли. Сохранить отдельной книгой для кластеризации, исходники оставить отдельно.

**Выход:** пригодный целевой пул запросов, сохранённые источники и при необходимости информационный остаток. **Приёмка:** полнота не потеряна из-за слепых фильтров, чужое удалено по смыслу, география соответствует бизнесу, дубли/кодировка проверены. Маркеры и конечные страницы определяются следующими процессами, а не каждым запросом этого списка.
