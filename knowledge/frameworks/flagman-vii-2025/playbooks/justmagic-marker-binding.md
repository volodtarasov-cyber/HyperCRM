# Маркерная привязка в JustMagic по курсу

**Тип:** импортированный процесс по [полностью прочитанному уроку](../lessons/v-80740368ac3a.md). Вход: проверенная по выдаче карта страниц и объединяемых маркеров. Для режима онлайн — дополнительно собственная база фраз.

## Подготовить файл

Из XMind/таблицы сделать две колонки: страница (URL или понятное имя) и маркер. Нескольким маркерам одной страницы назначить одинаковую страницу. Удалить легенду, служебные контейнеры и заголовок колонок перед подачей. Иерархию при необходимости сохранить в имени категории.

Проверить протягивание имён с цифрами: Excel не должен разнести одну категорию на числовую последовательность разных. Сохранить исходную карту отдельно.

## Выбрать режим

**«Маркеры»:** подбор из исторической базы JustMagic. В записи Hard выбирается для точности коммерческой привязки, Soft — для более широкого результата с готовностью дочищать. Задать метку, файл, посмотреть стоимость и выполнить задачу.

**«Маркеры онлайн»:** привязка собственного пула к той же карте с заданным регионом. Объединить фразы из выбранных источников, удалить дубли, очистить чужие смыслы и географию. Частотные отсечения ради стоимости ограничивают полноту: сохранить их как условия опыта, а не обязательные нормы. Загрузить карту и базу отдельными файлами, проверить расчёт стоимости.

## Разобрать результат

Источники фраз различаются: `SRC1` — вход, `FOUND` — найденное; `SRC0` в обычном режиме означает отсутствие расширения. В показанном онлайн-результате нераскрытое остаётся `SRC1` без дополнений. Не смешивать обозначения режимов.

К отсутствию расширения возможны разные причины: неудачная формулировка, редкий спрос, излишнее дробление либо недостаток свежих данных базы. Просмотреть причину до удаления страницы.

Снять нужные частоты/дополнительные параметры, сопоставить по фразе через точный ВПР. Валидацию использовать для просмотра, не слепого удаления. Внутри категорий выбрать главный осмысленный запрос, посчитать нужную сумму частот. Отличать её от прогноза визитов.

## Доработать слабое

Выделить группы без расширения или с неожиданно малой частотой. Проверить формулировку в выдаче, собрать подходящие статьи/посадочные и их видимость, сгруппировать отдельно. Информационный H1 может не быть удачным маркером. Пример курса: «автономная скважина» уточняется до «автономного водоснабжения» после просмотра смысла.

Готовые группы передать на производство, неясные оставить в дополнительном исследовании. При объединении обычного и онлайн-результата учитывать разные срезы входа; сравнить повторы и уникальные дополнения до окончательной чистки.

Выход: таблица назначений с метриками, источниками и границами полноты. Приёмка: контейнеры/заголовок не попали как ключи; числовые категории не разошлись; пустое расширение разобрано; сравнение режимов учитывает фильтры; слабые темы не потеряны из-за одной исторической базы.
