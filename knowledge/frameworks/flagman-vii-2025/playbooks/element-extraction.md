# Извлечение элементов страницы браузерным скрапером

**Тип:** импортированный процесс по [уроку Simple Scraper](../lessons/v-4073a880e170.md). Вход: страница, нужные элементы и место сохранения. Примеры курса: меню, категории, названия товаров, результаты поиска.

1. Открыть расширение на выбранном элементе через контекстное меню либо выбрать его мышью.
2. Посмотреть подсказки похожих наборов, число элементов и подсветку на странице.
3. Если набор неполон или неверен, скопировать XPath нужного элемента из инструментов разработчика. Скорректировать область выборки, проверяя каждое расширение по фактическим объектам.
4. Альтернатива — CSS-селектор; указать соответствующий режим расширения.
5. Сопоставить извлечённое с видимым: пункты другого класса могли не попасть, а расширенный XPath — захватить лишнее.
6. Скопировать результат в таблицу или экспортировать CSV. Обозначить, включает ли выборка только уже загруженные элементы.

Выход: проверенный список нужных элементов. Приёмка: состав соответствует объектам страницы, формат пригоден для следующего этапа, динамически подгружаемое не объявлено извлечённым без проверки. Урок не показывает массовый обход всех страниц магазина этим способом.
