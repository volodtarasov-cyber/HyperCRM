# Построение сети для поискового охвата по курсу

Статус: импортированная авторская схема [урока о сетях](../lessons/v-d051e04fa0b0.md). Дополнительные источники: [мультирегиональность](../lessons/v-851c0808c39f.md), [методы региональности](../lessons/v-01e93554190e.md). Внешняя проверка не проводилась; сеть здесь не запускается.

Вход: сайт с подготовленной техникой, спросом, структурой, содержимым и релевантностью. Выход: схема версий и требования к каждой из них.

1. Определить цель: разные регионы, несколько мест внутри одного региона либо гибрид. Не смешивать с сетью доноров для ссылочного веса.
2. Довести материнскую основу по основному курсу. Автор начинает копирование после этого, а не заменяет им подготовку.
3. Выбрать архитектуру: поддомены, папки, отдельные домены или сочетание. Маркин предпочитает отдельные домены; его коэффициент трафика относится к собственным замерам.
4. Для региональных версий определить город, соответствующие контакты, название региона в шаблоне/title и вариант привязки. Физическую привязку автор считает сильнее, но позднее допускает развитие без неё с меньшим эффектом.
5. Для сети внутри региона учесть различие авторских требований автоматики и ручного просмотра. Его минимальная схема — разные контакты; для долгой работы предлагает различающиеся дизайн и тексты. Придуманные адреса/контакты в источнике не становятся подтверждёнными сведениями о компании.
6. Сравнить присутствие по регионам и типам выдачи через инструменты замера, не по одному удачному обновлению браузера. Отдельно смотреть рекламу и органику.
7. Разделить результат сайтов и общую обработку обращений. Больше доменов не задаёт фиксированного коэффициента заказов или прибыли.

Приёмка: вид сети и цель ясны; основа подготовлена; города и адреса не смешаны; проценты автора не подставлены в расчёт проекта; типы выдачи и периоды различены. Автор сам говорит о рисках аффилирования сети вглубь; его утверждение о безопасности сети вширь не распространяется автоматически на любые ошибки индексации, контента и доменов.
