# Релевантность общего шаблона по курсу

Статус: импортированный процесс [урока о шаблоне](../lessons/v-9ad90179e8c2.md). Внешняя проверка не проводилась.

Вход: проблема роста, выделенный повторяющийся шаблон и подходящие сайты-лидеры. Выход: адресное задание на общие элементы, с пониманием охвата изменения.

1. Определить типы шаблонов. Для разных крупных направлений не считать автоматически общим один и тот же образец.
2. Получить страницу без основной контентной области: специально пустую на своём сайте либо подходящую 404/служебную. Убедиться, что окружение совпадает с рабочими страницами.
3. Выбрать похожих лидеров с видимостью, желательно ростом. Получить сопоставимые шаблоны и текстовые таблицы.
4. Сравнить основные слова, их порядок и относительные пропорции. Не копировать чужую плотность механически; пример контролируемого переспама автор отдельно не рекомендует молодым сайтам.
5. Сопоставить ширину: выгрузить слова в Excel, выделить различия и посмотреть смысл употребления. Полезную связь отличать от служебного или случайного слова.
6. При необходимости добавить источник связанных фраз. В демо — JustMagic «Акварель», затем Miratext для приведения к таблице слов. Список фраз не равен обязательному тексту внедрения.
7. Сформулировать изменения повторяющихся элементов и их контекста. Рассматривать влияние на весь массив страниц, затем на целевые страницы целиком: корректный шаблон не заменяет их содержание.

По [бонусному уроку](../lessons/v-aae686edf0a1.md) дополнительно посмотреть около десяти категорий и десяти товаров для повторяемой закономерности. Проверить дубли меню для разных экранов, скрытые старые кнопки и варианты листинга. После редизайна или изменения общих элементов повторить анализ: прежний результат относится к прежней версии.

Приёмка: сравниваются шаблоны одного назначения; процент не назван универсальной нормой; добавленные слова имеют подходящий контекст; типы страниц различены. Автор ограничивает применение проблемными сайтами и компетенцией исполнителя: не предлагает переделывать успешно растущий сайт только ради графика. Результат конкретного внедрения этого демонстрационного анализа в уроке не показан.
