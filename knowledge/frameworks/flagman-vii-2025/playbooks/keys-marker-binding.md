# Раскрытие подготовленных маркеров через Keys.so

**Тип:** импортированный процесс по [уроку маркерной привязки](../lessons/v-aa214b73cb5e.md). [Быстрый пример](../lessons/v-c8f1989daa33.md) показывает его место в общем техпроцессе. Отличать от [кластеризации в KeyAssort](keyassort-clustering.md): здесь расширяется уже подготовленная карта.

## Вход

Таблица маркеров после [сбора структуры](structure-draft.md) и [актуализации](structure-finalization.md), предложение и география. Подробные ключи нужны для измерений, наполнения и других процессов курса; сбор не означает одновременного запуска рекламы или закупок.

## Раскрыть карту

1. Проверить каждый маркер в Keys.so: точное наличие нужной словоформы и возможность расширения. Пометить рабочие и исключения разными цветами.
2. Нераскрытый переформулировать без изменения смысла: падеж, число, предлог, уточнение коммерческого назначения. Букварикс помогает найти формулировку; её повторно проверить в Keys.so.
3. Рабочие маркеры массово подать в расширение ключевых слов. Выгрузить пары «целевой запрос → подробный ключ».
4. Исключения раскрыть через Букварикс по одному либо другой источник; сохранить однозначное назначение маркеру. При невозможности полного расширения оставить подтверждённый маркер с явной границей полноты.

## Добавить параметры

В WordKeeper или названном источнике собрать используемые частоты месяца/года и дополнительные поля: коммерцию, правильность, подсказки, число главных, конкуренцию. Регион — проекта. Ошибку получения показателя для длинной фразы не превращать в ноль.

Связать параметры с ключами через ВПР с точным совпадением, закрепить диапазон. Проверить соответствие; затем при необходимости заменить формулы значениями. Не переносить построчно по предполагаемому порядку.

`СУММЕСЛИ` по маркеру позволяет получить сумму выбранного вида частоты кластера. Использовать как ориентир порядка производства, сохраняя название метрики; это не число будущих визитов.

## Проверить назначения

Подсветить повторяющиеся фразы. Для каждого пересечения решить, ошибочно ли ключ попал к соседнему маркеру или сами группы нужно объединить. Не сливать автоматически все страницы с одним совпадением. Отсутствие дублей не завершает смысловую проверку.

Пройти каждый кластер, отвести полностью пустые запросы с нулями также в истории. Живые годовые значения защищают сезонные фразы от удаления по одному месяцу.

Ноль в подсказках и низкая коммерциализация — признаки для просмотра. Порог около 30–40% в уроке подбирается по теме. Вопросы, полезные коммерческой странице, могут остаться и стать FAQ; чужая география удаляется по задаче. Оценивать смысл вместе с параметрами.

## Выход

Очищенная таблица назначений с параметрами, отмеченными ограничениями и сохранёнными исходниками. Приёмка: все маркеры раскрыты/отложены явно; формулировка не потеряла назначение; метрики сопоставлены по ключу; пересечения разобраны; сезонное не потеряно; валидация не стала слепым удалением.

Для экспресс-сбора из урока 29 сохранены отдельные условные фильтры похожести/частоты и длины. Они сокращают глубину и не являются обязательной частью этого подробного процесса.
