# Съём позиций в TOPSite по курсу

**Тип:** импортированный процесс по [уроку TOPSite](../lessons/v-e7cca3605c2b.md). Вход: ключи, целевой сайт/URL, система и регион.

1. Установить программу; автор предлагает сначала демоверсию. Подключить XMLStock/XMLRiver адресом из своего кабинета и проверить соединение/баланс.
2. Создать группу с нужными колонками, включая релевантный URL при его анализе. Для Яндекса и Google в примере используются отдельные группы.
3. Указать домен либо точный URL, регион, источник и глубину. Search API автор выбирает ради скорости; живой поиск считает точнее, но медленнее. Параметры записи не обязательны для всех проектов.
4. Импортировать ключи либо пары с частотами. Выбрать «проверять только позиции», если остальная статистика не нужна, и запустить.
5. Проверить окончание, ошибки, позиции и найденные страницы. При необходимости открыть выдачу из строки.
6. Для другой системы/региона копировать группу, затем изменить параметры. Проверить, что не остались чужие домен и география. Для кластеров использовать подгруппы и понятную легенду цветов.

Выход: измеренные позиции с нужным срезом и логами. Приёмка: источник/гео/дата ясны, ошибки не выданы за отсутствие сайта, унаследованные настройки проверены. Цены и сравнительные ограничения других сервисов относятся ко времени записи.
