# Hormozi Value Equation — Фреймворк

## Формула ценности

```
          Dream Outcome × Perceived Likelihood
Value = ──────────────────────────────────────────
          Time Delay × Effort & Sacrifice
```

## Как увеличить ценность оффера
1. **Dream Outcome ↑** — усилить желаемый результат (конкретика, цифры, визуализация)
2. **Perceived Likelihood ↑** — повысить веру в результат (кейсы, гарантии, доказательства)
3. **Time Delay ↓** — сократить время до результата (быстрые победы, этапность)
4. **Effort & Sacrifice ↓** — снизить усилия клиента (делаем за него, простой процесс)

## Структура Grand Slam Offer
1. Определи Dream Outcome клиента
2. Перечисли все проблемы на пути к результату
3. Для каждой проблемы придумай решение
4. Упакуй решения в компоненты оффера
5. Назначь цену, которая кажется смехотворно низкой относительно ценности

## Применение
- При создании оффера для лендинга
- При формировании продуктовой линейки
- При написании рекламных текстов (бить в каждый элемент формулы)
