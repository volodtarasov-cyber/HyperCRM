# Поиск, ниша, семантика — фаза 1 курса, уроки 1–4

> Импортированная внешняя теория: курс «Цех Васина» (Константин Васин, SEO 2026). Не метод агентства — его применение в `marketing-os/` решается отдельно. Индекс курса → [_index.md](_index.md).

## Как ранжирует поиск — «доказательное SEO»

Опора курса — утечка Google Content Warehouse API (2024), показания инженеров Google в деле US v. Google (Панду Наяк) и утечка кода Яндекса (2023). Имена сигналов приводятся как основание, а не как рецепт.

**Конвейер Google, а не единый алгоритм:** индексация и распределение по «складам» (Base / Zeppelins / Landfills) → первичный отбор Mustang → переранжирование NavBoost по кликам → финальные фильтры («твиддлеры»). Провал на раннем этапе поздним не компенсируется.

**Диагностика по симптому:**

| Симптом | Где поломка |
|---|---|
| Нет показов | индексация или первичный отбор |
| Показы есть, кликов нет | заголовок и сниппет |
| Клики есть, уходят | контент и первый экран |
| Позиции есть, заявок нет | конверсия страницы |

**Два столпа.** Q* — качество, медленная репутация домена (`siteAuthority`). Слабые и дублирующие страницы копят «алгоритмический долг» вплоть до штрафа на весь сайт: новый контент не поможет, пока не убран старый мусор. P* — популярность (`chromeInTotal`): Chrome считает все заходы, поэтому прямой, соцсетевой и почтовый трафик — тоже рычаг SEO.

**NavBoost:** клики за 13 месяцев — `goodClicks`, `badClicks`, `lastLongestClicks`. Заголовок — это обещание, первый экран должен его выполнять. Скорость сайта (CWV: LCP < 2,5 с, INP < 200 мс, CLS < 0,1) влияет не напрямую, а через быстрый возврат в выдачу.

**Молодой домен:** песочница (`hostAge`), выход по порогу доверия, а не по сроку. Яндекс подхватывает первым, Google копит; первые показы через 2–6 недель, трафик — через месяцы. Смена URL обнуляет историю страницы; год в URL вечнозелёного материала не ставится.

**Яндекс отдельно:** в утёкшем коде PageRank стоит первым; поведенческие весят ~25–30%; фильтры — Баден-Баден (переспам), Минусинск (ссылки), АГС (резкий рост слабых страниц), накрутка ПФ (откат до года). Турбо-страницы с апреля 2025 мертвы. Диагностика — Вебмастер, а не GSC.

## Ниша и тематический фокус

- **Монетизацию выбирают вместе с нишей:** партнёрки (CPA), лид-формы под свои услуги или свой продукт. Инфо-трафик без пути к деньгам — «работа в стол».
- **Критерии ниши курса:** массовый инфо-спрос («как / что / почему / сколько»), топ не занят гигантами, тема разворачивается в сотни статей, **только B2C**. Тяжёлый B2B «без запросов» автор прямо называет неподходящим.
- **Стратегия курса — инфо-статьи, а не коммерческие запросы:** нужен длинный околоцелевой хвост, который ведёт к покупке.
- **Тематический фокус** (`site2vec`, `siteFocusScore`, `siteRadius`): сайт «про одно» получает авторитет по теме, а статьи не по теме тянут вниз весь сайт. Смежные темы — отдельными кластерами внутри той же темы, а не «ещё пару статей про другое».
- **YMYL** (медицина, финансы, право) — только с фактчеком, первоисточниками и реальной экспертизой автора.
- **Быстрая проверка спроса за 30 минут:** 5–10 маркеров → Wordstat → кто в топе (гиганты или обычные сайты) → разворачивается ли дерево в сотни вопросов. Глубже — скилл `razvedka-nishi` (он уже стоит в волте).

## Семантика

- **Смыслы, а не частотность.** Запросы с одним намерением — на одну страницу; иначе страницы дерутся между собой (каннибализация).
- **QBST:** у поисковика есть набор понятий «исчерпывающего ответа». Выписать общие подзаголовки и термины топ-5–7 и вопросы из «Люди также спрашивают», затем добавить то, чего у конкурентов нет, но что ожидается. Один абзац по недостающей подтеме весит больше тысячи слов воды.
- **Кластер ≠ страница** — центральное предостережение курса. Wordstat показывает спрос, эмбеддинги — похожесть формулировок, но одну ли страницу закрывают запросы, решает выдача. Кандидат становится страницей, только если: интент один; выдача по фразам пересекается; своей страницы под этот интент нет; отдельному материалу есть что добавить. Пример автора: «экзамены в колледж» и «подготовка к экзаменам в вуз» попали в один кластер, хотя задачи разные.
- **Семантический кокон:** 1 хаб темы → 4–6 промежуточных → 5–15 опорных на каждую. URL отражает иерархию. Перелинковка — по следующему вопросу читателя; жёсткая пирамида «вес только вверх» из курса убрана как недоказанная. Анкор описывает, что найдёт читатель. Проценты точных анкоров и «активация ссылки кликом» курс называет фольклором.
- **На старте** хватает soft-кластеров и понятной структуры; полный кокон собирается, когда сайт уже живёт.

### Три режима сбора ядра в заводе

| Режим | Что | Цена |
|---|---|---|
| A · авто по API | Wordstat (Yandex Cloud Search API) → расширение → кластеризация Arsenkin | ≈ $0,6–1,3 за 5000 фраз; Wordstat 20 ₽ / 1000 запросов, лимит 100 в час |
| B · супер-лайт | sitemap и заголовки конкурентов → черновое ядро (`competitors_lite.py`) | бесплатно; поле, а не спрос |
| C · вручную / фриланс | Key Collector, Букварикс или заказ → импорт в `wordstat_seed.csv` | 3–15 тыс. ₽ |

- Частота записывается вместе со срезом: фраза с оператором, регион, устройство, дата, сырой ответ. Ядро снимается широкой частотой, фразовая — вторым проходом.
- LLM не кластеризует тысячи фраз с нуля, а только называет готовые кластеры. Черновая кластеризация — эмбеддинги локально (BGE-M3 → HDBSCAN), Arsenkin — только по спорным группам.
- Старый бесплатный `api.wordstat.yandex.net` закрыт; из РФ DataForSEO и Serpstat недоступны.

### Профессиональный сбор — три маршрута эксперта (урок 4, 54 мин)

Только информационная семантика: коммерческую курс не кластеризует — это «на порядок сложнее». Маршрут выбирается по объёму ядра, а не по амбициям.

| Маршрут | Объём | Как | Деньги |
|---|---|---|---|
| START | до нескольких тысяч фраз | ИИ строит карту маркеров (12 веток × 8–12) → руками расширяешь каждый маркер в Wordstat, только левая колонка, регион Россия → ИИ чистит (`cleaned` / `removed` / `review` + QA-отчёт, исходник не трогать) → частоты через Wordstat API: базовая и в кавычках, два вызова на фразу, стоп при прогнозе > 300 ₽ → топ-10 Яндекса через XMLRiver → кластеры по 3 общим URL | подписка + XMLRiver ≈ 25 ₽ за 1000 фраз; грант Yandex Cloud 4 000 ₽ на 60 дней, но 100 фраз в час — 2 400 фраз сутки |
| MEDIUM | 10–30 тыс. фраз | Arsenkin «Парсинг ключевых фраз»: маркеры по 250, до четырёх прогонов, каждый раз беря 250 самых частотных → объединить, убрать дубли → «Кластеризация», soft, сила 3 (можно 4), топ-10 (топ-20, если выдачу забили агрегаторы) | Arsenkin ≈ 2 200 ₽/мес |
| PRO | от 30 тыс., вся ниша — «писать годами, делать несколько сайтов на разные категории» | Arsenkin «Выгрузка ТОП-10» по маркерам → самые частые домены-конкуренты в Яндексе и Google → «Семантика по URL» (у коммерческих сайтов — только папка блога), позиции 1–15, без нулевок → частоты, отсечь фразы с частотой в кавычках < 10 → Key Assort + XMLRiver + прокси, soft или middle, сила 3–4; hard для инфо-семантики не брать | от 5–6 тыс. ₽: Key Assort $40 разово, XMLRiver ≈ 5 000 ₽ за 183 тыс. фраз, прокси |

Проверка кластеризации глазами: в каждой группе все фразы соответствуют её названию.

### Как семантика течёт в заводе (боевой пример ped-college.ru, снимок 2026-08-02)

Wordstat-сиды + реальные показы из GSC и Вебмастера + темы сайтов-доноров → детерминированная чистка (1502 → 320 фраз) → кластеризация `claude -p` на подписке → **4 фильтра «такое уже есть»** (бренд; ключ занят на ≥70%; каннибализация по `seo/keymap.json` ≥0,75; точный дубль) → `topics_backlog.csv` → генерация в очередь (буфер 12) → публикация 5 статей в день → опубликованный URL попадает в `keymap.json` и сам начинает отсекать похожие темы.

**Где лежат данные — важно для вопроса о втором сайте:** сиды, ядро, кластеры и снимки — в `seo-agent/data/` завода; список тем, очередь и реестр сгенерированного — в `content-factory/`; карта «страница ↔ ключи» — `seo/keymap.json` в репозитории сайта. Всё это состояние одного сайта.
