# Право, выкат, сервер — фаза 2 курса, уроки 9–10

> Импортированная внешняя теория курса «Цех Васина». Конспект для ориентировки, не юридическая консультация — в самом курсе тоже. Индекс → [_index.md](_index.md).

## Юридический минимум (до того, как форма начнёт собирать контакты)

**Порядок жёсткий:** документы → размещение на сайте → выкат и сбор заявок. Форма, которая собирает контакты без согласия и политики, нарушает закон с первого дня.

| Что на сайте | Что нужно |
|---|---|
| Только статьи, без форм и счётчиков | реквизиты в подвале |
| Метрика, форм нет | политика + плашка о куках |
| Форма заявки, подписка, чат-бот, квиз | согласие + политика + уведомление в РКН + галочки у формы |
| Приём оплаты | + оферта (без неё платёжные сервисы часто не подключают) |
| Рассылки | + отдельная **необязательная** галочка на рекламные материалы |

- **Уведомление в Роскомнадзор** подаётся один раз через портал, разрешения ждать не нужно; одно на оператора, а не на каждый сайт. С 30 мая 2025 за его отсутствие есть административная ответственность.
- **Галочки:** бесплатная заявка — одна («даю Согласие … в соответствии с Политикой», оба слова — ссылки); платная услуга — две (Оферта; Политика + Согласие). Ни одна не проставлена заранее; без обязательных форма не отправляется; рекламная — не обязательна.
- **Реквизиты в подвале на всех страницах:** ИП — ФИО, ИНН, ОГРНИП, дата регистрации, телефон, e-mail; ООО — название, ИНН, ОГРН, адрес, дата регистрации, контакты.
- **Документы пишет юрист, а не нейросеть:** ≈ 15 000 ₽ юрист под ключ, 5–10 тыс. ₽ помощь с РКН, Kwork — до 5 000 ₽ вместе с уведомлением.
- **Домены .ru / .рф / .su** с 1 сентября 2026 регистрируются и продлеваются только через подтверждённые Госуслуги — оформлять на собственника бизнеса, а не на подрядчика.
- **Google Analytics** для российской аудитории = трансграничная передача персональных данных с отдельным уведомлением; автор курса ставит только Метрику.
- **Передача заявок партнёру** делает владельца сайта оператором персональных данных — это прописывается в политике.

## Сайт в интернете — 7 шагов

0. **Гейт:** «проведи SEO-аудит и покажи пульт» — красных пунктов нет; юридический минимум готов.
1. **Домен и VPS.** Под сайт — российский VPS, Ubuntu LTS, 1–2 ГБ / 20 ГБ NVMe (~200–600 ₽/мес), если проект собирается локально и на сервер уезжает готовое. A-записи `@` и `www`, TTL 300. Агенту — доступ ключом и алиасом, не паролем.
2. **GitHub:** приватный репозиторий, деплой одной командой, `.env` не в репозитории.
3. **Выкат и приёмка глазами** (телефон + компьютер, одна статья целиком). Три ветки: сайта не было; на домене уже были страницы — нужна карта старых и новых адресов, иначе трафик уйдёт в 404; основной сайт на чужой CMS — блог в подпапку `/blog` через реверс-прокси (подпапка копит вес основному домену, поддомен — отдельному).
4. **Консоли:** Вебмастер (мета-тег), Search Console ресурсом «Домен» с подтверждением TXT-записью в DNS (не слетит при редизайне), Метрика. Проверять теги в исходнике трёх разных страниц.
5. **Sitemap** в обе консоли и в robots.txt; IndexNow для Яндекса и Bing (Google не участвует).
6. **Приоритетные страницы** — ручной переобход, квоты маленькие. Сервисы ускорения дают редко больше 30–40% — без гарантий.
7. **Telegram-уведомления:** что опубликовано за вчера, ошибка публикации сразу, падение сайта.

## Сервер

- **Сервер под сайт и сервер под Claude — два разных сервера.** С российского IP Anthropic не пускает, а `api.telegram.org` недоступен с российского VPS — нужен прокси-слой (у автора — свой Cloudflare Worker). Под Claude — зарубежный VPS, 2 ядра / 4 ГБ / NVMe от 40 ГБ (~1 000 ₽/мес).
- Штатный режим завода — **гибрид:** генерация на компьютере с подпиской, на сервере — мониторинг, аудит, отчёты. Скриптовые модули без нейронки можно гонять в GitHub Actions.
- **Грабля второго месяца:** диск съедает кэш сборок Docker. Лечится `docker builder prune -af && docker image prune -f`; правильно — почасовой скрипт уборки, который удаляет только кэш сборок и раздутые логи, не трогая образы, тома и контейнеры.
- **Заявки с сайта в Telegram:** один релей обслуживает несколько сайтов — сайты отличаются только чатом.

## Ключи завода (`KEYS.md`)

- Обязательно только два: домен в `site.config.yml` и одна нейронка — подписка (`claude` / `codex`) или API-ключ. Модуль без ключа выключается сам и говорит об этом в `doctor`.
- Секреты — только в `.env`; в конфиге и `.md` — лишь имена переменных.
- Wordstat — API-ключ сервисного аккаунта Yandex Cloud (scope `yc.search-api.execute`) + `YC_FOLDER_ID` из того же каталога; 403 при верном ключе почти всегда означает отсутствующий folderId или не ту роль. Лимит 100 запросов в час; **несколько сайтов разносить по времени.** Стоп-крана по деньгам нет — сразу поставить бюджет-предохранитель 300–500 ₽/мес.
- Обложки по умолчанию — HTML-шаблон, снятый локальным Chrome: 0 ₽, без ключей. Платно — Higgsfield, почти даром — Cloudflare Workers AI (~170 картинок в сутки бесплатно), своя видеокарта.
- Search Console: OAuth-токен «протухает» за 7 дней; сервисный аккаунт Google — один на все проекты (новый сайт подключается добавлением его e-mail в GSC). Коннектор Windsor.ai бесплатно держит только один сайт и пропускает данные через третью сторону — для клиентских проектов не годится.
